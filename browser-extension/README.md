# 实验搭子教务课表扩展

适用于 Microsoft Edge / Chrome；应用版本仍为 2.1.5。

1. 在默认浏览器输入 `edge://extensions`（Chrome 为 `chrome://extensions`）。
2. 开启开发人员模式，点击“加载解压缩的扩展”。
3. 选择实验搭子用户数据目录中的 `course-browser-extension` 文件夹（应用启动选课服务时自动准备；浏览器连接页会显示完整路径）。
4. 回到实验搭子 → 实验选课 → 登录设置 → 登录教务网站。首次打开连接页时安装扩展后刷新本页。
5. 如尚未登录，扩展打开学校官方教务页面；由你完成密码、验证码和二次认证。登录完成后自动读取一次课表并返回应用。
6. 完成后可保留浏览器连接页。应用进入时仅加载上次缓存课表；教务课程变化后，请再次点击“登录教务网站”主动刷新。关闭应用后连接凭据失效，下次需再次点击连接。

扩展仅有学校教务站点的访问权限、会话内存存储权限；没有 cookies、debugger 或浏览历史权限。学校会话由浏览器管理，扩展不读取密码输入框、不导出 cookie。

回传字段限于学号、学期、教学日历、课程及调课/停课/补课记录。读取账号与选课账号必须一致；官网未提供可核对学号时会停止同步并保留旧课表。不会代替你选课、退课或提交登录。

服务只监听 127.0.0.1，连接使用随机临时凭据并绑定当前选课账号；不会把凭据写进访问日志。没有后台定时轮询学校接口；仅用户登录完成或应用发出同步任务时读取。

已完成的课表会保存在实验搭子自己的用户数据目录；失败不会覆盖上次完整课表。真实校园网认证和课表返回格式仍需在首次安装后实际确认。
