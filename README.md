## 当前可用

- 28 个实验的分类、搜索、数值/数组/矩阵/科学计数法录入、必填与尺寸校验、草稿保存、学生信息、原始照片和 JSON 导入导出。
- **手机本机离线生成 Word 报告**：复用原版 28 套 Python 计算脚本、章节变体、知识约束、五位有效数字显示策略、Matplotlib 图表及 OMML 可编辑公式，不依赖电脑服务或服务器。
- 在实验页点击“生成 / 查看报告”，选择章节变体、随机组合、章节启停、是否插入原始数据照片；生成后可直接预览、查看报告中的图表，保存或分享 Word 文件。
- 单份生成在独立 Worker 中执行，可以取消；报告队列在连续任务间复用运行环境，暂停、停止或结束后释放。失败保留上次报告；修改数据后提示旧报告需要重新生成。
- 清除本实验会移除测量数据双副本、原始照片、报告与图表、章节配置及应用内的临时 Word/PNG 导出；保留学生信息和其他实验。已由用户分享到应用外的文件不会删除。
- “实验预习”按原版明确映射打开官网资料页。上下学期透镜、偏振光及水/空气声速分别共享对应页面；无明确直链时打开官网目录，不提示“没有资料”。官网资料需要网络，手机本地报告生成不需要网络。

- Android API 配置分别支持问答/润色和识图；使用本机 Keystore AES-GCM 加密保存密钥，不回显密钥，更换 API 地址需重新输入。浏览器预览和 iOS 暂不提供明文存储回退。
- 识图会发送当前照片给配置的服务商，长边压至 1600 像素；结果逐项核对、选择录入，支持仅填空白，缺失值不覆盖，长度不符拦截。
- 报告页的“AI 助手”支持自定义思考题、章节润色、编辑核对、显式导入及重新生成。导入内容绑定当前数据，数据变化后不能继续使用旧内容。

- 一站通已支持 Android 独立会话登录、身份与学时核对、已选课表、官网允许周次的余量查询、60 秒缓存、实验评价与清除登录。课表状态仅突出未来最近一场；清除使旧任务失效且不自动重连。已接入原生选退课二次确认、一次性票据、提交前复核与提交后回读；选课需明确确认教务冲突未校验。教师与实验用房已接入官网元数据查询；独立教务/报告会话已有实现与模拟验证，报告系统真实登录未通过验收。

保持绿色、圆角、输入框自身加粗绿色边框及设计动效。

## 本地数据与报告

Android 数据位于应用私有 files/lab-maker/v1；iOS 使用 LibraryNoCloud。测量记录、学生信息和报告元数据用轮换双副本及 SHA-256 校验；这是完整性校验，不是加密。学校账号仅在用户明确选择本机保存后写入 Android 加密账号库，使用 AES-GCM 与 Android Keystore；登录会话保留在内存，清除会话不等同于删除保存账号。Android API 配置整体加密保存在应用私有 shared_prefs/ai-v1.xml，AES 密钥由 Android Keystore 管理；不进入测量 JSON 导出。卸载后需重新配置。

报告二进制写入独立 generation 目录，完成后才发布元数据；报告元数据两份均写入成功后清理旧代，失败时避免删除可能已发布的新报告。原始测量精度保留，不在录入/计算中提前截断。

JSON 导出包含测量数据和草稿，不包含照片、Word 文件；导入仅替换本实验测量字段，保留当前日期、学生信息和照片。Word 导出走系统分享面板。卸载或清理应用数据可能删除本机记录，请主动保存需要的文件。

“填写完整”只代表录入规则通过；请核对测量记录、图表和生成报告的处理结果。

## 构建与验证

```powershell
. E:\tools\app-maker\activate.ps1
Set-Location E:\project\lab-maker-app
npm.cmd ci
npm.cmd test
npm.cmd run dev
.\scripts\build-android.ps1
.\scripts\install-android.ps1 emulator-5560
```

输出带版本的 `artifacts/preview/lab-maker-app-x.y.z-debug.apk`，并生成 `artifacts/preview/current-build.json`。同一版本内容变化时增加摘要后缀，保留已有包；旧常用路径不会被覆盖。安装入口按当前构建记录核对源码版本、包名、构建号、大小、SHA-256 和签名，不会回退安装旧包。可运行 `scripts/install-android.ps1 -VerifyOnly` 只核对、不操作设备。构建检查领域测试、JVM 测试、资源清单及原生类；仍是调试测试包，不推送仓库或发布云端。

报告验证入口：

```powershell
npm.cmd run test:reports
node.exe scripts/test-report-runtime.mjs --all --sections
# 对照原版算法在独立原生 CPython 中的正文/公式，不读取原版用户 data.json
E:\apps\xdu-labreport-writer-master\python-runtime\python.exe scripts\compare-native-reports.py
# 以下会改写专用模拟器的测试记录，只允许 emulator-* 序列号
node.exe scripts/smoke-android.mjs emulator-5560
node.exe scripts/smoke-report-android.mjs emulator-5560
node.exe scripts/test-android-report-corpus.mjs emulator-5560
```

Python/WASM 固定为 Pyodide 0.29.3，包按锁文件 SHA-256 下载/校验，只带报告所需组件。构建时可通过 scripts/prepare-report-runtime.py 从桌面源码重新准备资源；先在工具目录 report-runtime-lab 安装 pyodide@0.29.3，默认使用既有桌面开发 Python 的 fontTools。准备过程只读取 generate.py、schema、variants、知识文件及公共模块，不复制用户 data.json、照片、生成报告或凭据。

`npm.cmd run sync:ios` 同步 iOS；最低版本暂设为 15.4，附 Filesystem 的 PrivacyInfo.xcprivacy。尚未证明 iPhone 端的运行时、内存和预览兼容，不能据此称 iOS 可发布。

## 代码与证据

- src/domain：表单、校验、报告快照、双副本与旧任务隔离。
- src/features/reports.ts：报告页面、章节选项、取消、预览、图表及导出。

- public/report-worker.js：离线资源校验及 Python/WASM 执行，不接触宿主 Python。

- public/report-runtime：离线运行库、源代码快照、字体及开源许可；不是从云端运行 Python 代码。
- tests/fixtures：测试样本，不进入安装包。
- artifacts/verification、artifacts/report-tests：检查结果、截图和样本报告，供开发复查。
