# 科研绘图·图表模板

配合《科研绘图规范（matplotlib）》使用：数据从 `DATA` 取，图存到 `OUT_DIR`，每张图给一行 `caption`。

## 1. 散点 + 最小二乘拟合（最常用）

```python
import numpy as np
x = np.array([...], dtype=float); y = np.array([...], dtype=float)
k, b = np.polyfit(x, y, 1)
r = np.corrcoef(x, y)[0, 1]
fig, ax = plt.subplots(figsize=(8, 5.5))
ax.scatter(x, y, marker="o", s=45, color="#2c5f9e", label="实验数据", zorder=3)
xs = np.linspace(x.min(), x.max(), 100)
ax.plot(xs, k * xs + b, color="#e07b39", linewidth=1.6,
        label="拟合直线 $y=%.4f x %+.4f$，$r=%.5f$" % (k, b, r))
ax.set_xlabel("$U_{dx}$ / V"); ax.set_ylabel("$D$ / mm")
ax.grid(True, alpha=0.3, linestyle="--"); ax.legend(loc="best")
fig.tight_layout(); save(fig, "fig1.png"); caption("fig1.png", "图1 $D-U_{dx}$ 关系曲线")
```

## 3. 多系列同图（按条件分组，如不同 U₂）

```python
colors = ["#2c5f9e", "#3f8f5b", "#e07b39"]; markers = ["o", "^", "s"]
for i, (label, (xs_, ys_)) in enumerate(groups.items()):
    k, b = np.polyfit(xs_, ys_, 1)
    ax.scatter(xs_, ys_, marker=markers[i % 3], color=colors[i % 3], label=label, zorder=3)
    xr = np.linspace(min(xs_), max(xs_), 50)
    ax.plot(xr, k * xr + b, color=colors[i % 3], linewidth=1.4)
ax.legend(loc="best")
```

## 8. 平滑曲线（无理论模型时，不要硬拟合）

```python
from scipy.interpolate import make_interp_spline      # 只有 scipy 可用时才用
xs = np.linspace(x.min(), x.max(), 200)
ax.plot(xs, make_interp_spline(x, y, k=min(3, len(x) - 1))(xs), linewidth=1.5, label="平滑曲线")
```
若数据点少于 4 个，直接 `ax.plot(x, y, "o-")`，不要插值。
