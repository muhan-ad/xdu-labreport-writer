# 实验选课开发入口

已接入实验搭子主界面“学校实验系统”区域的“实验选课”按钮。

## 启动与修改

在项目根目录运行 `scripts/启动开发版.ps1`，或安装好项目的 Electron 后运行 `npm start`。修改本目录 `app.js`、`index.html`、`style.css` 后，在选课窗口按 Ctrl+R 刷新。修改 Python 或主进程后需要完全退出开发版再重新启动。

主进程入口为 `src/main/course-selection.js`。它启动内置 Python 本地服务，监听系统分配的空闲回环端口，因此不依赖原型网站的 8187 服务。独立选课窗口没有主应用 preload 和 Node 权限；仅主应用可信 IPC 能打开窗口。

## 当前功能

- 读取官方物理实验身份、学时、已选列表、可退列表和各周余量；按周一至周五下午/晚上展示。
- 分类着色、同名实验跨天对齐、跨周搜索；服务器核对后才允许用户确认提交。
- 进入选课窗口时仅加载教务本地缓存；由用户在登录设置中主动登录教务网站刷新，没有自动教务登录或定时轮询。
- 教务在默认浏览器的学校官方页面登录，验证码和二次认证由本人完成；配套扩展将课表返回本机应用。读取课程及调课/停课/补课，按实际日期与钟点检查冲突。未知记录标记不完整，失败保留上次快照。
- 按物理实验学号隔离课表，位于应用用户数据目录 `course-selection/academic/<账号哈希>/`。现有学校账号加密模块保持原样；此窗口不另建密码库或保存物理实验密码。
- 物理实验登录会话保留在内存；教务会话由用户的默认浏览器管理，扩展不读取密码或导出 cookie。密码不写入课表、源代码或日志。官方物理实验入口仍是 HTTP。

## 运行与打包

`package.json` 已配置复制本目录运行文件至 `resources/course-selection`；Python 依赖已装入 `python-runtime`，并记录在 `requirements-runtime.txt`。

浏览器扩展位于项目 `browser-extension/`，打包时复制到 `resources/browser-extension`，启动选课服务时准备到用户数据目录 `course-browser-extension`。安装说明见扩展 README。应用通过绑定当前选课账号的临时凭据与浏览器连接页通信。服务随应用退出停止；关闭选课窗口后，本次应用运行中的物理实验会话可继续复用。

本次保持应用版本 2.1.5，更新本地桌面程序资源；不发布云端或新安装包。

## 检查

选课卡片、跨周搜索、已选课表及确认页支持教师与教室信息。`course_metadata.py` 通过固定的官网 course.aspx、expeinfo.aspx 查询入口读取已登录页面；教师按实验、起止周、单双周和完整场次时间匹配，教室取实验项目查询，已选课表已有教室优先。查询由前端后台队列逐项触发，结果在本次登录会话缓存十分钟；不能唯一识别的入口、表格或多个教室只提示待核对，不猜测、不影响余量查询及选课资格校验。

- `node --test tests/*.test.js`：主应用回归。
- `python-runtime/python.exe -m unittest discover -s src/course-selection -p test_*.py`：选课适配器与教务同步。
- `node --test src/course-selection/test_*.cjs`：排序、搜索、预加载与冲突计算。
- `tests/course-selection-smoke.cjs`：需通过 Electron 运行，设置 `LAB_COURSE_SMOKE_WORK` 到隔离输出目录；不连接学校、不提交选课。

本次主应用 178 项回归、选课适配器 31 项 Python 测试与 23 项 JavaScript 测试通过；隔离 Electron 确认服务启动、页面加载、搜索入口及权限隔离。桌面截图捕获出现 UnknownVizError，视觉验收未完成。真实教务账号登录后的课表内容及真实选/退课结果尚未作为本次自动验收通过项。


教务课表仅用于后台冲突检测，不提供查看或导出界面。教师/教室解析失败时，用户数据目录 course-selection/course-metadata.log 记录控件名称和表头用于诊断，不记录表单值、账号密码或原始响应。

同实验、同周次、同完整场次只显示已选卡片，其他周次/场次仍保留并按资格禁用。进入时通过现有受限填充 IPC 获取账密填入登录框后自动提交一次；自动填充关闭、没有保存凭据或登录失败时使用手动入口，退出登录后的首次重载不自动重新登录。
我的实验课表按本机时间与官网实验日期/结束时刻标为已结束或未开始；右侧每行方格与该实验一一对应，最近结束的一格有动态光效，完成数量按已结束实验 / 当前列表实验数显示，不表示成绩或出勤。缺少日期或时间时为待确认，不计入已结束。切换周次/页面使用短滑动淡入，遵循系统减少动态效果设置。

我的实验课表及取消选课使用统一卡片，右侧无文字细长进度段一一对应、段间距 16px；最近结束的实验有小人与呼吸光效。取消操作仍经原 prepare/commit 确认流程，索引使用原已选数组位置。开始选课可选卡片使用深橙、蓝、绿、紫底色配白字；已选、无余量和冲突保持灰色。

## 一站通内容与老师推荐

侧边栏分为选课/课表/报告、实验推荐/老师推荐/常见问题、试题库/仿真三组，两处分隔线为 44px 短横线。导航独立滚动，登录设置保留在底部。

`guide-content.js` 为已审核的静态内容，包含 28 项实验推荐、27 位老师的 46 组实验评价以及 13 条问答。老师分类为明确写入的 `recommended`、`not_recommended`、`mixed`，不在运行时推断。同一老师不同实验的评价分别绑定；相同评价的多个实验合并显示。内容均作为纯文本展示，保留换行。

修改表格后，在项目根目录运行 `python-runtime/python.exe -X utf8 scripts/import-one-stop-guides.py <表格目录>`。目录内须有《实验推荐审核表.xlsx》《官网实验教师评价清单.xlsx》《常见问题填写表.xlsx》。导入器只读原表，先校验本次确认的条数、标识和教师分类，再更新静态内容；空白或待补充的实验评价显示“暂无评价”，空白问答跳过。新增教师或改变本次内容规模时，需要相应调整导入器的显式分类和校验。应用运行和打包不依赖 Excel 或此导入器。


## 定稿指南与真实选课（2.1.5）

`guide-ui.js`、`guide-ui.css` 在独立样式根中呈现已确认的三个内容页面，使用现有登录会话、请求队列、WeekCache 和教师元数据。读取官网允许的本周及未来周次，按日期排除已开始场次，按名称/周次/时间去重；教师入口只采用唯一核实的教师，不拆分共享名额。教师为推荐3、不推荐12、介中12；最终内容以当前 `guide-content.js` 为准，重新从旧表导入会覆盖后续人工修改，操作前须合并内容。

指南查询缓存60秒，刷新或选退课使其失效。加载、部分失败、日期和教师不明确均独立显示，不视为零余量。冲突开关默认开启并本机保存，按下午15:55–17:30、晚上19:00–21:25检查；缺少教务课表时明确显示未校验。

指南提交向 `/api/prepare` 增加 `guide:true`、`expectedTeacher` 和可选 `academicConflictToken`。教务冲突返回409、`code:ACADEMIC_CONFLICT` 和120秒会话内令牌；令牌绑定场次、教师及教务快照，确认后换成原有一次性票据。最终 `/api/commit` 重查名额、时间、已选、周学时、教师及冲突确认；返回不明确时保留回读，不重发提交。普通选课入口保持原有教务冲突拦截。

音频来自 Mechvibes CherryMX Brown PBT，文件及 MIT 许可证位于 `audio/`，仅本地加载。问答默认收起，保留逐字、折叠动画与可记忆音效开关，遵循减少动态效果设置。

### 2.1.5 音效与加载流程修复

JSON 静态配置按原始字节返回，FAQ 从本地 Mechvibes 录音加载配置并等待解码后播放。开关失败原因显示在按钮提示中；停止展开、关闭页面和关闭音效时停止发声。应用保留完整动效，不跟随系统减少动态效果偏好。

已选实验的查看评价使用原地弹窗，按明确别名和当前实验关系列出实验及教师评价；教师姓名为普通文字。推荐页缓存卡片和场次索引，只更新余量区域。当前周元数据与已保存教务课表检查完成后结束首屏加载；其余周次在串行后台队列补齐，未完整数据明确标记统计中或未完整获取。

首次展示状态存于用户数据目录 course-onboarding.json，与随机本地服务端口无关。统一清除通过受限 IPC 清理报告与学校浏览器会话，再经原有 CSRF 边界清理选课会话、票据、冲突证明和个人课表缓存；保留加密账号及自动填充偏好。专用教务浏览器切换到全新会话目录，不复用旧登录，也不强制关闭用户已打开的浏览器。
### 2.1.5 实验筛选与取消选课规则

一站通不再显示试题／仿真导航或账号选项；报告账号与提交功能保留，登录设置中的报告状态行隐藏。选课日历卡片均可原地查看实验和对应教师评价。

取消选课同时要求官网允许、距离实验开始超过72小时。采用北京时间，正好72小时、已开始及日期无法核实均拒绝；overview 返回 officialCancellable、cancellable、cancelReason，prepare 与 commit 都重新核对。前端在最早时间边界与窗口重新获得焦点时更新状态。使用一次性确认票据，跨界限拒绝后必须重新核对。

实验筛选按账号存于用户数据目录 course-filters.json（账号哈希键）。受限账号 IPC 提供 filter-load/filter-save；不改变官网选课 API。筛选草稿确认后才生效，条件取交集、多选内部取并集。当前周日历与跨周搜索共用配置，已选课表和推荐页余量开关独立。多选目录来自允许的未来周次真实场次，包含已满及冲突，不把评价中的静态教师关联作为课表来源；不唯一的教师不会满足教师筛选。目录后台补齐，失败明确标注且可重试，已有勾选不会被覆盖。
