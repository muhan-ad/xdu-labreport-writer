# 0.70.0 系统目录保存与官网预习验收

2026-10-27，当前模拟器 emulator-5560，保持 0.70.0，本轮未修改应用源码或安装包。

## 系统目录保存

初始默认目录为未设置。通过真实 Android 文档选择器进入唯一临时 Documents 子文件夹，确认系统读写授权；未选择任何原有用户目录。使用独立随机报告标识暂存一份已生成的测试 DOCX，原生 ReportFilePolicy、LabReportFilesPlugin、DocumentsContract 和 ReportExport 均实际执行。

五项通过：

1. 取得指定测试文件夹的长期读写授权，原生状态返回可写。
2. 第一份报告实际保存为 `LabMaker-report.docx`；同名再次保存为 `LabMaker-report（2）.docx`，没有覆盖第一份。
3. 两份文件各 142,928 字节，使用 adb pull 独立回读，两者 SHA-256 都与源 DOCX 完全一致。
4. 重新打开文件夹选择器并取消，原有已选目录保持不变。
5. 清除测试授权后，默认目录恢复未设置，继续保存被拒绝并提示重新授权。

结束后删除仅测试生成的源目录和公共文件夹，系统 URI 权限列表显示该目录 persisted=0x0，长期授权已释放，默认目录未设置。Android 仍保留当前 Activity 拥有的临时 URI 授权，直到 Activity 销毁；未为清除该临时记录而强制关闭应用。原有 209 个应用数据文件与更新前备份逐字节一致。

证据：`artifacts/verification/native-saf-1793073884371/`，含 state.json、results.json、两份实际导出的 DOCX。保存/取消/撤权复验脚本 `scripts/accept-native-saf-save.mjs` 要求先在系统选择器中选择指定测试文件夹，不会自动选择原有目录。

脚本第一次取消检查过早按返回；而 Android 选择器返回会逐级离开子目录，不能按一次就当作关闭。最初超时后的清理曾因选择器仍占用文件操作而不能立即清除设置；已核实 URI 仅为本次临时目录，关闭选择器后完成清理。脚本改为等待选择器成为前台、逐级退出并等待取消回调，完整流程随后通过。未修改应用的文件操作互斥或授权策略。

## 官网预习

实际点击“直螺线管磁场分布的测量”的预习入口，原生 Browser 打开 Chrome Custom Tab，地址正确为 `https://wlsyzx.xidian.edu.cn/expe/experiment.html?id=7`。

模拟器 Chrome 首次启动时选择不登录账号。官网页面实际加载完成，标题为“实验详情”，正文显示“冲击法测螺线管磁场实验”，相关文件包括实验 PDF、实验要求及注意事项 PDF 和实验 MP4。已检查原生截图。返回后恢复 MainActivity，并保持原实验页面。

初始浏览器观察脚本存在不受限的调试等待，已停止自己创建的测试进程；新版脚本为浏览器连接和页面目标等待设置超时，先读取前台浏览器，再等待 Activity 返回稳定后读取应用状态，避免将转场中的无 resumed Activity 当作应用返回失败。`scripts/lib/android-cdp.mjs` 的目标枚举也增加读取超时。这些均为测试脚本调整，不是应用功能修复。

证据：`artifacts/verification/native-preparation-1793074667218/`。复验脚本 `scripts/accept-native-preparation.mjs` 用于观察已从应用打开的指定官网页面及返回。

## 边界

没有登录学校账号、选退课、上传报告或付费 API 请求。本次只确认一个实验的官网资料列表加载及返回，没有逐份打开 PDF/视频，也没有验证所有实验资料在官网始终可达。没有安装或测试手机 Word/WPS、第三方云文件提供商、系统进程中断恢复或 iOS。目录测试为 Android 当前系统内置文档提供商，不能推广为所有文件提供商均已验收。
