# 报告上传资源版本核对修复

0.120.0 修复报告系统上传前的误判：报告使用在线更新的实验数据生成时，其保存快照包含数据包摘要，但上传前比较快照时未读取当前摘要，导致同一数据包下的报告也被提示重新生成。现在使用本次会话实际生效的数据包摘要比较；数据包改变后仍要求重新生成，内置数据保持原有行为。

使用实际 `SchoolReportView` 和本地模拟的文件/报告服务验证四种情况：更新数据不变可进入确认、更新数据改变会拒绝准备、内置数据可进入确认、内置报告遇到新数据包时拒绝。393 项领域测试和 Android 构建通过；测试没有访问学校或上传报告。iOS 共享资源已同步，尚未进行原生构建或设备验收；学校报告系统真实登录及实际上传不在本次验证范围。

证据：`artifacts/verification/school-report-resource-ui.json`、`school-report-resource-tests-0.120.0.log`、`build-0.120.0.log`、`sync-ios-0.120.0.log`。
