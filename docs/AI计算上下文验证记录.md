# AI 本次计算上下文（0.15.0 开发中）

源码中的问答和润色现可先读取原版报告算法的本次计算结果。结果在独立本机 Worker 内离线计算，不生成用户报告，不上传图片，不修改测量记录。缺少 API 配置时先提示配置，不先初始化计算引擎。

## 行为及限制

数据填写完整且通过校验时，调用原版 `common/calculation_context.py` 的计算捕获逻辑；电容与高电阻实验调用其原有 `calculation_context`。计算只使用当前输入，保留内部精度。缺失输入时不宣称取得了派生结果，AI 只能回答有依据的原理问题；填写了无效数字则先提示错误。

结果绑定实验标识、原版实验名称与当前数据快照。问答和润色可复用同一快照的计算，输入变化后重新计算；数据变化、取消、关闭窗口后不会继续发送旧数据请求。Worker 在成功、失败或取消时终止。历史和报告中的显示精度规则不反馈到内部计算。

计算阶段清理临时目录、环境变量、Python 搜索路径和绘图对象。测试同时发现并修复了既有报告生成流程没有恢复 `sys.path` 的遗漏，避免保留已删除任务目录。

## 验证证据

- `node --test tests/*.test.mjs`：61 项通过，包括计算结果的实验绑定、精度、零/null、非法值、体积限制、Worker 消息、取消、迟到旧消息和计算失败后继续生成报告。
- `node scripts/test-calculation-context-runtime.mjs`：28 个实验的 Node/WASM 计算与独立 CPython 进程中的原版算法逐项对照通过；另外检查三类无效请求、修改电流后重新计算、任务目录/搜索路径/环境恢复，以及计算后继续生成三个代表实验报告并保留 OMML 公式。
- 直螺线管另以独立 JavaScript 公式核对标定常数、理论中心磁场、实测中心磁场和相对误差，明确换算 mH→H、mA→A、cm→m 或 mm；不是只拿同一算法互相对照。
- 数值对照默认相对容差 `1e-9`、绝对容差 `1e-24`。仅对理想圆偏振样本的近零调制度 `m45`，以及正文中紧跟“拟合残差均方根”的近零数值，允许双方均小于 `1e-12` 的数值差异。未改变原版算法去消除两套线性代数运行库的浮点尾差。
- `node scripts/test-report-runtime.mjs --all`：28 个实验完整报告回归通过。
- `npm run build`：类型检查、前端构建及 37 项离线资源校验通过。

机器结果见 `artifacts/verification/calculation-context/results.json`，报告全量结果见 `artifacts/report-tests/wasm-results.json`。只用模拟测量样本；独立 CPython 参考脚本不读取原版用户的 `data.json`、凭据或报告。
