# 教务课表过期界面更新验证

版本：0.95.0。学校操作均为模拟，无真实选退课或报告上传。

教务课表达到 24 小时有效期后，原来的单周选课页面虽然会更新选课按钮，却可能继续隐藏场次并显示“教务课表已同步”；已选课表的状态提示也可能不更新。跨周页面的重绘路径已有刷新，但现在统一处理。

定时更新时重新计算教务状态及单周、跨周筛选，不重建已选卡片；重新获得焦点并取得有效课表后恢复筛选。过期的已知冲突仍按原有逻辑阻止选课，最终提交前的原生复核机制没有改变。

生产页面组件结合模拟学校及教务接口完成 12 项浏览器检查，包括到期、恢复焦点、单周和跨周筛选、已选页状态、已知冲突、账号偏好与六种视口。375 项领域测试、Android 原生单元测试、构建、资源及插件核对通过。0.95.0 已覆盖安装当前模拟器，前后 217 个应用数据文件的摘要一致，应用进程可启动。测试没有在 Android 界面重放教务到期场景，也不代表真实学校服务或手机验收。

iOS 共享页面及资源已同步核对；未进行 Xcode 构建或 iOS 设备测试。
