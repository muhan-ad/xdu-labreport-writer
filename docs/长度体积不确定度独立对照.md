# 长度与体积不确定度独立对照

0.119.0 使用单独编写的标准库公式，对“长度与体积的测量”的板长、孔径、板厚、缝长、缝宽及最终体积标准不确定度进行对照。体积按 `(L×W - πD²/4 - Lx×Ly)×d` 对原始独立输入求偏导，板厚 d 作为同一个共同输入，只传播一次；零点修正按当前模型视作固定值，仪器限差来自输入。

电脑 Python 与手机使用的 WebAssembly 运行环境各通过 28 个实验共 116 项主要量及部分不确定度对照。对 7 类实验构造无离群点的均匀、扰动和限差放大数据，21 组各 111 项对照在两种运行环境均通过。还故意将板、孔和缝的体积不确定度直接合成，独立检查正确拒绝了这一忽略共同板厚的错误。

这些为模拟数据下的模型一致性检查，不证明仪器限差、零点误差相关性、离群点处理及其他所有实验的不确定度口径符合具体课堂要求；也不代表 Word/WPS 排版或真实手机验收。未修改报告计算或安装包，未使用真实数据或调用外部服务。
