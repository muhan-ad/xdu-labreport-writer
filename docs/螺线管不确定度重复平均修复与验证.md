# 0.72.0 螺线管不确定度重复平均修复

2026-10-27。仅修改手机版源码与独立预览包，已备份并覆盖安装当前 emulator-5560；未修改原电脑版、真实实验数据或发布服务。

## 确认的问题

RKb = M I0 / [10 (d1+d2)/2]，d1、d2 是以 cm 表示的两次独立读数。单次标尺不确定度为 u_single = Δ_scale(mm)/(10√3)，两次均值的不确定度才是 u_single/√2。

旧代码先把 u_single 除以 √2，再将这个均值不确定度分别当成 d1、d2 的输入不确定度传给包含均值公式的传播函数，导致均值中的 1/2 偏导再次缩小了标尺分量。现两个输入均传入单次读数不确定度；中心读数均值继续只除以一次 √2。保留原有电流表分量、三组标定的 RMS 合成、固定 M/n/S 和独立读数假设，不将本次修复扩张成对所有相关性和不确定度模型的完整认证。

补齐计算上下文的数值分量，供独立验证及 AI 引用。磁场实测值、理论值、RKb 均值、相对误差及左右图形位置均未改变。旧报告不会自动改写，需要重新生成。

## 独立证据

标准库解析公式直接从测量输入计算偏导，不调用生产计算函数。增加一组可手算例：M=1 H、I=1 A、两次位移均 1 cm、单次位移标准不确定度 1 cm、电流标准不确定度为零时，RKb=0.1、u(RKb)=0.1/√2；nS=1 时 B=1 T、u(B)=1 T。此手算例仅验证公式，不作为应用录入数据；实际运行用符合正限差约束的样本。

CPython 和实际 WASM 各通过 110 个主要/不确定度核对项；六类实验的 18 组恒定、扰动、限差缩放输入，各通过 93 个敏感性核对项。14 项独立核对器自身测试通过。

另在隔离源码副本重建旧错误并实际执行，核对器准确拒绝四个受影响分量，同时 RKb_mean、B_exp_center、B0_theory、E_rel 与修正后完全相同；不是仅手工把预期值改为当前输出。原有主数值/不确定度 1000 倍单位错误负例仍被拒绝。

示例样本中心磁场合成标准不确定度从约 1.3144e-5 T 修正为 1.3268e-5 T（约增加 0.95%）；这是该样本的差值，不代表所有数据的固定修正比例，也不解释先前其他单位错误造成的巨大相对误差。
