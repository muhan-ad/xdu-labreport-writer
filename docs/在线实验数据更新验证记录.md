# 在线实验数据更新验证记录（0.42.0）

本轮接入 Android 在线检查和下载，沿用签名文件导入的校验、离线 Worker 预检、双份存储、最终确认、重新载入及恢复内置资源机制。应用版本 0.42.0，Android versionCode 45。

## 行为

- 设置中的实验数据更新提供“检查在线更新”，核实签名、最低应用版本、运行环境指纹和历史版本后才显示下载。
- 下载为匿名只读 GET，不携带学校 Cookie、账号或 API 密钥；固定官方资源地址，不跟随跳转。清单最大 64 KiB，数据包最大 8 MiB。
- 清单 404 单独提示暂未发布；403、跳转、断流及格式异常均显示失败，不误报已是最新版。
- 下载支持进度和停止，核对准确字节数与 SHA-256，再核实完整签名资源。完成下载不会自动启用。
- 点击检查并启用仍需最终确认和实际离线运行预检；成功后明确重新载入生效。当前会话和已有报告、照片、测量数据保留。
- 取消、离开页面、旧请求迟到、旧进度回调不会覆盖新页面；本地两个文件导入继续可用。

## 本轮证据

- 184 项领域与桥接逻辑测试全部通过，其中在线下载编排 7 项、原生请求适配 6 项。
- 118 项 JVM 测试全部通过（117 项业务、1 项原生工程示例）；下载器新增 7 项本地模拟 HTTP 测试，覆盖匿名请求、404/403/跳转、大小/摘要/编码错误、分块读取和取消。
- 在线更新生产界面模拟检查 8 项、原有文件导入界面回归 9 项、主应用设置导航 7 项全部通过。
- 实际签名包与报告 Worker 回归 6 项通过，测试使用临时测试密钥，实际生成报告 64 条公式；没有使用或读取生产私钥。
- 320、360、390、768、1024、1280 六种宽度检查无横向溢出，人工查看 320 和 768 截图；更新说明中的 HTML 被按文字显示。
- 构建、Android 同步、原生单测及 assembleDebug 成功。APK 校验覆盖 100 个资源、94,349,184 未压缩字节；11 个 DEX，26 个原生定义检查通过，调试签名与旧版一致。
