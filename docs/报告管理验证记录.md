# 0.13.0 报告管理

设置新增“报告管理”，列出本机已发布的报告，支持按实验/姓名搜索、预览、外部打开、保存/分享、进入实验、单份删除及删除全部报告。报告页同时新增外部打开。沿用绿色按钮和输入框，列表适配手机及平板。

预览读取所选生成代次的实际 Word 文件，使用已有沙箱查看器；外部打开通过 Android FileProvider 提供只读权限，不接受任意路径。没有安装 Word/WPS 时明确提示，可改用保存/分享。保存/分享使用原生系统选择器，准备的缓存字节与所选报告一致。

## 删除范围与失败处理

复用原版“删除报告保留实验内容”的规则，新增独立报告删除接口，避免调用会清除章节配置的整实验清除方法。删除前弹窗确认，确认后再次核对当前生成代次；新报告已替换旧报告时停止删除。文件清理与报告索引在同一报告队列处理，清理失败保留索引供重试。只删除目标代次、报告索引和应用内导出缓存，测量记录、原始照片、学生信息、章节/绘图配置及 AI 导入内容保留。外部另存副本不受影响。

缺失文件与损坏索引作为明确错误行显示，不冒充空列表，也不从实验目录隐藏实验。缺失文件的预览/打开不可点击，仍可清理其已核实的报告索引；损坏索引保留重试/进入实验重新生成入口。批量操作逐份核对并汇总失败，不因一份失败中止或宣称全部成功。

## 验证

- 45 项领域测试通过：新增清理失败后重试、测量/配置保留、确认后的报告替换保护、索引删除失败恢复。25 项业务 Java 单测保持通过（另有 1 项模板示例）。
- Android 实际 APK 报告管理 6 项组合通过：列表及损坏索引、搜索、实际 DOCX 沙箱预览、原生打开身份约束/缺失文件/无查看器提示、原生分享缓存字节一致、取消与确认期间替换保护、缺失文件和批量删除、数据/照片/配置逐字节保持。
- 测试临时隐藏旧报告索引并在结束后恢复，保留旧报告文件；删除只针对新建测试代次。系统分享选择器取消，未选择接收对象或外部存储位置。
- 10 项既有离线报告流程回归通过：生成取消、Python/NumPy/Matplotlib/Word、UI 心跳、MathML/照片/图表预览、图表提取、离线重启恢复、系统导出取消、完整清除和预习浏览器返回。
- 320/360/430/768/1024/1280 CSS px 截图和溢出检查，人工查看 320 手机和 768 平板列表。证据：artifacts/verification/report-manager-native.json、report-manager-*.png。

## 边界

模拟器未安装 Word/WPS，本轮验证其缺失提示和原生 Intent 文件约束，不能代替真机阅读软件对接验收。没有操作真实官网、选退课、报告上传、付费 API 或云端发布。

自定义公共保存目录/持久目录权限、已另存文件的统一管理、损坏索引专门修复及 iOS 原生直接打开仍待迁移；当前“保存/分享”不是自定义默认报告目录的等价替代。完整目标继续推进。
