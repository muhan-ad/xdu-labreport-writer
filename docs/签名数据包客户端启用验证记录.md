# 签名数据包客户端启用验证记录

版本：0.41.0 / Android versionCode 44，独立开发测试包。

## 客户端功能

设置 → 实验数据更新增加本地签名包导入。一次选择签名清单及对应数据包，核对签名、字节摘要、版本、目录、模板及字体后展示更新说明。用户确认后，先将数据包保存到两个独立文件并回读，再启动真正的报告 Worker 做运行检查，通过后才发布活动资源指针。

本版尚未接入在线检查和下载，不能称为在线更新已经完成。本地候选目录中的 unsigned 清单仍会被拒绝；没有正式签名、激活或发布任何生产包。

## 一致性与恢复

- 本次运行固定使用同一份已核实资源快照。启用或恢复内置只改变下一次载入的选择，用户点击“重新载入生效”后统一切换；不强制关闭应用。
- 报告模板选择、报告和计算 Worker、AI 知识及隔离绘图字体使用同一份活动资源，避免 UI 模板与 Python 模板不一致。
- 版本保护记录和活动指针分开保存；版本保护的两个副本先写入成功，才能发布新活动指针。
- 运行检查失败或提交前取消，原资源继续使用，并清理未使用的暂存包。正式提交阶段禁用停止，避免误报“已取消”但实际已经切换。
- 指针只有一个副本成功时明确返回已提交并带副本异常状态；全部写入状态无法确认时提示重新读取，不自动重复更新。
- 最新数据包无法核实时尝试上一份完整签名包，再不行使用内置资源，并给出状态。恢复内置不会清除版本保护，不会因此允许下载旧版覆盖。
- 重复启用相同的已签名版本可修复存储副本，并保留上一份可回退资源；不将当前版本写成自己的回退版本。
- 保留当前及上一份包，清理已经无引用的旧更新文件。用户测量数据、照片、报告、账号、AI 配置和自建库不参与此清理。

资源版本进入报告输入快照和 AI 数据来源标识。更新前生成的报告仍可查看和导出，但不会被当成新资源生成的当前正文来直接润色或复用派生 AI 图。

## 运行检查与轻量化

报告 Worker 接收已经验签的资源集合，Python/WASM 本体仍从安装包读取。新字体实际交给 FreeType 解析，并检查源资源所需的常用汉字覆盖；只有文件头正确、实际不可用或缺字的字体会导致预检失败。

会话只保留已解析资源和身份摘要，不长期重复保留整个原始包字符串。缓存包利用已签名的摘要校验正文，避免额外嵌套封装造成多重 JSON 转义。读取更新文件前检查文件大小；没有重复下载或保存整套 WASM 依赖。

## 验证

- 171 项领域测试通过。新更新存储事务 13 项，覆盖不读写用户记录、失败暂存清理、双份保存与重开、回退、版本保护、部分写入、停止及恢复排队、提交边界、旧包清理、重复启用和恢复内置。
- 新增报告资源身份测试；计算/报告 Worker 协议共 6 项，包含未核实资源不启动、资源解析期间取消及候选整体传递。
- 真实浏览器、签名校验、更新存储、ReportEngine、生产 Worker 与离线 WASM 组合 6 项：运行预检后提交、重新读取同版本模板和知识、实际 Word 报告生成（64 个公式）、不可用字体拒绝、缺字字体拒绝及恢复内置。发布密钥为浏览器内临时测试密钥，存储为内存端口，不冒充 Android 正式包启用。
- 生产更新页面 9 项检查覆盖未签名拒绝、取消、说明转义、运行失败、停止、手动重载、重复启用不要求多余重载、恢复及旧结果隔离。320/360/390/768/1024/1280 宽度无横向溢出，已查看 320/768 截图。
- 实际主程序导航 7 项、报告变体 10 项、真实报告 Worker 3 项回归通过。
- 真实隔离绘图 6 项回归通过，网络探针请求为 0。测试构建调整为完整包含新增分块；产品的隔离 CSP 未放宽。
- Android JVM 111 项（110 项业务、1 项模板）、构建、100 项安装资源、24 项原生类定义、签名与版本核对通过。

证据：`artifacts/verification/data-updates-ui`、`data-worker-update`、`settings-navigation-ui`、`ai-plot-isolation`，及 0.41.0 独立验证记录。

没有实机安装、正式发布密钥读取、生产更新启用、云端发布、真实选退课、报告上传或付费 API 调用。Android 私有目录磁盘事务、系统文件选择器、重启恢复和 WebView 的实际机型兼容仍需实机验收。
