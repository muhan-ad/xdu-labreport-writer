# 手动 AI 导入核对验证记录（0.46.0）

应用版本 0.46.0，Android versionCode 49。

## 本轮完成

手动问答、单章节润色、历史结果选用后编辑、多章节润色编辑后的导入，现均使用与生成前问答相同的确定性检查。核对发生在采用配置及新增编辑历史写入之前；已返回但尚未采用的模型原始历史仍可保留查看。

- 校验明确绑定的数值与当前计算是否矛盾、数据占位符是否有效、润色中的原始公式序列是否保持，以及是否混入原版禁止的通用写作指导/软件说明。
- 有明确证据的矛盾阻止导入，保留原配置和编辑框。数值无法核实时仅提示待核对；不把公式常数、未知数值一概判为错误。
- 完整数据使用与当前源身份匹配的本机计算结果，优先复用已有缓存；历史选用后缺少缓存时离线重读计算。数据未完整时只检查实际可取得的输入，不虚构派生值。
- 手动核对可停止，数据或报告原文变化后不采用旧结果；核对阶段与保存阶段分开，保存期间保持已有导航保护。
- 批量采用先核对整组内容，任何一章失败时不部分写入。修正文本后可以正常重试；没有为核对发送额外模型请求。
- 未核实数值提醒按题号/章节保存，保留未选章节的提醒；删除对应历史导入时一起清理。生成报告和报告管理页能看到相应提醒。
- 核对与请求期间禁用相关操作按钮，完成后恢复；修正批量润色结束仍残留“正在请求 AI”的页尾状态。

这些规则针对可明确绑定的数值和来源，不等于完整科学正确性证明。实际模型生成质量、单位语义的全面理解及 Word/WPS 显示仍需检查。
