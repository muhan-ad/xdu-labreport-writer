# 安卓系统安装授权与覆盖安装补验

本轮记录的是 0.74.0（versionCode 77）独立本地验收包的真实 Android 安装器测试，四项检查通过。没有修改应用功能、更新主应用或发布任何安装包。

## 已验证的范围

- 使用独立包名 `com.labmaker.app.acceptance`，与主应用使用不同 UID、存储及授权。辅助 Activity 只接受自身包名、与已安装测试包证书一致的本地 APK。
- 实际通过 PackageManager 读取 APK 身份、版本、最低 Android API 和签名证书：版本 0.74.0、代码 77、最低 API 24、71,006,126 字节；测试证书 SHA-256 为 `57d6f58780b1cbce1457f31a6fb5756b847883d036c75c5a50d6ac07f1f0adc4`。放入缓存后的 APK 摘要也与本机源文件核对一致。
- 初始未授权时，系统来源检查返回禁止，未打开安装器。进入该测试包专属的“安装未知应用”设置，启用来源授权后返回，检查变为允许。
- 通过真实 FileProvider URI、ClipData 与临时读授权打开 Android 系统安装器；选择取消后回到测试页，私有目录中的测试标记原样保留。
- 再次打开安装器并选择更新／安装，执行同版本覆盖安装。脚本确认 PackageManager 的 `lastUpdateTime` 已改变，且安装后仍能读到相同的私有测试标记。
- 清理记录确认辅助包已卸载，主应用进程 PID 未改变。云端请求、学校写操作及模型请求均为零。

## 尚未证明的范围

这是本机模拟器的系统授权和安装 API 补验，不是正式应用更新的完整验收。没有执行生产更新插件的签名清单检查、云端下载、主包身份策略或更高版本更新整条链路；没有绕过正式插件对包名、签名、版本提升等条件的限制。私有数据保留只由测试标记证明，不能扩大成全部用户数据或实体手机升级验收。实体设备、其他 Android 安装器及正式发布流程仍需继续验证。
