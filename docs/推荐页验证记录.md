# 0.9.0 实验推荐与老师推荐

## 本轮行为

- 原版 28 个实验评价和 27 位教师评价均来自已迁入的静态原始数据，保持顺序、明确别名和推荐/不推荐/介中分类；张欢保持介中。离线可读，不为浏览评价自动登录。
- 实验推荐与老师推荐均可搜索；老师按原版推荐、不推荐、介中切换。推荐页的“只看有余量”独立于选课筛选。教务排除选项目前禁用并标记未校验，不伪装成已校验。
- 实时名额只统计官网允许、本周及以后的已确认未来场次，排除已满、已选（含明确别名）、真实实验冲突和每周学时超限。名额合并按真实名称/周次/时段去重，再按日期和开始时间排序。
- 教师统计沿用原版保守归属：官网仅唯一确认教师时才归入个人名额；未知、多位教师同场不根据静态评价推定名额。教师相关实验不明确时标待核实。已确认部分可查看；余量不确定时不显示成零。
- 推荐页和跨周搜索、多选目录共用一条串行队列和在途扫描，展示缓存并逐周补齐；整次目录有 60 秒缓存，切换页面不重复失败查询。手动刷新/重试可强制重新读取，失败保留已读结果并显示未完整获取。数据快照变化时缓存失效。
- 后台更新只更新统计和可见性，不反复重建全部评价卡片。时间边界定时刷新，重新获得焦点也刷新；已开始的场次不再统计。
- 点击“查看场次”显示对应名称、时间、明确教师及余量，选取后仍经原生准备、一次性票据、最终确认、提交时重核和回读。准备期间关闭弹窗会丢弃迟到票据，不再弹出确认。不开辟绕过资格检查的提交路径。
- 清除/刷新会话清理目录统计，旧任务结果不会回写；后台查询中官网登录过期时撤销实时名额并回到登录。
