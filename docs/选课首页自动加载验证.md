# 首页选课自动加载验证

0.81.0 本地预览版。仅明确选定已保存的选课账号后，在首页空闲时读取课表和本周场次；默认关闭，不自动登录报告系统。设置只记录账号标识，密码仍由原有加密账号管理保存。

变更或取消设置时，正在恢复的已有会话予以保留；正在发起的旧自动登录则取消并丢弃过期结果。主动清除会话后，本次页面运行不自动重连；重新打开时仍按保存的设置加载。页面重载后优先恢复已有原生会话，避免替换当前账号。

验证：构建、资源和签名检查通过；自动加载界面 7 项、账号管理界面 10 项、实际 Android 原生接口和本地模拟学校站点 8 项通过。模拟站点使用虚构账号，未执行选退课和报告上传。页面重载通过，不等同于实体手机冷启动测试。真实学校登录和报告系统首页预加载不在此次验证范围内。

已备份当前模拟器数据并覆盖安装，215 个原文件均保留；仅 WebView 运行设置文件变化。测试辅助应用和端口转发已清理。安装包为 artifacts/preview/lab-maker-app-0.81.0-debug.apk，仅供本地预览，未发布。
