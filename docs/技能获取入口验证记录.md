# 技能获取入口（0.65.0 / Android 68）

## 对照与范围

原版 `src/renderer.js` 的 `SKILL_PAN_URL` 与设置“获取 skill”提供公开分享链接；手机版此前只有导入、启停、查看、删除和恢复内置。现补齐“获取技能”，放在技能页的折叠区，使用原版相同地址和提取码。

只有点击“打开下载页面”才打开外部浏览器，不自动访问、下载、解压或导入网盘内容。下载后仍通过既有 Markdown 文件选择和校验导入。内置四个技能继续离线可用；没有验证网盘文件当前是否仍有效或与内置版本相同。

链接可复制或长按选择；复制被拒绝时显示重试提示。Android 沿用原生复制与 Capacitor Browser，网页使用隔离的新窗口。异步结果绑定当前页面代次，离开后不写入新页面。获取不改动技能正文或启停状态。
