# 声速位相法记录口径与验证

0.86.0 修正录入页面的歧义提示：空气和水中的位相比较法均明确要求依次记录同相、反相点，合计 12 次。两份新生成报告的数据处理部分同样写明此计算前提，以及单独记录同相点或反相点不能套用该公式。测量数据、计算结果和已有报告均未被改写。

核对依据：现有脚本使用 λᵢ=|Lᵢ₊₆−Lᵢ|/3，意味着相邻位置是半波长；天津理工大学的实验讲义明确指出斜率相反的直线交替出现时移动半波长。若依次记录相同相位，两点间相隔一个波长，同一固定公式会使声速变为两倍。参考：https://physics.tjut.edu.cn/wlsyzx/info/1282/1077.htm

独立构造的空气和水中各两类数据，在电脑 Python 和实际 WebAssembly 计算资源中共核对 8 项：交替点输出正确，同相点用现有固定公式得到两倍值。两份真实 WebAssembly DOCX 生成通过，提示各出现一次，公式保留；Android 隔离测试包的两页在 320×568、568×320、768×1024 下没有横向溢出。359 项领域测试、安卓单元测试、构建、资源与签名检查通过。证据：artifacts/science-audit/sound-phase/results.json、artifacts/verification/native-sound-labels-1793168956965/results.json。

限制：本轮只澄清现有公式的适用条件，并未增加对仅记录同相或反相点的选择和计算；有这类旧数据时不能直接采用现有结果。旧报告不会自动变化。后续需要完整接入测量间隔选择，并覆盖旧数据、报告公式、批量生成和 AI 计算上下文。

另发现两份脚本将位置仪器限差直接转换为波长 B 类分量，频率仪器限差直接用于传播；是否符合本实验具体仪器和课程要求尚需核实。位置差的不确定度依赖输入的分布、各读数间相关性及逐差公式，不能仅凭当前信息选择某一个系数。GUM 的一般原则见 https://www.bipm.org/en/doi/10.59161/jcgm100-2008e ，本轮没有擅自调整不确定度计算。
