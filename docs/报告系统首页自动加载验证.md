# 报告系统首页自动加载验证

0.84.0 本地预览版。在本机账号管理中可分别为选课和报告系统指定一个账号进行首页自动加载；两者默认关闭、互不替换。沿用旧版设置格式，旧选课选择保留，报告自动加载不会因升级而自动开启。只保存账号标识，不把密码写进该设置。

报告系统后台仅登录并读取报告列表和状态，不准备或上传报告。打开报告页面时复用进行中的读取；已有报告会话优先恢复，修改未来自动加载账号不替换当前会话。清除会话后，本次页面运行不自动重连，重新加载页面时依然按保存的设置启动。账号删除、保存失败、损坏配置、重置和无效旧响应采用显式处理。

验证：357 项领域测试、Android 单元测试、正式包构建、资源和签名检查通过；账号选择界面 9 项、账号管理界面 10 项，恢复中切换设置的界面专项 1 项。实际 Android 组件配合本地模拟站点通过报告 6 项与选课 8 项检查，包括读取、页面重载、切换、清除和旧请求隔离；请求记录未出现上传或选退课。模拟包的测试网络例外不包含在正式预览包内。模拟器覆盖安装前备份并验证 215 个文件，安装后无缺失和新增，仅 WebView 运行设置文件变化；辅助应用和端口转发已清理。

局限：测试使用虚构账号和本地模拟网站；页面重载不等于真实手机冷启动；同时开启两套系统的完整设备交互、校园网真实读取和真机平板性能还需验证。此前真实报告系统登录测试被自动审批拒绝，未重复；没有真实报告上传、选退课或付费 API 调用。iOS 原生功能与全面移植验收继续。
