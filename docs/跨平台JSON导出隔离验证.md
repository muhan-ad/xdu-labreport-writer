# 跨平台 JSON 导出隔离验证

版本：0.98.0。适用于测量数据、自建变体与诊断摘要等 `exportJson` 路径，不改变报告或图片分享。

此前同名导出共用临时路径，后一次导出可能覆盖尚被接收方读取的前一次文件。现在每次使用独立的缓存目录，在分享前读取并核对 JSON 原文；写入失败或回读不一致时不打开分享面板，并移除不完整文件。已交给分享面板的文件暂留系统缓存，避免接收方延迟读取失败；系统可按缓存规则清理。

四项单元测试覆盖同名文件隔离、中文内容、异常清理、取消及文件名。浏览器中的生产导出路径分别使用安卓和 iOS 模拟桥，通过并发同名导出、内容回读及错误阻止分享检查。原技能文件和报告目录界面回归分别通过六项和八项；完整构建中 379 项领域测试及安卓原生单元测试、资源/插件核验通过。

0.98.0 已备份并更新当前模拟器，安装前后 217 个文件一致。隔离测试使用虚构变体，通过真实安卓分享面板和独立应用读取移动版及电脑版 JSON，内容核对与往返共五项通过；首次连接因应用进程尚未就绪失败，待应用启动后重试通过。测试后 216 个文件与安装前一致，另一个是系统 WebView 设置文件；测试数据已按隔离流程清理。没有真实学校写操作或付费模型调用。

iOS 共享资源已同步核对；模拟桥不是 iOS 系统分享、Xcode 构建或实体设备验收。
