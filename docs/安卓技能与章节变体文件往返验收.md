# Android 技能与章节变体文件往返补验（0.74.0）

本轮在当前 emulator-5560 操作已安装的 0.74.0。未改正式应用功能、未更新安装包或版本、未发布；补齐此前只有浏览器模拟或分享取消证据的文件往返链路。

## 实际 Android 验证

测试包 com.labmaker.app.acceptance 的独立 Activity 接收系统分享，从主应用的 FileProvider content URI 读取文件。它与主应用不同 UID，实际核对了临时读授权、中文文件名、MIME 与完整内容，不用主应用私有文件读取冒充外部接收。

再将这些合成测试文件通过 Android DocumentsUI 选择回主应用，没有给 file input 注入 File/DataTransfer。主应用的存储写入统一重定向到随机隔离目录，不修改原技能、测量、账号或报告选项。

技能六项：

- 实际导出 Markdown，外部 UID 收到完整内容和中文原文件名；禁用状态保留。
- 删除隔离技能后，经系统文件选择器重新导入，身份与禁用状态恢复。
- JSON 技能经系统选择与真实分享往返，CRLF、两端空白、公式反斜杠、多行元数据、绘图范围和禁用状态一致。
- 从系统文件选择器选入不支持的 JSON，库不变。
- 取消文件选择或分享后控件恢复可用，分享取消为中文提示。
- 完整重载 WebView 后，从 Android 私有文件恢复技能及启停状态。

章节变体五项：

- 电脑版文件通过实际选择器进入导入确认；取消不写归档。
- 手机版归档和电脑版章节文件通过真实分享被外部 UID 接收，正文、公式与原文件名完整。
- 删除后从手机版文件重新导入；重复导入去重。
- 实际详情预览和显式“追加并选用”把原文保存为对应实验的候选，没有替换原有内置变体。
- WebView 完整重载后归档恢复。

本轮没有再次生成报告，采用后的实际报告输出沿用此前的 WASM 验收证据；没有把该项文件往返扩称为新一轮报告渲染。

## 隔离与清理

新增接收 Activity 仅存在于 android/app/src/acceptance，不进入交付构建。主调试包重新构建后核对 30 个原生定义与 11 个 DEX，测试 Activity 不在其中；把验收 APK 送进交付核对入口，已因包含该 Activity 被明确拒绝。

结束后卸载独立接收包、移除本轮下载目录及主应用隔离目录。原 215 个 files/shared_prefs 文件中 214 个摘要一致，唯一变化为 CapWebViewSettings.xml；无新增原目录文件、无残留私有测试目录，原用户数据和账号配置保留。主应用 0.74.0 冻结安装包与签名记录仍有效。

未读取或发送真实凭据、学校选退课、报告上传或付费 API。外部读取器为本地测试 Activity，不等同于用户手机的文件管理器/编辑器/WPS；实际文本编辑器的体验、其他文件提供商、实体手机和 iOS 仍待验收。
