# 选课问答与感谢声明移植记录（0.43.0）

应用版本 0.43.0，Android versionCode 46。原版工程仅只读核对，未修改。

## 本轮功能

- 从原版 guide-content.js 移入选课问题 6 条、实验问题 5 条，排除不在迁移范围内的两条仿真问题。原版经验问答与应用报错分开；提示具体安排以学校及任课教师通知为准，避免把静态经验数字当作当前官网规则。
- 一站通登录前即可打开常见问题，设置也提供同一入口。支持问题与答案全文搜索、按分类展示和逐项折叠；切换帮助类型清除搜索词。
- 设置增加感谢声明，内置名单从当前报告源归档 common/credits.json 提取，与原版六位贡献者一致。构建时核对名单与报告归档一致，避免副本漂移。
- 当前会话启用签名数据包时，从该会话的已验证 sources 读取名单；保留与报告资源相同的重新载入边界，不在页面中途另行切换资源。
- 名单按数据解析并限制大小、条数、名称与贡献内容长度；签名有效但名单格式错误的数据包也不能通过完整资源核对。旧包缺少名单或异常时显示内置名单并给出说明；空名单显示待同步。
- 名称与贡献通过 textContent 展示，HTML 不执行；离开页面后迟到的读取结果不会写入新的页面。
