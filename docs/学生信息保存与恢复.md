# 学生信息保存与恢复

0.127.0 学生信息保存先读取现有记录，再逐份写入并回读核对；识图导入学生信息也使用同一核对流程。写入未能确认时保留输入供重试，并保留至少一份可恢复记录。应用启动时若无法读取学生信息，学生信息页显示重试入口，报告生成不会把未经核实的空白资料当作已读数据。

领域故障模拟覆盖首份无写入、首份损坏、第二份损坏及识图导入失败；实际页面 5 项模拟检查覆盖读取失败、阻止生成、恢复前导零、保存失败保留输入和重试。独立 Android 验收包中，本机写入被模拟为无效时明确提示失败，重试后重新加载保留姓名与前导零学号。395 项领域测试及安卓构建通过。

测试使用虚构资料，不访问学校或模型；验收包已卸载、模拟器已关闭。iOS 已同步共享资源，但未原生构建或设备验收。证据：`artifacts/verification/profile-recovery-ui.json`、`native-profile-save-1793318364682/results.json`、`profile-tests-0.127.0.log`、`build-0.127.0.log`、`sync-ios-0.127.0.log`。
