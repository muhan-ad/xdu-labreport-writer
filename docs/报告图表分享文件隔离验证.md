# 报告和图表分享文件隔离验证

版本：0.102.0。原有报告和图表使用实验 ID 与文件名作为缓存路径，同名内容再次分享可能覆盖接收方尚在读取的文件。现在每次分享生成独立缓存目录，保留用户可见的文件名；取消分享显示中文反馈，缺少分享地址时不打开系统分享面板。

临时文件不会在分享面板关闭时立即删除，因为接收应用可能稍后读取。它们保留在系统缓存中，系统可清理缓存；删除对应实验报告时应用也会清理该实验的报告和图表分享缓存。此方式可能让多次分享暂时占用更多缓存空间。

浏览器中用模拟安卓/iOS 原生桥检查同名报告及图表的独立路径、图表数据、取消和缺少分享地址；报告平台路由回归通过。381 项领域测试、安卓原生单元测试、构建及资源核对通过。三个历史安卓烟测脚本已按新路径调整并通过语法检查，其中报告管理测试新增已有分享缓存时拒绝运行的保护；本次未执行这三个历史脚本。

安卓模拟器以隔离数据在报告管理界面两次打开真实系统分享面板，分别回读两份同名、不同内容的 DOCX，两个路径及内容均独立；两次均取消系统面板，没有选择接收方。覆盖安装前后 217 个文件一致；测试后 216 个文件与安装前一致，另一个为系统 WebView 设置。未进行报告上传或学校写操作。

iOS 共享资源已同步；模拟原生桥不等于 iOS 系统分享、Xcode 构建或实体设备验收。
