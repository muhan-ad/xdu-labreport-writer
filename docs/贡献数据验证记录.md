# 贡献数据迁移验证（0.34.0 预览版）

设置中的“贡献数据”接入变体与报告两种方式；按用户最新范围不迁移识图训练数据贡献。功能服务于开发者审核与模板优化，与向学校提交报告相互独立。

## 内容选择与确认

变体来源为当前实验的独立归档库，支持搜索、每页十条、跨页勾选、清空、查看完整正文和备注。提交时重新读取每条并校验归属，只导出所选章节正文与备注，同文去重，不附归档内置原文或整份测量数据。最多 500 条、8 MB。

报告贡献保留 7.0～10.0 分、0.5 分步进的必选分数；最多九张照片和一份 DOCX。可使用本机已生成报告，也可通过系统文件选择器选文件。照片实际经 canvas 重绘为最长边 1600 像素、质量 0.8 的 JPEG，单图最多 2 MB，DOCX 最多 16 MB，总内容最多 40 MB。原版云函数仅接受 docx 扩展名，未伪装支持旧 .doc。

每次内容变化撤销同意勾选。上传前通过应用公共弹窗确认所选正文、照片、DOCX 文件名、分数、备注、应用版本及完整文件大小清单。DOCX 在贡献入口按文件名/大小列出，没有声称此处全文渲染；本机生成报告可在原报告页预览。

## 原生传输与失败语义

确认后将本批文件暂存于应用缓存的独立 UUID 目录；桥接只传索引、扩展名、大小与 SHA-256，不以巨型 base64 作为上传桥接参数。取消暂存也会阻止后续原生提交。结束时尝试清理本批缓存，不操作实验原始文件。

原生只读取固定缓存路径，检查目录边界、完整哈希、文件类型与大小，校验 Word ZIP 的必要文件、条目数和总解压大小；实验须存在于内置目录。使用与原版相同的固定凭证服务和 COS 目的主机，对全部票据检查 key、大小、服务器批次 UUID、文件名、协议/主机/端口/路径以及整批一致性，随后逐文件重读核对并上传。重定向和自动重试关闭，不使用登录 Cookie 或 API 配置。

报告清单最后上传。中途断线停止后续文件，结果显示已确认数量及未完成/待核对状态，不称为整批成功、不自动重发。完整成功才清空报告附件；未知结果保留选择供核对。重复点击、实验切换和旧页面响应隔离均有检查。

## 验证

- 130 项领域测试通过，新增 6 项内容构建与暂存队列测试，含显式内容范围、分数/数量/大小、固定缓存路径、取消暂存、清理和原生结果一致性。
- 7 项纯 JVM/本地 MockWebServer 检查通过：路径与 SHA-256、变体结构、DOCX ZIP/分数、逐票据绑定、完整批次顺序、第二个 PUT 断线后不重发且不上传 manifest、无效票据、取消及源文件变化拒绝。原生业务合计 97 项通过（另有框架样例 1 项）。
- 生产贡献页 11 项通过，使用模拟仓库/上传和真实 canvas 压缩，含分页跨页选择、完整确认正文转义、未同意/取消不上传、只传所选内容、报告与照片、未知结果不重试、成功清理选择、切换实验、读取失败和取消/旧响应隔离。截图覆盖 320/360/390/768/1024/1280；窄屏人工查看。见 artifacts/verification/contributions-ui/。
- 实际应用 main.ts 启动/设置路由检查扩为 5 项，含贡献入口、分数选项与无识图贡献入口；反馈/帮助 10 项回归通过。
- 安卓构建成功，96 个资源与 22 项原生定义检查通过，调试签名一致。

安装包与校验记录在 artifacts/preview/。没有真实云端上传、设备安装、学校写操作或付费 API 调用。手机系统文件选择器、缓存路径集成、真实服务配额/可用性与整套功能的实机验收仍待完成；整体移植目标未完成。固定 APK 与旧预览未覆盖，未发布仓库。
