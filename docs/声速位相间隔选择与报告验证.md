# 声速位相间隔选择与报告验证

0.87.0 在空气和水中声速实验的数据录入中增加“相邻位相记录点”选择：同相与反相交替对应半波长，相同相位对应一个波长。根据选择，位相比较法分别使用 |Lᵢ₊₆−Lᵢ|/3 和 |Lᵢ₊₆−Lᵢ|/6；共振干涉法保持原来的除以 3。新报告写入实际选择，并在可编辑 Word 公式中使用相应分母。

选择保存在实验记录，旧记录和旧报告仍可读取；旧记录不会被猜测或自动改写，需要用户选择后才能重新计算和生成。导出、重新导入、批量生成、报告快照与 AI 实验计算上下文均携带或识别此选择；导入无选择的旧文件和识图改变位相位置后需要重新选择。改变选择会使旧 AI 来源与报告快照不再匹配。实验数据包若使用不支持该选择的旧声速脚本，计算会明确停止并提示恢复内置数据或更新数据包。电脑版脚本未修改，不能假定旧电脑版支持手机新增的选择。

验证：两种介质、两种间隔的独立模拟对照在电脑 Python 和 WebAssembly 共 8 项通过；4 份实际 WebAssembly Word 报告的选择文字和可编辑公式分母逐份检查通过，5 种缺失/非法选择及 4 项旧数据包防误算检查被拒绝。Android 隔离测试包通过两实验的保存、重新打开、手机与平板界面检查；另用本地测试数据完成实际批量生成：未选记录被拦截，补选后重试成功，另一份的选择及 Word 公式保持正确。全部 28 份 WebAssembly 报告生成通过；28 实验独立对照在两种运行环境各 110 项、18 组不确定度变化各 93 项通过；366 项领域测试和 Android 构建、单元测试、资源签名检查通过。

保留限制：位置和频率仪器限差的不确定度口径仍需结合本实验仪器与课程要求核对，本次没有调整其模型；单纯选择间隔不能消除这项待核实内容。模拟数据不证明用户真实记录的间隔或实验结果。旧报告需要重新生成才会体现选择。

模拟器已备份并更新：215 个原文件无缺失或新增，仅 WebView 运行设置变化。测试只用隔离包和虚构数据，没有真实选退课、上传、付费 API 调用或发布。真实手机、平板和 iOS 全面验收仍未完成。
