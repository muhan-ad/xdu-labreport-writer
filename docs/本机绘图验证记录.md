# 0.7.0 本机自定义绘图与尺寸适配

本轮属于持续移植的进展，不代表完整目标完成。按用户最新范围：不移植试题库和仿真系统；其余功能继续完成，并适配手机和平板，精简无价值的小字。

## 已接入

- 数组、表格行和表格列可选为 X/Y 数据；可变测点按当前数据长度建立候选项，对应位置标签读取实际位置数组，避免用旧静态位置冒充新位置。
- 散点、折线、柱状图、线性拟合复用桌面 `chart-preview.py`，在本机 Python/WASM Worker 执行，不调用电脑服务或模型。原版两个辅助脚本保持原样，适配位于 runner.py。
- 标题、坐标及图注默认自动，次要设置收起；支持预览、取消、保存 PNG、按实验保存最多 8 个配置，以及明确勾选是否随报告插入。
- 图片每次由当前数据重新生成；配置、测量值和报告快照绑定，避免数据变化后分享旧图。保持原始计算精度，数值显示沿用原版策略。
- 完全成对的空测点可略过；单边缺失、非法数字、非有限数、长度不同、拟合横坐标退化均拒绝，不能静默补值。未填写的其他实验字段不妨碍独立预览所选数据；完整报告仍经过完整录入检查。
- 插图复用桌面 Word 插图脚本，并跟踪原版 writer 真正声明的一级标题来划分章节（原版直接格式化标题，未使用 Word Heading 1 样式）；不将带编号的小节当成章末。不存在或被禁用的章节明确报错，保留旧报告。
- 自动字段的 Unicode 下标/上标转为绘图数学排版；图注复用原版文字/OMML 渲染。`dₘ₁`、`n_i` 不以缺字或裸下划线呈现，图注公式保持可编辑。
- 重新生成替换报告代次，不累计旧图；关闭插图后重新生成会移除自定义图，保留原版预设图。清除本实验同时清除绘图配置及应用内 PNG 导出缓存，保留其他实验和学生信息。

## 手机与平板界面

- 手机保持单列，平板上 X/Y 和高级标注使用双列；报告弹窗内部滚动，页脚操作保持可见。
- 标题与标注默认折叠，未勾选插图时不显示章节选择。保留绿色、圆角、键盘焦点和完整动效。
- 登录页仅保留密码不保存的说明，删去迁移实现说明；设置页移除重复的功能罗列。冲突“未校验”等影响决策的状态保留。

## 本轮证据

- 29 项领域测试通过：包含 4 项绘图测试，覆盖数组/行列、可变长度、零和原始精度、空对/单边缺失、长度错误、拟合退化、设置大小及快照失效。
- Node 中真实 Pyodide/Matplotlib 运行验证 4 组组合：四种 PNG、独立手算 `y=2x+1` 的斜率 2/截距 1、偏转电压整行与位移对应、真实报告章末插图及两个可编辑下标。`artifacts/verification/chart-runtime.json`。
- 全 28 套报告在同一 WASM 运行时重新生成通过，记录在 `artifacts/report-tests/wasm-results.json`；不能用此替代 28 份全部页面的人工排版验收。
- 实际 Android APK 离线完成 8 组组合测试：取消并重试、UI 心跳、PNG 文件和系统分享（取消，未发送）、配置关闭后恢复、报告预览/原版图与自定义图共存、取消插图后重生成、清除缓存。
- 检查 320×640、360×800、430×932、768×1024、1024×1366、1280×800 六种 CSS 视口；页面及报告滚动容器无横向溢出。仅为同一 Android WebView 的布局验证，不能称为这些物理设备或 iOS 已验收。
- 截图：`chart-320.png`、`chart-768.png`、`chart-native.png`。已人工查看预览、中文标题和下标。
- 未进行真实选退课、上传、发送分享或付费 API 调用。

## 仍需继续

基础自定义 XY 图不能替代完整官网预设及 AI 绘图。当前按所选原始列/行和单位绘制，不擅自套用实验专用换算；原版专用报告图继续由原版算法生成。完整预设选择、复杂 AI 图组、其余一站通系统及上传、教程、设置和 iOS 等仍待移植和验收。手机真机与更多系统/字体缩放也需继续验证。
