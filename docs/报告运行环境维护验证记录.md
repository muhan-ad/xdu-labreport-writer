# 报告运行环境维护验证记录

版本：0.40.0 / Android versionCode 43，独立开发测试包。

## 功能及平台区别

设置 → 实验资源维护提供“检查资源完整性”“检查报告运行环境”“刷新运行缓存”和结果导出。保留绿色样式，手机窄屏按钮换行，异常资源长列表可滚动。

电脑版内置修复针对用户目录中的脚本副本；手机版实验脚本直接随签名 APK 安装，没有同样的可写副本。本轮不伪造替换 APK 资源的修复功能：安装包资源损坏时列出问题，提示备份后完整覆盖安装。实验数据在线热更新和应用更新发布流程仍未迁移完成。

运行环境检查先核对整个安装资源清单，再启动实际离线报告 Worker，检查全部 28 个实验的生成脚本、字段结构、变体模板及知识资料。对 56 个 Python 源文件执行编译检查，在内存中创建 DOCX、转换公式、编码 PNG，确认文档、公式、图像组件能启动。

刷新缓存需要用户确认。原生端再次核对安装资源，只有完整结果才在 Android UI 线程调用 WebView 的资源缓存清理，然后启动全新报告 Worker 执行自检。没有调用删除测量数据、照片、报告、账号、Cookie 或本机配置的接口。此操作不是卸载、退出或重新安装应用。

## 生命周期与结果语义

- 可重复检查和刷新；取消确认不触发原生操作。
- 原生端拒绝不完整、已取消或旧任务；队列任务超时后，即使迟到运行也不会再清理缓存。
- 缓存是否已刷新、运行环境是否检查通过分别核实，运行环境失败不显示维护成功。
- 检查及运行阶段可停止，离开页面取消旧任务；刷新执行期间导航锁定，可在当前页面停止。
- 修复重复挂载未移除点击处理器的问题，重新进入后导出只执行一次。
- 非 Android 平台明确显示尚未接入，不尝试调用不存在的原生缓存接口。

## 验证

- 147 项领域测试通过。
- Android JVM 共 111 项测试（110 项业务与 1 项模板），新增 5 项缓存操作核心测试覆盖重复刷新、损坏资源拒绝、取消、旧任务、迟到任务、异常和调度失败。
- 实际离线 WASM 自检 4 项：28 实验/56 脚本/28 模板正常；缺失生成脚本、坏 Python、坏 schema、坏模板一起报告；重复实验编号拒绝；恢复后再次成功且不写报告任务或源文件。
- 实际浏览器 ReportEngine、生产 report-worker 与完整离线 WASM 3 项检查：真实自检、取消终止 Worker、停止后重新启动通过。
- 生产维护界面 10 项浏览器检查使用模拟 Android 缓存与运行结果，覆盖重复操作、取消、96 项异常列表、转义、失败不误报成功、旧进度与结果隔离、导出单次执行；320/360/390/768/1024/1280 宽度无横向溢出，已查看 320/768 截图。
- 实际主程序导航 6 项回归通过，包括维护入口及浏览器平台的禁用状态。
- 凹透镜、直螺线管、RLC 三份实际 WASM 报告生成回归通过，源文公式无未映射项；本轮没有重复验证全部实验数值和 Word/WPS 排版。
- Android 构建、96 项安装资源校验、24 项原生类定义、APK 签名和版本核对通过。

证据：`artifacts/verification/resource-runtime`、`resource-worker`、`resource-maintenance-ui`，以及 `artifacts/report-tests/resource-maintenance/wasm-results.json`。

原生 WebView 清缓存的真实手机效果尚未验收；JVM 测试验证的是调度与前置检查，浏览器测试不冒充 Android 实机缓存操作。没有安装 APK、执行真实选退课/报告上传、调用付费 API、修改电脑版源码或覆盖原安装包。
