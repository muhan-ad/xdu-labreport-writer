# 实验搭子 2.1.3

本版汇总 2.1.2 发布后的修复与功能改进。

## 新增与改进

- 主页新增学校实验系统入口，在独立的应用内窗口打开学校网站。
- 新增本地学校账号密码管理，使用 Windows 系统加密保存，填写前需确认；支持自动填充及复制账号、密码，复制内容会限时清理。
- 主页新增“实验预习及要求”入口，使用默认浏览器打开学校预习网站。
- 重新整理设置：必读公告置于首位，技能归入 AI 服务，自建变体与变体管理归入报告管理，优化检查更新页面布局。
- 进入应用后自动检查应用版本和实验数据版本更新。

## 修复

- 修复部分设置图标的绘制问题，并移除“技能”星形中的竖线。
- 改进实验表单的数据完整性校验，明确区分固定矩阵和允许部分行录入的表格。
- 改进重力加速度 T-h 曲线求交与坐标自适应处理，修复相关边界情况。
- 移除静电场模拟的坏点机制，调整绘图与计算逻辑。
- 改进内置实验资源与热更新资源的同步、来源识别及用户修改保护，提供需要用户确认的“使用内置实验修复”入口。
- 修复章节设置保存后仍读取旧内置配置的问题。

## 安装

下载 Release 中的 `labreport-setup-2.1.3.exe`，可使用同时提供的 `SHA256SUMS.txt` 核验文件。
建议关闭旧程序后，覆盖安装到原来的安装位置。用户填写的数据、报告和个人设置仍保存在用户数据目录，不会随安装包更新删除。

本次只提升应用版本；实验数据发布版本保持不变。本应用安装包未使用 Windows 数字签名。
