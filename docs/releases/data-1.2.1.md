# 实验数据 1.2.1

适用应用：2.2.0及以上；应用版本不变，无需重新下载安装包。

- 按官方预习PDF补齐第二学期薄透镜实验：表1凸透镜自准法8次焦距、表2凹透镜自准法8组位置、表3凹透镜物像法3组位置。
- 统一表单与报告中的X4～X8、u_L、u、v编号；内部旧字段保持原映射，已录入的测量值不交换、不覆盖。
- 两种自准法给出标准化处理、A/B类与合成标准不确定度；凹透镜位置差按独立位置读数传播B类不确定度。物像法只给出逐次焦距及平均值。
- 同步更新报告原理、方法、思考题、误差分析与结论，移除预先断言两法一致的文字；为现有报告预览使用兼容的等价公式写法。
- 旧数据缺少表1时保留原记录，并提示补录8次凸透镜焦距；不会用教材或测试数值补齐。

验证：新增6项独立算例与兼容性测试、完整自动验证、报告表格/原生公式检查、应用内预览截图；在未修改的已发布2.2.0中，用隔离用户目录完成签名更新包的检查、下载、应用与报告生成闭环。传输使用本地样本替身，签名校验/合并/表单/生成均执行真实代码。没有写入用户个人数据。
