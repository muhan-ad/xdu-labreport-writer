# 实验搭子 2.2.0

实验数据版本：1.2.0。请先升级应用，再检查实验数据更新。

1. 一站通接入实验与教师评价、真实余量、场次筛选、冲突确认及72小时退课校验。

2. 优化登录设置、预加载、页面切换和报告提交状态显示。

3. 新增资源完整性检查、可重复资源修复，完善异常数据恢复及清除流程。

4. 新增DeepSeek API配置教程，统一绿色输入框样式，更新使用说明及公告。

5. 修复实验参数、计算校验、下标与报告说明，实验数据更新至1.2.0；上下学期版本共用对应预习资料。

本版保留原有绿色界面与动效。试题库、仿真入口使用默认浏览器打开；账号管理不保存这两个系统的密码。

安装前请退出旧版应用。安装包不包含个人账号、个人课表或测量数据；升级保留本机用户数据。

自动校验与隔离桌面测试不包含用户真实选退课、真实报告上传及扬声器听感验收。若遇到资源缺失，请在“设置 → 检查更新 → 资源完整性检查”查看具体缺失项。

Windows安装包未购买代码签名证书，可使用同页SHA256SUMS.txt核对文件摘要。
