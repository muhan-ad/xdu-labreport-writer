# 帮助与意见反馈验证（0.33.0 预览版）

设置新增帮助与反馈卡片：使用说明、必读公告和意见反馈。帮助支持使用说明/常见问题/公告切换和当前分类搜索，常见错误采用“报错标题 + 原因和处理”折叠条目；公告保留原版四项核心内容，并明确手机版仍为开发预览。桌面特有路径和未接入的资源修复操作没有照搬成可用功能。

## 反馈

正文 5～5000 字，相关实验可不选；提交前由应用公共确认弹窗展示完整正文、所选实验、具体版本与 Android 平台。用户确认后原生构造 JSON，只有 kind/text/ts/appVersion/exp/platform；不自动读取学生资料、账号、课表、测量数据、报告或 API 配置。

沿用桌面固定腾讯云凭证服务和 COS 目的主机。原生核对单个凭证的请求 key、实际 UTF-8 大小、服务生成的 objectKey 与上传 URL 的主机/协议/端口/路径绑定；签名地址不返回网页。禁止重定向、Cookie 共享和自动重试，反馈正文不自动持久化。

取消确认不发送；取消凭证阶段不 PUT；PUT 开始后中断或响应异常提示“提交结果未确认”，正文保留，不自动重发。成功才清空正文。重复点击不并发提交，导航/返回在处理期间保留页面；离开销毁时取消并隔离旧响应。

## 验证证据

- 124 项领域测试回归通过。
- 9 项纯 JVM/本地 MockWebServer 测试通过：实际 POST/PUT 方法和字段、正文大小、Cookie/Authorization 缺失、错误凭证、跨主机/路径拒绝、响应大小、重定向不跟随、断线不重发、预先取消、凭证阶段取消及 409 不误报成功。
- 原生业务测试共 90 项通过（另有 1 项框架样例）。
- 生产反馈/帮助界面 10 项通过：短正文、确认取消、明确提交、未知结果保留、不重发、服务失败、取消、并发按钮、迟到响应和离线帮助搜索；320/360/390/768/1024/1280 无横向溢出，窄屏截图人工查看。
- 直接运行实际 src/main.ts 的应用入口，4 项检查通过：本机存储启动、设置入口、完整确认内容转义、版本/平台展示、确认期间的导航保护、取消后进入公告。见 artifacts/verification/settings-navigation-ui/。
- APK 构建通过，96 个资源及 20 项原生定义检查通过，签名与此前预览一致。

独立安装包 artifacts/preview/lab-maker-app-0.33.0-debug.apk；核对记录 verification-0.33.0.json。没有向真实服务发送反馈、贡献文件或执行官网操作；真实服务可用性、Android 实机提交以及其余贡献数据/更新维护等功能仍待验证或迁移。未覆盖固定安装包、未安装设备、未发布。
