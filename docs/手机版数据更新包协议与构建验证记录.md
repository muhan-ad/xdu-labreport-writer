# 手机版数据更新包协议与构建验证记录

本轮为在线实验数据更新的构建、验签与运行验证阶段。尚未接入应用中的下载、暂存、启用、失败回退和恢复内置入口，没有宣称在线更新已完成；现有应用测试包仍为 0.40.0。

## 为什么不能直接使用电脑版包

只读核对电脑版 `src/main/update-package.js`、`main.js` 及发布公钥。电脑版使用 Ed25519 签名、ZIP 文件清单和桌面应用版本约束。手机版同时依赖 WASM 包、录入目录、模板选择列表、实验知识及字体，不能只覆盖 Python 文件而保留另一版 UI 字段。

手机版采用独立域标记 `lab-maker-mobile-data`、协议版本和适配器版本，固定下载域名及 `/mobile-data/data-x.y.z.json` 路径。签名覆盖数据版本、最低应用版本、运行环境指纹、字段目录指纹、地址、字节数、摘要和更新说明；电脑版清单不能冒充手机版更新。

沿用现有发布 Ed25519 公钥，仅复制公开 PEM。没有读取、生成或保存正式发布私钥。测试使用进程内或浏览器内临时密钥，不能授权应用的正式更新。

## 包内容和约束

- 将全部实验脚本、模板、字段、知识和报告字体作为一组 JSON 数据包，SHA-256 绑定整个包。
- 当前 28 个实验、173 项源资源、28 份模板及字体，候选包为 2,449,068 字节；不重复携带完整 WASM/Python 依赖。
- 消费端再次验证清单签名后才核对包摘要，检查 UTF-8、资源路径、公共组件、实验归属、字段与 UI 一致性、模板列表与脚本中的模板一致性。
- 本协议第一版只支持当前录入布局和运行依赖兼容的数据更新。增加实验、改变字段或更换底层运行环境时要求先升级应用，不静默迁移或裁剪用户数据。
- 版本上下限、8 MB 包大小、说明长度、文件数量与路径、模板正文和字体编码均有限制。没有解压 ZIP 或执行下载脚本的构建动作。
- 加密签名和结构校验不证明实验算法正确；激活前还必须运行新的离线 Worker 进行实际资源检查，后续启用事务不能省略这一关。

## 本地构建

脚本：`scripts/build-mobile-data-package.mjs`。必须指定数据版本、最低应用版本和新输出目录；支持可选说明文件。默认生成明确带 `.unsigned` 文件名的清单，消费者会拒绝它。

本次仅执行：

```powershell
node scripts/build-mobile-data-package.mjs --data-version 1.0.0 --min-app-version 0.40.0 --out artifacts/data-package-candidates/1.0.0
```

`1.0.0` 是独立手机版协议的本地候选编号，不代表已经发布的数据版本，也不改写电脑版的数据版本。已有输出会被拒绝，重复执行已验证不覆盖文件。

构建工具提供可选发布签名参数，要求私钥与应用发布公钥完全匹配。本次没有传入私钥参数或签署正式包，也没有上传、更新远端 manifest 或切换任何应用的活动资源。

## 验证证据

- 154 项领域测试通过；新增 7 项覆盖完整真实资源、签名篡改、错误公钥、未签名/电脑版清单拒绝、版本与来源、运行环境及字段不兼容、字节篡改、UTF-8、目录与模板错配、缺失组件及字体。
- 真实 Chrome WebCrypto 3 项验证：用临时 Ed25519 密钥签署并验证完整 28 实验包，修改签名说明及资源字节都被拒绝；没有用模拟验签函数。
- 真实离线 WASM 3 项验证：经临时签名验证的包载入后 28 实验/56 脚本/28 模板自检通过；更新后的模板确实进入一份 Word 报告，包含 64 个可编辑公式；坏 Python 源码被运行前检查报告，临时报告任务被清理。
- TypeScript 检查通过。源码结构校验和运行自检分开测试，不将“签名正确”等同于“Python 可以执行”。
- 本轮没有改动原生 Android 功能或重打 APK，没有读取用户账号、测量数据、照片和报告。实际手机 WebView 的 Ed25519 支持、下载、断网、磁盘事务及版本回退需在后续客户端接入时验证。

证据：`artifacts/verification/data-signature-browser/results.json`、`artifacts/verification/data-package-runtime/results.json`、本地候选目录及其验证记录。
