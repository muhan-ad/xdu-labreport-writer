# 0.5.0 教师、教室与场次信息

2026-10-23。继续完整原版移植，没有将一站通读取功能作为最终完成。

## 本轮新增

- 按原版固定的 `student/expeinfo.aspx`、`student/course.aspx` 读取实验用房与教师排课。原生层只新增这两个只读查询操作，保留独立 Cookie、域名/路径限制、串行请求、失败重试与会话清除隔离。
- 支持合并单元格、嵌套表格和 ASP.NET HeaderTemplate/ItemTemplate 分离结构；借用原版保存的官网教室样本验证。实验名称先按官网明确项目名和学时后缀归一，不用静态评价猜教师。
- 教师匹配同时要求实验范围、完整时段、起止周和单双周。单行明确多教师分别展示；不一致的重叠记录显示“待核实”，不合并为臆造的多教师名单。停课行、其他实验、其他时段不参与匹配。
- 评价弹窗按已确认教师逐人展示其与当前实验明确关联的评价，姓名是普通文字。未知教师或无相关评价显示待核实/暂无评价。实验名与教师名继续采用原版分类的绿色/红色标记，正文黑色 18px。
- 登录/刷新结束前读取当前允许周场次，并补齐本页及已选实验所需元数据。逐项状态反馈；读取不完整明确提示，可主动重试。完整元数据缓存十分钟，有警告时三十秒；完整实验用房目录复用一次，切换周次不反复抓取。
- 使用官网明确日期与周次锚点推导场次日期，多个锚点不一致或无锚点时继续待核实；新增已开始、名额、已选实验、完整时段重叠和每周学时限制的显示判断。它们是前端资格显示，尚不代表原生最终提交复核已经完成。

## 验证范围

`npm.cmd test`：25 组领域测试。新增真实教室样本 18 项解析、rowspan、嵌套表所有者隔离、最新隐藏字段、查询 postback、歧义选项、教师完整范围/时段/单双周、多教师和歧义记录、锚点一致性、完整时段冲突与学时资格。

Node HTML 测试使用开发依赖 [LinkeDOM](https://github.com/WebReflection/linkedom)，不打入 APK；其结果另由真实 Android WebView 模拟官网测试补充，不能替代浏览器 DOM 验证。

`node scripts/smoke-portal-android.mjs`：真实 APK / Android 16 模拟器、本机模拟官网，覆盖真实官网教室 HTML、原生只读元数据查询、多教师显示与对应评价、跨周教师变化、单双周、未知教师、歧义记录、503 部分失败、重试、缓存、401 会话失效以及旧有 Cookie/ASP.NET/串行/清除/窄屏回归。

证据：`artifacts/verification/portal-native.json`、`portal-teacher-review.png`、`portal-availability.png`、`portal-small.png`。截图为模拟账号/排课，不是实际学校账号验收。
