# 音效资源轻量化（0.51.0）

检查打包资源后，保留报告、科学计算和绘图运行库，本轮精简问答音效的未使用录音。原录音共 39.265 秒，实际只抽取 25 个键盘片段；以前仍需完整解码录音。

现在只打包原录音中的这 25 段，按原采样率 44.1 kHz、立体声保存为标准 PCM16 WAV，在片段之间留 20 ms 间隔。保持原片段选择、音量/淡出、随机变化、节流、页面退出释放及后台停止逻辑。没有改用合成音效。

## 测量结果

| 项目 | 0.50.0 | 0.51.0 |
| --- | ---: | ---: |
| 音频文件 | 1,941,031 字节 | 905,188 字节 |
| 解码时长 | 39.2653 秒 | 5.1312 秒 |
| 44.1 kHz 解码缓冲 | 13,852,808 字节 | 1,810,288 字节 |
| 完整 APK | 71,742,101 字节 | 70,705,925 字节 |

安装包实际减少 1,036,176 字节，约 1.04 MB。此处内存差值仅指音效解码缓冲，不代表整个应用进程的内存测量；手机音频设备的实际采样率可能不同。整体 Pyodide、计算与绘图库仍占主要体积，未为减包而删除离线功能所需资源。

## 可追溯处理

原录音和原配置保留在开发目录 `scripts/assets/guide-audio`，不进入安装包。`scripts/prepare-keyboard-sprite.mjs` 先核对原文件固定 SHA-256，在本机浏览器离线解码、提取片段，再生成运行资源。它会重新解码输出 WAV，逐个对照全部保留采样点；本次最大绝对采样差为 0.0000439883，低于 2/32768 的 PCM16 量化容差。这是有界量化转换，不声称与原浮点波形逐位一致。

MIT 授权、作者和源项目提交信息保留在安装包的 `guide-audio/LICENSE.txt`、`SOURCE.txt`；来源声明注明了手机版裁剪处理。生成结果和配置、授权文件继续由构建前 SHA-256 校验和最终安装包完整性核对覆盖。
