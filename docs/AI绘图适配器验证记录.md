# AI 绘图适配器（内部开发阶段）

原版 AI 绘图的 `DATA` / `DATA_FILE` / `OUT_DIR` / `save` / `caption` 接口已建立本机 WASM 适配器，并加入生成绘图消息、完整绘图技能、实验知识、字段单位及可选本次计算结果的请求构造。本文记录最初的内部适配器验证；后续已在源码接入页面、采用与插图，见 [页面与插图验证](AI绘图页面与插图验证记录.md)，Android 原生联动仍待验收。

## 已完成

- 使用当前输入副本执行，避免绘图代码改动原始测量数据。仅收集 `fig1.png` 和对应图注；输出先核对 PNG、尺寸、体积，再返回结果。
- 尺寸最多 10×7 英寸，dpi 在 50～200；限制图注、代码和日志长度。读取 `DATA_FILE` 时返回当前数据的内存副本，不提供宿主文件访问。
- 请求只带启用的绘图技能，不混入报告技能；知识、单位、原始数值不截断。注明显示最多五位有效数字，计算保留精度。
- 目前支持已打包的 numpy、matplotlib、math、statistics 和 json；原版允许的 scipy、pandas 等尚未配齐，不能宣称支持全部原版绘图代码。
- 开发适配器只在本机 WASM 测试中调用。主 Worker 没有开放执行任意绘图代码的消息分支，`Reports` 没有 AI 绘图按钮。

## 验证

`node scripts/test-ai-plot-runtime.mjs`：3 个正常场景、15 个错误场景通过。包括直接读 DATA、读 DATA_FILE、失败后再次成功，以及不支持的模块、JS 接口、私有属性、外部文件、直接文件接口、路径越界、多图、超尺寸、超 dpi、无图注、无图、语法错误、缺少数据、超长代码和日志。失败后临时任务目录已清理。

`node --test tests/*.test.mjs`：63 项通过。新增检查完整绘图技能/知识、计算绑定、实际单位/零值、代码提取及响应长度限制。

`npm run build`：类型检查、前端构建和 38 项离线运行资源校验通过。只新增一个较小的 Python 适配器，不新增运行库依赖。

样图 `artifacts/verification/ai-plot-runtime/solenoid.png` 已人工查看：负位置使用左侧数据，正位置使用右侧数据；下标、cm/mm 单位正常；没有额外图例。图注单独随结果返回，供后续报告排版，不嵌进图内。样图使用模拟测量数据。
