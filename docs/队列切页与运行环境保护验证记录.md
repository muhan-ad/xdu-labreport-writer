# 队列切页与运行环境保护（0.68.0 / Android 71）

## 原版对照与行为

原版批量队列可离开面板浏览，再通过队列入口返回。手机版此前把整条队列运行期计入页面切换阻塞，无法浏览其他内容。本轮将队列任务与其页面生命周期分开：切页只解除界面监听，任务、顺序、暂停状态、选择和搜索条件保留。

其他页面显示绿色队列返回入口，包括完成数、暂停/停止/待确认状态；完成后仍能返回查看结果，清除队列记录后入口消失。实验页重新绘制时同样保留入口。本机数据正在保存或清理时仍须等待操作结束后离开。

队列运行及暂停期间占用报告运行环境。其专用计算引擎仍可执行，前台报告、计算上下文、手动图表和独立 AI 绘图会在创建额外运行环境前被拒绝；异步读取资源后再次检查。资源维护、应用/实验数据更新、开发者批量数据操作及彩蛋页面需先停止队列，避免运行时重载或叠加较重的效果。已保存报告浏览、学校页面、帮助、设置等可正常进入。

生成前思考题若出现需留空确认的答案，队列显示“待确认”，回到队列后显式选择“留空并继续”或“停止队列”。浏览其他页面时不会用全局弹窗替换用户正在处理的对话框。提示正文按纯文本转义；停止信号能结束待确认请求，单独取消该任务仍可继续后续任务。现有数据/配置快照复核保留，不允许借切页采用过期输入。

这是应用内切页后继续运行，没有新增 Android 前台服务，也不保证应用被系统挂起或杀进程后仍继续执行。原生返回键已接回既有页面返回逻辑，实际设备体验仍需验收。

## 验证

- 领域测试共 310 项通过：新增运行环境占用/释放、前台读资源前拒绝、异步晚到拒绝、队列专用引擎、重载路由边界，以及思考题确认收到同一停止信号。
- `test-queue-navigation-browser.mjs` 四项组件组合：切页完成当前并保持暂停/搜索/选择、占用保持至队列结束、独立绘图被挡在创建 iframe 前、提示跨页保留/转义/显式继续、停止与单项取消；四种宽度提示截图留档。
- `test-queue-navigation-production-browser.mjs` 五项实际压缩应用组合：真实本机 Worker 队列离页后继续，返回恢复并续跑；前台尝试生成报告和图表没有创建新 Worker；三个任务创建 Worker 共 3 次、最终活动数 0、最大同时活动数 1；三份报告文件可读。还检查非队列实验清理后的页面重绘保留返回入口，五尺寸无横向溢出。
- 生产测试曾在数据清理完成前点击返回，被现有保存保护拦住；测试改为等待明确的清理完成状态，没有放松应用保护。
- 既有队列界面 12 项、生成前思考题组件 8 项、设置导航 16 项通过。实际 WASM 自定义思考题队列 28 实验通过：先隔离一份不完整数据，再只重试该项，28 次生成、最大并行数 1，逐份核对自定义答案及报告回读。模型回答使用模拟数据，真实 API 调用为零。
- Android JVM 134 项零失败，构建成功。125 个资源 / 95,537,580 字节、88 个 Web 文件完整，30 个原生定义 / 11 个 DEX 核对通过。

Worker 数量是测试中的运行环境并行证据，不是整机内存、启动速度或手机后台性能实测。本轮未安装到设备、请求付费服务、执行学校写操作或发布；新包独立保存，不覆盖旧包。
