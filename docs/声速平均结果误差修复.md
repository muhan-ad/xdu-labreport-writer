# 声速平均结果误差修复

0.94.0 修正空气和水中声速报告结论的平均声速相对误差：先取两种方法测得声速的算术平均，再将该平均值与参考值比较。此前程序使用两种方法各自的绝对相对误差的算术平均；两者是不同量。例如相对于同一参考值分别偏低 10% 和偏高 10% 时，平均声速的相对误差为 0%，而两次误差的平均为 10%。单种方法的声速及其相对误差计算未改。

程序此前将两种方法的不确定度简单取平均，作为 `u_v_avg`；由于两种方法使用同一频率和仪器，相关性无法凭现有数据确定，该数不再提供为平均声速的不确定度，也不传给 AI 计算上下文。内置报告没有使用该字段；如果用户自定义变体曾引用 `u_v_avg`，需要移除该占位符或另行确定合适的评定方法，否则会提示缺少字段，不会给出未经核实的数字。本次未改动各方法各自的仪器限差与不确定度模型，其口径仍待核实。

电脑 Python 和 WebAssembly 中，对空气／水中、两种位相间隔及相反／同向偏差共 16 项独立对照通过；四份 Word 结论检查通过。模拟器隔离测试包实际导入数据并生成两份报告，回读确认结论数值；旧实验数据包缺少修正标记时会提示恢复内置数据或更新数据包。375 项领域测试、Android 构建及 28 份离线报告回归通过。旧报告不会自动改变，需要重新生成；桌面版未修改。

模拟器更新前备份，217 个应用数据文件安装前后内容一致；iOS 共享资源已同步，未构建或设备测试。测试均为虚构数据，未执行真实学校选退课、上传或付费 API 请求。证据：`artifacts/science-audit/sound-average-error/results.json`、`artifacts/report-tests/sound-average-error/results.json`、`artifacts/verification/native-sound-average-1793191087524/results.json`、`artifacts/verification/emulator-update-0.94.0/results.json`、`artifacts/verification/build-0.94.0.log`。
