# 全局知识库限定开关移植验证

本轮补齐原版 `kbOnly`：默认开启，在实验报告的 AI 页面显示“限定知识库（全部实验）”。设置全局保存，不随实验切换，也不归入学校登录会话。每个实验的写作风格和自定义要求仍独立保存；恢复本实验要求不会重置全局知识库选择。

关闭后，手动思考题、生成前答题、单章与批量润色、绘图及绘图修复不再读取教材知识，也不再发送“只限教材”段落。开启时仍核对当前实验的完整知识，缺失或不匹配会阻止请求。开关仅控制教材限定，不放宽真实数据来源、本机计算结果绑定、数值导入核对、润色公式逐字保留或绘图隔离限制。

全局偏好使用 `ai-knowledge-policy-a/b` 两份带摘要的存储。旧安装没有该记录时只返回默认开启，不作迁移写入。保存先读取现有修订号，再保存两份并回读；新建 Repository 后直接保存也不会让旧的较高修订副本重新生效。一份损坏可从另一份恢复，两份损坏拒绝静默改用默认值或覆盖文件。
