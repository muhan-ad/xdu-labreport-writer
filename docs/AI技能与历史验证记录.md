# AI 技能与历史（0.15.0 开发中）

本轮源码接入设置中的技能管理、完整 Markdown 正文、启停/删除/恢复内置技能，以及按实验保存的问答和润色历史。安装包交付仍为 0.14.0；0.15.0 尚未完成 Android 界面与持久化联动验收，不作为已交付版本。

## 行为

- 四份内置技能沿用桌面源码的完整正文。报告请求仅注入启用的报告技能；绘图技能保留独立范围，尚未接入 AI 绘图请求。
- 自定义文件只读取 Markdown，单文件最多 64 KB；按范围与正文去重，重复导入保留既有启停状态。
- 问答与润色结果按实验分记录保存，目录每页十条；历史保留原文、题目、结果和数据快照。数据不一致时禁止导入。
- 编辑历史结果后导入会另存一条记录；删除旧记录只清除仍关联该记录的导入内容，后来导入的版本与其他章节保留。
- 清空历史能够处理损坏目录及孤立文件，仅清理当前实验的历史文件。测量数据、原始照片、全局技能和其他实验不在删除范围内。
- 删除历史不会改写已生成的 Word，需重新生成报告。清除 AI 导入内容保留历史。
- 保存期间阻止重复操作；先保存配置再更新页面内存。存储失败不显示清除成功。

## 已验证

`node --test tests/*.test.mjs`：61 项通过。新增验证覆盖完整技能正文、报告/绘图范围隔离、关闭状态、重复导入、持久化与单副本恢复、跨实验历史隔离、损坏目录清空、删除旧历史保留新导入内容、选定章节删除、旧版无关联内容保留、排队旧写入失效及清空后的重新保存。

后续接入了原版 28 份 `rag/原理.md`，与桌面文件逐一核对（只归一化 BOM/换行），没有另存重复知识文件；读取复用既有报告源码包，并核对清单字节数和 SHA-256。缓存只保留约 2.5 万字的知识，不长期保留整份 Python 源码包。失败可重试，单个实验知识缺失不阻断其他完整实验，不以别名借用知识。

问答/润色请求带入完整知识依据、字段标签、单位及矩阵行列说明；明确知识只供原理参考，不以教材示例代替用户测量。空值仍为空，零值和原始精度保留；无效数字在请求前提示。新增测试验证 28 个实验的字段值/单位/行列配对、完整文本不截断、缓存合并读取、校验失败、缺失与修复重试、不同实验隔离。没有调用真实模型来评估回答质量。

`npm run build`：类型检查、前端构建及 37 项离线报告运行资源校验通过。

`node scripts/test-ai-history-runtime.mjs`：本机 Node/WASM 离线引擎生成 12 份模拟数据报告。凹透镜、RLC、直螺线管三个实验分别验证当前导入、删除无关联旧历史、只删除当前问答、清空全部关联导入四种情况。核对问答与润色标记只出现一次或完全移除、删除旧历史不改变报告正文、可编辑 OMML 公式保留。

报告与机器结果：`artifacts/report-tests/ai-history/`。这些报告仅为开发测试数据，不用于提交。
