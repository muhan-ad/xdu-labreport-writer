## 测试边界

没有 Android 真机；没有在 macOS/iPhone 编译测试。照片测试通过构造本地 File 走应用实际处理流程，覆盖签名检查、原生写入和 WebView 图片读取；尚未验收各品牌手机的系统照片选择器。导出验证了实际缓存 JSON 和系统分享面板，未选择发送对象。

首次模拟器冷启动曾出现系统级 System UI isn't responding 弹窗，遮挡首次截图并拦截返回；等待恢复系统后重新完整运行通过。不是用首次失败截图当作通过证据。构建有 SDK XML/flatDir 工具警告，没有编译错误。

报告计算、公式、Word/PDF、图表、官网会话、选退课、上传和 AI 本次未实现，也未据此声称验证。
