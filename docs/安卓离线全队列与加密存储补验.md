## 断网、系统返回与全部报告

实际关闭 emulator-5560 的 Wi-Fi 和移动数据，并核对系统没有活动默认网络。重载安装包内应用后导入隔离样本，从实际队列页面连续生成全部 28 个实验。生成过程中按系统返回回到首页、再次返回最小化，约两秒后恢复前台，返回同一进程和原队列。

28 份报告全部完成，本轮约 53.1 秒（包含返回/恢复操作），最大并行 Worker 为 1，最终活动数为 0。对 Android 实际双副本元数据及对应 Word 文件回读，ZIP CRC、正文 XML、学生信息、1,011 条 OMML 公式和 20 张内嵌 PNG 的关系/内容核对通过。

28 次内存采样的作业目录数均为 0，WASM 线性内存最高 187,695,104 字节（179 MiB）。此数据不是应用总内存；不作为真机内存、长期后台或系统强杀恢复结论。报告文件检查也不等于 Word/WPS 分页视觉验收或所有不确定度分量的科学验证。

网络恢复至测试前 Wi-Fi/移动数据均启用；隔离测试目录全部清除，原 209 个数据文件和 3 份非 WebView 配置摘要一致。

证据：artifacts/verification/native-queue-runtime-0.71.0-1793079389700/，包含 results.json、docx-verification.json、network-restoration.json、data-preservation.json 和 28 个样本报告。

## 加密配置的实际设备验证

新增 acceptance 构建类型，使用 com.labmaker.app.acceptance 独立包名、UID、存储和 Android Keystore。界面系统名称标为“实验搭子·本地验收”，与交付 debug/release 包分开。安装前确认该包不存在，重启只终止这个测试包，结束后卸载它，原应用进程保持不变。测试桥接拒绝模型请求和官网操作。

用虚构密钥和虚构账号通过五项检查：

1. API 配置真实加密落盘，同一配置重复保存的密文不同；密文文件不含测试密钥、模型和地址。识图继承问答配置正常，返回状态不泄露密钥。
2. 选课、报告、教务三类账号均真实加密保存，列表不返回密码；账号文件不含测试账号、密码或备注明文。
3. 真实进程重启后，可恢复 API 配置、识图模型和三类账号；账号身份不变。
4. 仅篡改测试包的认证密文后，API 返回 SECRET_READ；受损账号标为锁定，其他两个正常账号保持可用和可见。
5. 显式清除/重置后可以重新保存，重建的加密配置经再次进程重启仍可读取。

共三次测试包进程重启；主应用本轮进程未终止，数据和配置全部一致。未验证整机重启、密钥跨设备迁移或真实服务。

证据：artifacts/verification/native-secret-storage-1793080084001/。
