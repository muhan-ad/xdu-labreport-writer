# 0.8.0 实验筛选与候选目录

本轮继续原版功能移植，不宣称总目标完成；试题库、仿真仍明确排除。

## 行为

- 开始选课增加“实验筛选”及启用条件数量、本周名称搜索和显示场次数。筛选只隐藏当前周卡片，保留卡片的原始场次索引，评价和选课仍引用原始场次，不过滤后台选课资格或我的课表。
- 已接入隐藏已选/实验冲突、只看推荐实验、只看推荐老师、指定实验多选和指定老师多选。不同条件取交集，多选内部取并集；使用明确实验别名，混合/中性/未知不算推荐，未知教师不自动满足教师条件。
- 教务尚未接入，所以教务冲突选项明确标记未校验并禁用；不会把未校验当作正常无冲突。未知的实验冲突也不伪造为“已冲突”，卡片保留原有时间待核实及资格提示。
- 草稿只有“应用”才生效，取消/关闭丢弃；多选页支持搜索、全选当前搜索、清空、确认和取消。空的已启用指定条件拒绝应用。恢复默认仍需应用。
- 多选目录串行读取官网允许的本周及以后周次，使用既有 60 秒场次缓存和教师元数据；共用一次在途扫描，查询之间让主动操作进入既有串行队列，不增加并发。缓存先显示，读取失败可重试并标记未完整获取。
- 候选不受当前筛选影响，包含已满、冲突及已选未来场次；已选场次从官网已选课表补入，避免余量接口不再列出它们而漏项。日期无法核实的场次不冒充未来场次，目录报告待核实。
- 实验卡片逐位配对教师和简写时间；教师卡片逐个配对实验与时间；重复周次的相同时间合并。仅从官网明确匹配结果建立教师，不根据静态评价推断授课关系。已有勾选项未在部分目录中取得时保留并明确标记。
- 按学校账号 SHA-256 分开保存到应用私有 filters-<hash>-a/b.json。配置双副本校验，一份损坏可回退，两份损坏要求明确恢复默认；清除登录会话保留偏好。此处不存密码或登录 Cookie。
- 背景元数据更新只更新教师/教室及卡片可见性；搜索不重建卡片和输入框。换账号、清除会话、离开页面或官网快照变化后丢弃旧扫描结果。

## 冷启动问题

连续回归发现：启动读取本机记录期间，hashchange 可以提前触发一次路由，而 start 完成后会再路由一次，可能重新挂载正在登录的页面。现加入启动完成门槛，启动期间只记录最新地址，初始化完成后进入该页。没有用增加测试延时替代此修复。

- 33 项领域测试通过，含条件交集/多选并集、别名、已选/时间冲突、未知教师和混合评价、空选择、教务未连接、账号隔离、配置重开、单副本回退和明确损坏恢复。

- 14 项原生读取回归与 13 项基础表单/保存/导出回归通过。原生网络及事务单测继续通过；未变更报告算法和 AI 请求路径，不把历史验证当作本轮重新执行。
