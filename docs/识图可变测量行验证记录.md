# 识图可变测量行验证记录

版本：0.37.0（Android versionCode 40），独立开发测试包。

## 问题与修改

凸透镜共轭法的表格容量为 8 行，RLC 两个表格的容量为 13 行；目录明确设置 `variableRows`，允许按实际测量行数填写。此前识图解析仍要求返回全部容量行数，会拒绝有效的部分测量行。

现在仅对显式 `variableRows` 且非 `colsFrom` 的表格接受 1 至容量上限的实际行数，编辑容器剩余位置填 null，表示空白，不生成数值。超容量、错误列数仍拒绝；固定仪器组数和测量点与各组数据的配对约束保持生效。

识图提示词区分定长数组、可变测点数组、可变测量行和关联列长度，要求按照片实际记录输出。识图可先核对不足最低测量次数的结果；生成报告前仍要求实验规定的最低有效行数。

连续识别中，未识别单元格不清除已有值；仅填空白不替换已有读数。需要丢弃旧记录时使用实验页清除数据。此改动不增加多照片功能，不修改桌面原版。
