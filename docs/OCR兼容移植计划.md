## 验收标准

1. 未配置识图凭证时给出明确提示，不把密钥保存到网页存储或源码。
2. 无 schema 的实验不显示可执行的识别流程；有 schema 时字段由 schema 动态生成。
3. 识别结果不会直接保存，必须经过核对并点击“填入所选”，再由现有“保存修改”写入数据。
4. 勾选“只填空字段”时不得覆盖已有数据。
5. 未提供原始照片或照片无法插入时，报告继续生成并保留原占位文字。
6. 实验资源更新不得覆盖用户保存的照片、数据、变体和润色内容。
7. 当前主应用的测试与桌面端启动检查继续通过。
