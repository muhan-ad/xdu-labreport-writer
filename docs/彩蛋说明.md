# 彩蛋说明（「请勿点击」效果池）

面向维护者：这些彩蛋都藏在 **设置 → 请勿点击** 里，代码集中在三个文件，改起来不需要碰主流程。

## 一、怎么触发

1. 设置 →「请勿点击」→ 点那个红色大按钮；
2. 走完三步确认（`我不听！` → `继续` → `继续`，少一步都不出效果）；
3. 之后按权重从效果池里随机抽一个（不与上一次重复）；**第一次点永远是那段经典音频**。

## 二、文件分工

| 文件 | 干什么 |
| --- | --- |
| `src/danger-effects.js` | 效果池本体（20 个效果）+ runner（看门狗、清理、Esc 中断、计数） |
| `src/index.html` | 入口按钮与各弹窗的 DOM |

## 三、加一个新效果

在 `src/danger-effects.js` 的 `POOL` 里加一个对象即可：

```js
{
  id: 'my-effect', name: '中文名', weight: 3, maxMs: 12000,
  async run(h) {
    const el = h.layer({ pointer: false });     // 全屏覆盖层，结束时自动移除
    h.caption('底部灰黑长圆提示条', 2600);        // 需要提示就用它（别用应用的右上角 toast）
    await h.sleep(2000);                        // 可被 Esc / 看门狗提前打断
    // 需要自己收尾的东西（定时器、音频、样式）：
    // h.onCleanup(() => { ... });              // 一定会被执行
  },
}
```

三条纪律（改这个文件时守住）：

1. **不碰用户数据**：不写 `data.json` / 报告 / 实验目录；唯一允许的写入是 `localStorage` 里的彩蛋统计；
2. **一定能恢复**：`maxMs` 看门狗 + runner 统一清理，不允许出现"卡在特效里出不来"；
3. **窗口级操作要兜底**：涉及窗口的效果只走 `hide` / `setBounds`，主进程侧保证复原
   （见 `main.js` 的 `danger-window-shake` / `danger-window-vanish`；窗口最小化时一律不打扰用户）。

不进随机池的效果：把 `weight` 设为 `0`（原神 `genshin` 就是这样），
只能由代码显式 `dangerEffects.run('<id>')` 触发。

## 四、验收

```bash
npx electron . --remote-debugging-port=9222 --user-data-dir=<临时目录>
node tests/cdp_danger_effects.js 9222      # 确认流程 + 千分之一闸门 + 20 个效果（含文案断言）
node tests/cdp_settings_nav.js 9222        # 设置导航不裁切（加了导航项后必跑）
```

`cdp_danger_effects.js` 会在播放过程中采样页面文本：`FORBIDDEN` 里列的是"按要求删掉的文案"
（出现即失败），`REQUIRED` 里是"必须出现的文案"（可要求只在后半程出现）；喷发那项还断言
粒子数 ≥240 且互不重叠（<1.5px），按钮逃跑用 CDP 真实鼠标事件验证会躲。
