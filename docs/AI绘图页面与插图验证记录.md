# AI 绘图页面与报告插图（0.15.0 开发中）

源码已在报告的“图表”页接入 AI 绘图：需求→生成代码→查看/编辑代码→独立运行预览→核对图注与插入位置→采用。手动 XY 图表配置收进折叠区，沿用绿色按钮和圆角输入框。图表可点开放大、按原图滚动查看或适应宽度，返回键优先关闭放大预览。

## 数据与文件

- 生成代码使用启用的绘图技能、对应实验知识、字段单位和可用的本次计算结果。没有 API Key 时先提示配置，不自动调用模型或执行重试。
- 修改代码后必须重新预览。生成/预览/采用均核对数据快照，停止后迟到的模型响应不能采用。关闭页面会取消计算并回收图像 URL。
- 采用时保存带 SHA-256 的 PNG，配置包含实验标识、数据快照哈希、需求、代码、图注、目标章节及插入开关。两份恢复配置都写好后才清理旧 PNG；不能确认保存时保留文件，不误报成功。
- 重新打开会读取已采用图表，不重新请求模型。移除图表保留测量、原始照片和已经生成的报告；重新生成后更新 Word。实验全量清除会清理对应图表缓存。
- 普通报告引擎**只接收已核对 PNG、哈希、图注和章节**，不重新执行模型代码。原始 PNG 通过校验后按章节插入，保留原有公式和内置图。错误章节、损坏图像或校验失败会报错，不悄悄生成缺图报告。
- 修复报告失败清理顺序：先退出临时工作目录再删除，避免 WASM 下遗留空任务目录。

## 验证

`node --test tests/*.test.mjs`：66 项领域测试通过。新增采用图表配置校验、持久化、图像身份、数据哈希与跨实验拒绝。

`node scripts/test-ai-plot-browser.mjs --ui`：生产 `AIPlotView` 组件在专用桌面 Chrome 中的 12 项检查通过。模型回答为模拟值，图像预览实际执行隔离 WASM；文件接口为内存替身，配置使用真实 Repository 的双副本逻辑。覆盖生成/预览/采用、保存失败重试、重开不调用模型、移除取消、数据变化拦截、迟到响应、代码改动、图注转义和放大预览。

布局检查采用真实 CSS 设备宽度（断言 `innerWidth` 等于设定值），覆盖 320×640、360×800、390×844、768×1024、1024×768、1280×800，均无横向溢出。额外用实际 `.report-sheet` / `.report-body` 样式包装组件，在 320 像素下检查滚动、底部按钮及嵌套图表预览。截图等待既有入场动画完成，没有关闭应用动效。

已人工查看 360 宽组件图、768 宽组件图，以及 320 宽报告弹窗上下部分，输入框圆角/绿色风格、图注下标、按钮和插入位置正常。证据见 `artifacts/verification/ai-plot-ui/`。

`node scripts/test-ai-plot-report-runtime.mjs`：凹透镜、RLC、直螺线管三个实验的 Word 插图通过；核对原始 PNG 哈希、图注只出现一次、OMML 公式保留，以及校验错误、错误章节、空图注和非法 PNG 四类失败清理。故意传入会抛异常的顶层模型代码，报告仍正常生成，确认此报告路径没有执行它。证据见 `artifacts/verification/ai-plot-report/`。

`node scripts/test-report-runtime.mjs --all`：28 个实验完整报告回归通过。类型检查、前端构建及 38 项离线资源校验通过。

## 尚未验收

组件测试不能代替整个 Reports 与 Android 原生插件的联动；实际私有文件写入、损坏文件恢复、应用重启、设备内存及 Android/iOS 真机仍待验收。未使用付费模型或真实上传。安装包仍为已交付的 0.14.0，没有把源码版本号当作新包验收结果。

原版全部预设、更多科学绘图库、绘图代码历史和自动纠错策略仍需继续核对。整体移植目标保持不变，试题库与仿真系统不纳入迁移。
