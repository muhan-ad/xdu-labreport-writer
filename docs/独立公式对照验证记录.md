# 独立公式对照与 RLC 内部精度修复（0.47.0）

本轮建立开发用的独立公式核对入口，不增加手机端运行依赖。仅使用模拟测量样本，不访问学校账号、不选退课、不上传、不调用付费模型。

## 发现与修复

独立对照发现 RLC 脚本将理论谐振频率先保留三位小数，再计算相对误差和品质因数。样本中未舍入的理论频率为 5.032921210448703 kHz，原先计算链使用 5.033 kHz；相对误差由 0.45698390621896634% 修正为 0.45542557672305767%，品质因数由 2.9910049867315296 修正为 2.9909581637748768。

这属于中间量提前舍入造成的小偏差，不是本次发现的数量级错误。移动端打包时对已核对的公式行作精确替换，内部保留浮点精度，原有报告显示格式保留；遇到未知脚本结构会停止同步以便重新核对。桌面原目录未修改。

修复前证据保存在 `artifacts/science-audit/before-rlc-fix.json`：79 项检查中 3 项失败，均来自同一 RLC 原因。不得将它们描述为三个独立物理问题。

## 独立性与边界

`scripts/science/independent_formulas.py` 仅使用标准库、显式公式和测量输入；不导入生成脚本、计算上下文或其结果。覆盖 28 个实验、79 项选定关键量，明确记录输出单位及换算公式。电脑 Python 和手机采用的 WebAssembly 环境分别执行正式计算，再与独立预期比较。

这不是全部科学正确性的证明。尚未覆盖全部不确定度、异常输入、拟合分支、所有图形与 Word/WPS 渲染；样本通过也不能证明某份实测数据合理。电脑与 WebAssembly 运行同一算法本身不构成独立物理对照，独立性来自另写的公式参照。

参照建立时核对了实验方法：偏振第一学期扣暗值、第二学期排除 360° 闭合点；气体图解法采用端点及 SI 精确气体常数；RLC 品质因数沿用现有理论频率除以半功率带宽的定义。这些是对参照口径的澄清，未当作产品缺陷修改算法。

## 可重复验证

激活本地工具后运行 `npm run test:science`。其他机器可通过 `LAB_MAKER_TEST_PYTHON` 指定已安装报告依赖的 Python；默认复用本机便携解释器，只在移动项目与临时目录内写文件。

结果：

- 独立参照自检 6 项：手算线性/方程组、RLC 单位换算、扭摆直径四次方、螺线管两种电流区分、电容/电阻反向缩放、体积三次方缩放。
- 电脑 Python：28 个实验，79/79 项通过。
- WebAssembly：28 个实验，79/79 项通过。
- 故意将螺线管理论磁场放大 1000 倍，检查器以失败退出，且准确定位这一项。该文件明确标为故意错误，不能作为正式结果。
- 220 项逻辑测试通过，包含 RLC 替换的精确性、幂等性、未知结构拒绝与实际打包源码核对。
- 28 份实际 WebAssembly 离线报告生成通过；不等于全部页面已人工渲染验收。

测试结果分别保存在 `artifacts/science-audit/python-independent-results.json`、`wasm-independent-results.json`、`rejected-unit-error.json` 及 `artifacts/report-tests/wasm-results.json`。检查器每次写出预期、实际、单位、公式、误差与容差，便于追溯。
