# 0.11.0 报告上传

实验报告页新增“上传报告”，进入一站通报告系统后查询各页，按明确实验名称及别名匹配。只有唯一对应记录才自动准备；有多条场次时由用户从官网报告列表选择。尚未登录时先手动登录，不保存学校密码。

准备阶段核对本机报告数据快照、学号与报告账号、实验名称、官网允许上传状态及成绩。仅接受本应用私有目录内对应实验及生成代次的 Word 文件。此时复制到私有缓存并计算 SHA-256，不向官网传送文件。已有成绩、来源不明或状态待核实均停止。

最终确认使用绿色大弹窗，展示官网场次和本机学生/日期、文件名及大小，提供取消、预览、外部打开、继续上传。预览与上传共用同一不可变副本；页内使用原有沙箱 Word 查看器，超过 32 MB 提供外部打开。两分钟确认票据按原生单调时钟到期，一次使用，取消即清理；提交时重新读取官网资格和校验文件。

## 发送与结果核对

网页文件提交在文件选择事件前接管，支持 fetch、XHR、HTML 表单/iframe。截获实际表单字段后，由原生 HTTP 客户端发送附件，关闭自动重试和重定向；重复网络尝试被拦截。响应交还官网页面处理，随后重新读取对应报告记录。只有官网明确成功信息与回读状态均确认才提示成功。接收后断线、响应异常或回读失败提示结果待核实，不自动补发。

测试曾发现浏览器 fetch 在响应丢失后重复发送同一文件，因此采用原生单次发送，并按模拟服务器实际接收次数验收。该测试没有降低为仅检查按钮点击次数。

## 验证范围

- 43 项领域测试：新增跨页唯一匹配、别名、成绩限制、歧义及页码变化。
- 25 项业务 Java 单测（另有 1 项模板示例）：含报告副本、最终确认、精确到期、文件变化、账号会话变化、文件名/体积限制；HTTP 表单字段与 Cookie、断线一次发送、307 不重发及来源校验。
- Android 实际 APK 连接本机模拟报告服务：fetch、XHR、表单/iframe 三种传输；确认预览与上传内容哈希一致，取消无文件请求，未确认/重复点击/重放/过期不提交，确认后新增成绩停止提交，接收文件后断线不重发，登录失效、密码错误、清除期间旧响应隔离。
- 表单专项同时覆盖生成报告直达路由跨页匹配，以及错误学号、外部文件和错误实验的原生拒绝。
- 320、360、430、768、1024、1280 CSS px 弹窗与列表检查；人工查看 320 手机和 768 平板预览截图，底部操作可见，无横向溢出。预览夹具包含明确测试标记，不是真实报告。

## 尚未验证及后续

实际学校选课登录及课表只读复验成功，见 school-authenticated-readonly-latest.json；这不证明报告网站已真实登录。此前携带真实凭据的报告登录测试被自动审批拒绝，未执行，未绕过。报告上传仅在本机模拟服务验证，真实报告登录、学校服务端上传结果及各品牌系统文件选择器/外部 Word、iOS 和物理手机仍待验收。没有执行真实选课、退课、报告上传、付费 API 或云端发布。

官网报告预览、外部手选报告文件、完整账号管理、教务冲突及其余原版功能继续迁移，不能称为全功能完成。
