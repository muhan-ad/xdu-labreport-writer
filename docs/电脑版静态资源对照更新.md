# 电脑版静态资源对照更新

0.119.0 重新核对电脑版与手机归档的 28 个实验、196 个字段、28 套变体以及 173 份静态脚本和资料。164 份文本一致，其余 9 份与明确记录的手机版补丁一致；没有发现补丁之外的静态资源差异。

原对照工具只以电脑版原始 schema 和变体比较手机版目录，因此把水中声速的 10/12 点适配、低电阻的报告变体修正误报为不一致。现在工具同时记录电脑版原始比较结果，并以经过明确补丁的内容核对手机版，仍检查原始 schema 的 SHA-256 以及每份归档文件。

隔离副本验证：基线通过，分别篡改低电阻变体和水中声速 schema 时检查失败，恢复后通过；最后对实际电脑版静态文件只读核对通过。工具不读取电脑端账号和测量数据。对照不证明算法、官网通信或真机体验完全一致；本次仅修改检查工具和记录，没有修改应用代码或安装包。

证据：`artifacts/verification/desktop-parity/results.json` 和 `mutation-tests.json`，以及 `scripts/audit-desktop-parity.mjs`、`scripts/test-desktop-parity-audit.mjs`。
