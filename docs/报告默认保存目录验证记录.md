# 报告默认保存目录（0.21.0 独立测试版）

报告页和报告管理提供“保存报告”，保留独立“分享”按钮。首次保存选择系统文件夹；设置 → 默认保存目录可更换、清除。取消选择保留原目录；清除仅移除目录设置及长期授权，已导出的文件保留。应用私有报告、测量数据和照片不变。

Android 使用系统 ACTION_OPEN_DOCUMENT_TREE。长期读写授权由系统管理，应用只在私有 no-backup 目录保存版本和目录 URI，不把 URI 返回页面。不请求整个存储空间权限。状态检查失败或授权失效时要求重选。

保存只接受应用固定报告目录内的实验及生成标识，不接受页面指定任意源文件。目录现有文件名按大小写不敏感比较，同名另建“（2）”等副本；原生接口拒绝文件提供商返回已有文档标识。流式复制后重新打开新文件核对长度和 SHA-256，通过才提示保存成功。失败仅尝试删除本次新建副本；删除失败明确提示可能留下未完成副本，本机原报告保留。

保存过程禁用重复保存、生成与页面离开；开始保存前重新读取报告索引并核对生成标识。分享继续使用原有系统分享流程。

- 8 项桌面浏览器检查使用生产目录页面和模拟原生接口，覆盖恢复、取消、错误重试、重开、清除确认、授权过期、重复操作和旧回调隔离。检查 320/360/390/768/1024/1280 宽度截图，小屏截图人工复核。
- 网页和 Android 构建通过；APK 93 项资源逐项匹配，18 项原生类定义检查通过，桥接参数日志关闭。签名保持原调试证书。

## 尚待实机验收

单元测试的内存文件提供商不能证明实际 Android 文件夹选择器、长期授权、重启或第三方存储提供商行为。需在手机验证首次选择/取消、更换目录、保存两份同名报告、重启后再次保存、授权撤销后重选，以及 Word/WPS 打开所存文件。本轮没有执行官网选退课、上传报告或付费 API 调用。手机版整体移植仍在继续。
