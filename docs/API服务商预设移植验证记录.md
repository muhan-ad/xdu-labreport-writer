# API 服务商预设（0.55.0 / Android 58）

## 与原版对照

原版 `src/index.html` 的 AI 服务包含提供商选择、地址填充及常用模型，手机版此前只有地址和模型手填。本轮补齐提供商及常用模型选择，沿用当前绿色表单，不新增图标包或运行依赖。

提供 DeepSeek、小米 MiMo、硅基流动、阿里云百炼（北京）、OpenAI 兼容/自定义。问答与识图使用各自模型建议；硅基流动不预填无法核实的模型名单，仍可显式获取账号模型或手填。服务商预设不代表用户账号已开通、不保证可用性，也不替代模型测试。

## 数据与交互

- 从原有端点准确推导提供商，不新增持久化标记。未知地址完整保留，不按域名子串猜测。更改地址不会自动替换手填模型。
- 选择预设只改草稿。自定义保留现有填写；关闭丢弃草稿，明确点击保存才写入当前用途配置。
- 不同 API 地址不能沿用输入框的旧密钥；相同原生绑定地址允许保留。状态文字区分当前地址是否已有密钥。加密配置仍在原生层，前端不读取存储密钥。
- 预设切换取消在飞的模型列表/测试，旧列表不进入新服务商。DeepSeek 教程使用同一路径，避免跨地址携带密钥。
- 保存/清除配置写入期间禁用表单、阻止关闭；完成后恢复。模型列表获取仍可由用户停止或切换。

## 核对来源（2026-10-26）

- DeepSeek 地址和模型依据[官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/)，Flash 同时用于识图建议，Pro 仅列入问答建议。
- 小米地址依据[官方 OpenAI SDK 示例](https://platform.xiaomimimo.com/docs/en-US/usage-guide/passing-back-reasoning_content)；V2.5 多模态说明见[官方发布说明](https://platform.xiaomimimo.com/docs/en-US/news/v2.5-tts-release)。
- 硅基流动地址依据[官方快速开始](https://docs.siliconflow.cn/docs/userguide/quickstart)，候选模型以用户主动获取的列表为准。
- 百炼明确标注北京通用地址，依据[官方 Base URL 总览](https://help.aliyun.com/zh/model-studio/base-url)；视觉模型依据[官方视觉理解说明](https://help.aliyun.com/en/model-studio/vision-model/)。其他地区、业务空间端点继续手填，不误判为北京预设。

## 验证

254 项逻辑测试通过，其中新增准确端点识别、模型用途及密钥绑定草稿测试。生产配置组件配合模拟原生接口验证 12 项组合：旧配置不覆盖、预设不自动发送/保存、常用模型、自定义、手填识别、用途隔离、取消后晚响应、教程同地址及跨地址密钥处理、六尺寸、关闭草稿、保存恢复及写入期间阻止关闭。

原有模型配置 10 项、实际录入/模拟键盘 10 项、设置导航 13 项回归通过；资源核对、APK 构建和 Android 124 项 JVM 测试通过。截图在 `artifacts/verification/ai-providers-ui/`，人工查看 320px 配置页。

本轮没有向模型服务发起请求、没有使用真实密钥、没有设备安装/付费 API/学校提交/云端发布。不把模拟接口和官方文档核对当作真实服务调用成功。原版“识图继承问答配置”尚未对齐，本轮仍为两个独立的加密配置；完整移植及真机验收继续。
