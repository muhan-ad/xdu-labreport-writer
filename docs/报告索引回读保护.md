# 报告索引回读保护

0.113.0 修复报告索引写入后未确认、即可能清理旧报告的问题。旧实现没有在批量生成冷启动时先读取既有索引版本，也没有核对两次写入的结果；存储返回成功但实际写坏或未写入时，可能错误地继续清理旧文件。

现在先读取既有索引和版本，写入第一份后回读核对版本、内容和摘要，确认成功后才替换另一份；两份再次核对后才执行旧文件清理。任一阶段无法核实会停止清理，保留新生成文件供后续核对；两份已有索引均损坏时不会自动覆盖。报告管理中无法读取的索引单独显示“未核实”，不会算作确认不存在的报告。应用不会为了修复索引而清除测量数据。

测试使用虚构报告和隔离内存存储，先复现旧实现未拒绝损坏/静默未写入，再检查首份失败时保留旧索引、第二份失败时仍可读取已核实的新索引、冷启动版本衔接、两份损坏时不覆盖，以及真实 ReportGeneration 在故障时不调用清理。单份报告实际离线 Worker 生成、28 实验批量队列及失败重试、391 项领域测试和安卓构建通过。三种尺寸检查报告管理中的故障提示。

这些检查不等同于报告文件正文按字节回读、断电保证、真实文件系统故障或实体手机验收；既有损坏索引目前不会自动修复，应先检查存储并保留原文件。模拟器当前未连接，未覆盖安装本版；iOS 仅同步共享代码，未构建或设备验收。未执行学校写操作或付费 API 调用。
