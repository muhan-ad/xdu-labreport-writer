# 集中报告章节管理（0.58.0 / Android 61）

## 原版对齐

核对电脑版 `src/renderer.js` 的 `loadSecCfgForExp`、`saveSecCfg`：章节来自该实验实际变体模板的键名，按实验保存，关闭的章节只影响新生成的报告。

手机版新增“设置 → 报告管理 → 报告章节”，可搜索并选择实验，整张卡片切换章节，全部保留、放弃修改及明确保存。章节来自本会话的内置/已验签数据模板，不编造另一套章节名。已有实验内的章节控制继续使用同一份配置。

## 保存与草稿

- 勾选先改草稿，不自动落盘；未保存时锁定实验选择和搜索，保存或放弃后可切换。离开页面丢弃草稿，写入期间保护页面。
- 保存时在配置串行队列内重新读取当前配置，检查原可见开关是否已变化，只合并当前模板章节的开关。变体、AI 导入、题目、图表、照片开关及模板外历史字段保留。
- 双份写入并回读后才显示成功。同一批开关被其他操作改动时拒绝旧草稿，提示重新读取；首份/第二份写入失败也不伪称成功。
- 配置副本异常显示警告并禁止此页覆盖，可重新读取、切换其他实验或进入原有实验页面核对。不把单实验读取失败当成整个实验不存在。
- 未影响测量数据、原始照片或已生成报告；重新生成后才反映章节变化。

## 轻量化与界面

章节管理界面为按需加载模块，构建约 5.63 KB（gzip 约 2.10 KB），不在首页加载；约 1.01 KB 的章节合并辅助模块由现有存储共享。未新增依赖或改变原有动效。

实际生产构建以延迟模块下载验证离开页面时不会晚到覆盖；设置入口展示 28 个实验，在隔离浏览器文件存储中保存、完整重载后恢复。手机和平板滚动后保存按钮位于底部导航上方。

## 证据

- 275 项领域测试通过，新增 10 项：28 实验模板名称、局部合并、输入界限、并发冲突、较新无关配置、重启/实验隔离、写入失败/不确定写入、损坏副本及未知旧章节保留。
- 生产章节页、实际 Reports 和真实 Repository 配合隔离内存存储的 10 项检查通过：整卡草稿/放弃、明确保存、双向读取、全部保留、搜索与隔离、失败重试、冲突重读、空/失败数据、六尺寸及旧响应隔离。
- 真实生产构建 3 项按需加载/晚到/保存重载检查通过；实际设置导航 15 项、录入及模拟键盘 10 项、原历史管理按需加载 3 项回归通过。
- 28 个实验经过真实 Repository 保存开关、新 Repository 重读、离线 WASM 生成，共 28 份 DOCX 全通过；关闭的章节标题均不残留，保留 843 条可编辑公式，公式复制映射无丢失。该验证不是全篇排版或全部科学正确性证明。
- Android 134 项 JVM 测试、生产构建、APK 资源及原生类核对通过。
