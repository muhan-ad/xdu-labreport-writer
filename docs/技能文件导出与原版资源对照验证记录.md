# 技能文件导出与原版资源对照（0.69.0 / Android 72）

## 技能文件管理

原版设置可打开技能文件夹，用户能够取出、编辑并重新导入 Markdown。手机版原先只有正文查看、启停、导入、删除和恢复内置；本轮在展开的正文下增加“导出技能文件”，通过系统分享保存文件，不开放应用私有目录。

通常导出 Markdown，保留名称、描述、适用范围、正文和启停状态；改进带引号元数据的读取，公式中的反斜杠、引号和换行可以往返。内容若需原样保留前后空白/CRLF，或加上元数据后超过 Markdown 的 64 KB 限制，则导出有明确格式/版本的 JSON 技能文件。JSON 上限 128 KB，可从同一导入按钮重读，未知格式/字段被拒绝。多个文件先全部解析，尾部文件无效时不保存前面的文件。

导入同一内容仍保留本机已有启停状态；删除后重新导入或导入新内容时采用文件内的启停状态。技能内容不包含应用另行保存的 API 配置、账号、测量记录或历史。

原生导出先写入应用缓存的独立 UUID 子目录，核对写入文本后再打开分享面板，保留原技能文件名。写入或回读失败只清理本次文件；分享面板返回或报错后不立即删除，以便接收程序继续读取。网页导出使用本地 Blob；测试拦截下载，没有向用户下载目录写文件。导出期间保留正文展开状态，失败可重试。

## 验证

- 领域测试共 316 项通过，新增六项覆盖四个完整内置技能往返、转义元数据/禁用状态、JSON 回退、非法及过大文件、文件名、原生暂存端口的核对/失败/不确定分享。
- `test-skill-files-browser.mjs` 在实际源码应用与实际压缩构建各通过六项：导出、删除后重导、JSON 原文保留、多文件预检、导出失败重试，以及实际存储全页重新加载后的恢复。五个手机/短横屏/平板尺寸截图留档。
- 原有“获取技能”正式构建五项与设置导航 16 项通过。Android JVM 134 项零失败，构建成功；125 个资源 / 95,541,402 字节、88 个 Web 文件、30 个原生类 / 11 个 DEX 核对通过。
- 原生分享及手机外部文件编辑器尚未在新版 Android 中验收。现有模拟器安装的仍为 0.14.0，本轮只读检查，没有替换它。

## 原版静态资源对照

新增只读工具 `scripts/audit-desktop-parity.mjs`，只读取移动端静态源码归档中已经列出的原版文件，不扫描原版账号或测量记录，不自动改写任何原版文件。

当前核对结果：28 实验、196 个字段的完整 schema 与原版一致，28 份 schema 原始 SHA-256 匹配，28 套变体目录匹配。173 份归档脚本/资料中，171 份在去除 BOM、统一换行后的文本一致；两份差异恰好对应已有显式补丁：刚体自定义思考题变量名修复、RLC 理论频率计算保留完整精度。补丁规则应用到当前原版文本后与手机归档完全匹配，没有其他漂移。

证据为 `artifacts/verification/desktop-parity/results.json`。这证明的是静态输入和已记录补丁的对应关系，不是科学结论、原生业务、学校网站协议或真机效果全部正确。总目标仍不能仅凭这份对照标记完成。
