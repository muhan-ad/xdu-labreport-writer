# 安卓 28 实验带照片报告回归

0.126.0 在独立 Android 验收包的 WebView 中，使用内置离线报告运行环境、虚构学生信息、样本测量数据和同一张测试照片，逐项生成 28 份 Word 报告。每项使用独立 Worker，未写入主应用数据，也未调用学校或模型接口。

28 份文件通过 ZIP 与正文 XML 检查；逐份确认学生信息、报告公式数量及原始测试照片内容，合计核对 1005 个公式和 20 张生成图表。生成期间页面计时器继续运行，仅说明主页面仍可获得执行机会，不能推断真机帧率或性能。

此检查不覆盖实际用户照片、全部实验计算正确性、手机 Word/WPS 排版、系统分享及实体设备。验收包已卸载，模拟器已关闭。本次未修改应用代码或安装包。

证据：`artifacts/verification/native-worker-0.126.0-1793283486958/results.json`、`document-checks.json` 和该目录 28 份测试 DOCX，以及 `artifacts/verification/worker-corpus-0.126.0.log`。
