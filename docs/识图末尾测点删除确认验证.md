# 识图末尾测点删除确认验证

版本：0.101.0。识图服务使用模拟结果，没有真实模型或学校写操作。

识图校对中，水中声速的 10/12 点切换已经保护有内容的末尾；其他可变长度实验此前直接删除末点及关联表格内容。现在所有可变长度测点在末点或关联表格对应列包含内容时都要求确认，空白末点仍可直接删除；取消会保留数值，包括零。

生产校对弹窗浏览器测试覆盖空白删除、关联列有零时确认、取消保留、确认后同步缩短及 320/390/768/1024 宽度；已查看 320 宽截图。水中声速和识图校对原有回归分别通过 4 项和 8 项。381 项领域测试、安卓原生单元测试、构建及资源核对通过。

当前模拟器更新前已备份，覆盖安装前后 217 个文件一致。隔离模拟器真实界面和本地存储通过八项识图测试，包含普通可变测点的删除确认及取消保留；测试后 216 个文件与安装前一致，另一个为系统 WebView 设置。模拟模型和照片不代表真实识图准确率。

iOS 共享资源已同步，但未进行 Xcode 构建或设备测试。
