# 报告文件回读保护

0.115.0 在发布报告索引之前，对生成的 Word 和各图表进行写入后长度、SHA-256 核对；空文件或文件不一致会中止发布，由生成流程清理未发布的新目录，原报告不被清理。Android 使用原生分块读取，每次缓冲 64 KiB；其他平台先核对文件大小，再通过现有文件接口回读。文件限额保持 Word 24 MiB、单图 8 MiB、最多 32 张。

本地模拟故障先复现写入成功但文件损坏仍会被接受，再验证 Word 与图表的同长度内容变更均被拒绝。实际 Android WebView、私有存储和原生桥使用独立验收包与虚构数据完成 5 项：损坏 Word 被拒绝、正常重试成功、报告文件回读以及图表正常/损坏验证。首次原生验收发现 Capacitor 桥接整数读取方式错误，修复后重新验收通过；不把首次失败当作成功。原生路径、大小、摘要的 JVM 测试、实际浏览器离线报告生成、391 项领域测试和 Android 构建通过。模拟器更新前备份，更新前后 217 个文件一致。

本次核对证明写后可读文件与生成字节一致，不保证之后的磁盘故障或断电数据持久性，也不验证 Word 内容和计算的科学正确性。iOS 回读使用共享文件接口并可能产生额外内存占用，仅有模拟桥测试，尚未在苹果设备或 Xcode 构建中验收；用户的真实手机尚未测试。没有使用真实学校账号、选退课、上传或付费 API。
