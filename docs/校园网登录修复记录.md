# 0.5.1 校园网登录修复

2026-10-23，版本 0.5.1 / versionCode 7，Android 本地调试签名包。

## 真机反馈与核对

- 用户反馈移动网络下“学校系统连接失败”，连接校园网后变为“官网跳转地址未获授权”。尚未取得该次已认证跳转链，不能把具体成功跳转路径当作已验证事实。
- 电脑匿名 GET 官网根目录返回 HTTP 200 / gb2312；未登录访问 student/student.aspx 等受保护页面，官网确实返回 `/phyews/default.aspx?ReturnUrl=…`。
- 原版移动适配只允许固定页面且禁止一切查询参数，缺少官网登录入口。这会误拦上述官网实际使用的跳转。

## 最终修改

- 按用户要求取消逐页路径白名单，官网同域的新路径、大小写、查询参数均可跟随；仍只允许 wlsy.xidian.edu.cn 的 HTTP 80 / HTTPS 443，不向其他域名跟随携带会话的请求。
- 原生插件主动调用仍只暴露固定的只读操作及登录，不接受用户提供的任意 URL。模拟服务仍仅限调试包的本机固定端口。
- 受保护页面退回官网登录页时明确报告登录未生效/失效；未知域名、HTTP 错误、DNS、超时、连接失败分开提示，并指出操作阶段，不回显账号密码、Cookie、响应正文或查询参数。
- 改用本机标准 Android WebView 浏览器 User-Agent 加应用版本标识，降低官网旧浏览器判断的兼容风险。尚不能证明旧标识是本次真机失败原因。
- 登录页面说明先连接、认证校园网；未宣称移动网络下官网可达。

## 验证

- 25 项领域测试通过；Android 单元测试 3 项通过，覆盖任意同域路径与查询、官网登录别名、外域/非标准端口/带 URL 凭据拦截及脱敏诊断。
- 更新后的实际 APK 通过 14 项原生一站通模拟检查：新增未列举官网路径→default.aspx/ReturnUrl 跳转、Android 浏览器标识、真实 CookieJar/ASP.NET 表单状态、混合大小写、GB18030、会话失效、外域拦截、串行队列与清除后的旧结果隔离等。
- 同一 APK 的 Android 原生匿名请求成功读取真实官网登录表单及中文；未登录读取账号页得到 AUTH 而非“跳转未授权”。仅做两次只读操作，未提交任何真实账号密码。
- 证据：`artifacts/verification/portal-native.json`、`school-anonymous-probe.json`；原生单测结果在 `android/app/build/test-results/testDebugUnitTest`。
- 本版仍需用户连接校园网后真机复测登录。没有执行真实选退课、报告上传、付费 API 调用；未完成的选退课事务实现未纳入热修复。

复现验证：`npm.cmd test`、`scripts/build-android.ps1`、`node scripts/smoke-portal-android.mjs`；真实匿名检查使用 `node scripts/probe-school-android.mjs`（仅 emulator-5560）。
