# 安卓报告队列运行环境复用验证

2026-10-27，源码和独立预览包 0.71.0（versionCode 74），仅更新当前 emulator-5560。未操作真实手机、学校选退课、报告上传或付费 API。

## 修改

只在连续报告队列内复用 Python/WASM Worker，普通单份生成保持原有独立 Worker。每项数据和学生信息重新传入，资源包按内容指纹区分；资源变化、失败、取消、暂停、最终结束、等待用户确认时释放。完成单项后清理 Python 作业目录和输入全局变量，避免保留照片等大输入。

全量对照发现静电场脚本的 Matplotlib 全局样式会影响后续理想气体图表。现对计算、图表和报告入口使用 rc_context 隔离，退出后恢复绘图设置；保留失败样本证据，不改变实验计算数据。

## 结果

- 327 项领域/协议测试，134 项 Android JVM 测试通过，类型检查和 APK 构建通过。
- 28 个实验逐个比较全新 Worker 与复用 Worker：word/document.xml SHA、图表 PNG SHA 及公式数量全部一致；各实验使用不同学生信息检查串用。另三项先计算上下文再生成也一致。
- 28 份带原始照片的 WASM 报告回归通过。
- 正式构建队列控制及切页各 5 项通过，包括暂停、继续、终止、切页、拒绝前台并发和报告保留；五尺寸截图留档。
- 模拟器三项队列：0.70.0 为 41790 ms，0.71.0 为 18818 ms，单轮减少约 55%。前者创建 3 个 Worker，后者 1 个；最大并行数均为 1，结束时活动数为 0。
- 原生暂停后释放，继续后重建，计算中停止后释放并取消等待项，已生成报告保留。
- WASM 线性内存最高 130285568 字节，与基线最高值一致；每次采样剩余作业目录数均为 0。这不是应用总内存/RSS 测量，也不证明真机长期内存表现。
- 覆盖安装前不解密备份。原 209 个数据文件及 3 份非 WebView 配置哈希保持一致。验收使用独立存储命名空间，结束后清理并恢复原桥接与页面。
