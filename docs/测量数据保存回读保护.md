# 测量数据保存回读保护

0.128.0 测量数据保存前读取已有记录，逐份写入并回读核对；静默写入失败或内容不一致不会报告保存成功，旧记录至少保留一份可恢复副本。清除时也先核对空白记录，无法确认时中止后续清理；存储读取错误不再直接当作文件损坏处理。

故障模拟先复现旧代码漏报写入失败，再覆盖首份未写入、首份损坏、第二份损坏、清除未写入和重试恢复。实际页面 3 项检查确认输入保留、保存失败时不能离开、重试后恢复；隔离 Android 验收包 2 项检查确认原生存储写入失败后的提示和重新加载恢复。397 项领域测试和安卓构建通过。

清除流程可能在后续步骤失败前已清理识图缓存，失败提示仍要求重试，不应视为全部操作已回滚。测试使用虚构数据、未访问学校或模型；验收包已卸载且模拟器已关闭。iOS 仅同步共享资源，未进行原生设备验收。

0.129.0 调整清除顺序：先使旧识图写入失效，确认空白测量记录已写入后才清理识图缓存。若测量记录读取或写入未能确认，已有识图缓存保留。实际页面和隔离安卓验收包分别验证清除失败后两份缓存仍在；398 项领域测试通过。若空白记录已确认而后续清理失败，仍可能出现部分完成，需按提示重试。证据：`reset-ocr-before.log`、`measurement-recovery-ui.json`、`native-measurement-save-1793318800590/results.json`、`reset-ocr-tests-0.129.0.log`、`build-0.129.0.log`、`sync-ios-0.129.0.log`（均位于 `artifacts/verification/`）。
