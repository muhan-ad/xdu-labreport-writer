# 识图可编辑校对（0.26.0 测试版）

原识图校对仅展示只读 JSON。本轮改为可编辑数值输入框，保留字段勾选、警告字段默认不选、仅填空白及人工录入确认。原始照片留在同一弹窗，可向上查看。数值和单位沿用当前实验 schema，科学计数支持 e 和“×10^”写法。

可变长度测点提供增加/删除末点，已识别的对应 colsFrom 表格一起增减，新增值为空白。所有变化只在校对弹窗内，点“录入勾选项”才写入实验。取消关闭或重新识别放弃本次校对修改，重复识图使用新结果重新构造输入，不叠加上次长度。

录入前重新解析勾选字段并校验形状、现有数据格式和关联长度；不悄悄丢弃非法文字或截断对应表格。未勾选字段的非法编辑不参与录入；空白仍表示未识别，不清除已有值。只有明确关闭“仅填空白”才允许替换含既有值的不同长度数组，仍需同时选择各组匹配字段。

数据或照片变化会拒绝旧校对。保存中禁用操作并增加入口并发守卫，重复点击不重复写入；失败后保留输入、恢复操作及测点数量边界，可重试。识别服务只在用户点击识别时调用，修改和录入校对值不再请求模型。

## 验证

- 全部领域测试 96 项通过，新增 3 项直接校对解析/科学计数/空白与零/勾选边界/长度替换检查。
- `scripts/test-ocr-correction-browser.mjs`：9 项生产 AIFeatures 弹窗组合检查，图片由浏览器实际解码和缩放，识别服务与保存端口使用模拟对象。覆盖数值修改、科学计数、警告勾选、关联增点、仅填空白、明确替换、重复识图、非法文字、旧数据拒绝、清除后重录、失败重试及并发限制。
- 28 个目录 schema 均通过真实数值编辑器的形状往返；使用明确构造的数据检查字段与存储顺序，不作为物理数据合理性证明。
- 320/360/390/768/1024/1280 宽度的真实识图弹窗截图无横向溢出；320 宽度截图已人工查看。证据位于 `artifacts/verification/ocr-correction-ui/`。

本轮不改变模型原始识别率。原始响应中形状无效而被丢弃的字段仍列出错误，当前校对编辑器处理已通过字段形状检查的内容。没有真实付费识别、设备安装或官网写操作；Android 系统照片与文件保存、真实模型质量和 iOS 仍待验收。整个原版功能迁移继续进行。
