## 构建/安装入口修正

发现旧 Install-Android.cmd 固定使用 artifacts/lab-maker-app-debug.apk（0.14.0），会忽略新版独立预览包。旧构建入口又会直接覆盖该固定路径。

现在构建先通过领域测试、类型/Web 构建、JVM、APK 资源和原生类核对，再验证 APK 签名，输出带版本的预览包及 artifacts/preview/current-build.json。同版本不同内容加摘要后缀，已有包不覆盖；旧固定路径及所有既有预览包均未改变。

安装入口只认当前构建记录，重新核对当前源码版本、APK 包名/版本/构建号、长度、SHA-256 和签名。无记录、文件改变、记录身份不符或源码版本不符会拒绝，不回退旧包；多设备时要求明确目标。-VerifyOnly 完全不操作设备。

新增四项文件级回归：无记录不回退、同版本不同包保留、内容/路径/身份/版本篡改拒绝、隔离测试包或错误版本不能登记。共 332 项领域/协议测试通过，134 项 JVM、125 项资源、30 个原生定义及实际签名检查通过。实际完整构建入口与 Windows PowerShell 5 的安装校验模式通过；本轮没有调用新脚本真实安装。

证据：artifacts/verification/build-entrypoint-072.log、artifacts/preview/current-build.json。该记录仅为本地构建索引，不等于正式发布或完整设备验收。
