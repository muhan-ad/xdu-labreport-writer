# 识图缓存读取失败保护

0.108.0 保护缓存写入失败，但打开识图时如果缓存状态读取失败，校对页尚未建立缓存关联，关闭时会错误地认为无需保存。本轮用模拟故障先复现，再修复。

0.109.0 在缓存状态不可读时仍允许识图和编辑，但会显示校对内容未能保存的提示；关闭、离开或重新识别前会重试读取并核对来源。读取依旧失败时保留内容，由用户重试或主动选择“仍然关闭”。读取恢复后重新核对实验、照片、日期和已有数据，再绑定本机缓存并保存。如果实验数据或照片期间改变，不把旧校对结果写入新数据。显式录入成功后正常关闭，避免重新生成已清除的旧缓存。

浏览器使用实际界面和仓储模拟读取失败，验证 4 项：失败时保留、阻止重复识别、恢复后续接、数据变化时不绑定；既有写失败、正常识图、学生信息、缓存恢复和末尾点数回归通过。Android 隔离验收应用在真实 WebView 和原生文件接口上模拟读取失败，验证 4 项退出/页面切换/重复识别/恢复续接。388 项领域测试和安卓调试构建通过。模拟器备份更新前后 217 个文件一致。
