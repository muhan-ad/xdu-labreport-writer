# 电脑版自建变体迁移验证记录

版本：0.38.0 / Android versionCode 41，独立开发测试包。

## 对照依据与范围

只读核对电脑版 `main.js` 的 `export-custom-variants`、`import-custom-variants` 和 `CUSTOM_SECTION_NAMES`。电脑版单实验文件名为 `自建变体_<实验目录名>.json`，内容是章节名称到文本数组的映射，不包含基准变体或内容校验值。批量导出仍是逐实验的独立文件。

手机版设置 → 报告管理 → 自建变体库现在支持一次选择多个电脑版或手机版 JSON。文件合计最多 8 MB、100 个文件、500 条记录。全部解析与核对完成后显示实验数、条数和待核对条数，用户确认后才归档；取消不写入。无效文件导致整批预检失败，不按当前页面所选实验猜测文件归属。

电脑版按文件名精确匹配目录的 `sourceId`，保留不同学期和同名近似实验的区分。仅明确处理“实验结论”和“结论”的章节别名，未知章节拒绝导入。

## 来源与适用限制

电脑版没有提供基准原文。导入时尝试匹配当前内置章节中公式、数据占位符完全相同的兼容基准，标记为“电脑版导入”；详情称为“兼容基准（当前内置）”，不声称找回了当初的原文。匹配仅证明公式和占位符序列兼容，不证明正文的科学正确性。

无法匹配的条目完整保留原文，明确显示“未找到兼容基准，仅可查看与导出”，禁用“追加并选用”。这类任意自建正文的直接报告生成仍未完成迁移，不能视为与电脑版全部兼容。

新增“导出手机版”和“导出电脑版”，支持当前实验或详情中的单条。电脑版导出还原章节文本数组及原实验文件名，不加入手机版来源、校验或基准字段。手机版归档格式保留来源和待核对状态，旧归档校验值仍兼容。

## 测试证据

- 143 项领域测试通过；新增 6 项覆盖 28 个实验的电脑版文件结构、来源绑定、批量预检、结论别名、BOM、容量、去重、旧格式兼容、待核对记录的持久化及两种格式导出。
- 新增 8 项浏览器检查使用实际变体库页面、仓库和文件选择事件：取消、无效尾文件、重复导入、转义、禁用待核对条目、兼容条目选用、批量导出及关闭后的旧任务隔离。
- 原变体库 10 项、报告变体 8 项及实际主程序导航 5 项浏览器回归通过。
- 320/360/390/768/1024/1280 宽度截图和横向溢出检查，已查看 320/768 截图，保留产品动效。
- `test-variant-runtime.mjs --desktop`：真实离线 WASM 引擎对 28 个实验执行基准与导入后的报告生成，导入文本各出现一次、公式数量保持一致、内置模板未被修改；额外 3 次再次调整和 7 项无效配置拒绝检查通过。
- Android JVM 106 项测试（105 项业务、1 项模板）、构建、96 项资源核对、23 项原生类定义、签名和版本核对通过。

结果保存在 `artifacts/verification/variant-transfer-ui`、`artifacts/report-tests/desktop-transfer` 和独立 APK 的验证记录中。未安装实机，未调用付费 API、执行选退课或上传报告，没有修改桌面源码或覆盖既有 APK。
