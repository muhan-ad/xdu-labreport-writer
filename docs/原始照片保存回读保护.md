# 原始照片保存回读保护

0.116.0：原始照片先写入独立文件并核对长度及 SHA-256，再逐份写入和回读照片索引；索引结果不确定时保留新旧文件，避免误删可恢复的照片。识图缓存只在新索引确认后清理。Android 采用原生分块回读，其他平台在读取前检查大小。

照片索引故障注入、Android 原生校验单元测试、模拟 Android/iOS 桥的内容损坏与重试、392 项领域测试及 Android 构建通过。隔离 Android 模拟器测试通过 4 项：正常保存、同长度照片损坏拒绝并保留原照片、索引写入异常保留新旧照片、重试成功。模拟器测试未使用学校提交或付费 API。

补充检查：浏览器实际文件系统的照片保存与回读通过；28 个实验以离线报告运行环境生成含原始照片的报告，逐份核对嵌入的照片内容，均通过。该检查不代表手机 WPS/Word 排版或真实照片识别准确率验收。

当前启动的模拟器未检测到主应用，备份脚本在安装前拒绝了无效备份，因此没有覆盖安装主应用。iOS 共享资源已同步，但未进行 iOS 原生构建或设备验收；手机实机照片选择、低存储及异常断电仍需验证。
