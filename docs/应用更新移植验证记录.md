# Android 应用更新（0.52.0）

设置的当前版本区域新增“检查应用更新”，独立于实验数据更新。页面沿用绿色按钮和圆角卡片，提供检查、下载/停止、清理缓存、安装前确认及系统授权入口；更新说明作为纯文本展示，长内容在页面内滚动。

## 协议与安装边界

清单使用固定匿名地址 `https://labreport-1485394950.cos.ap-guangzhou.myqcloud.com/mobile-app-manifest.json`。只有 HTTP 404 表示尚未发布；403、跳转、断网、无效 JSON 或签名异常不会显示成“已是最新”。没有实际请求本轮线上清单，也没有发布线上文件。

应用清单与实验数据清单使用不同 `kind`，以固定公钥验证 Ed25519 签名，绑定包名、语义版本、构建号、最低 Android 版本、大小、SHA-256、APK 证书指纹及更新说明。APK 地址严格为同源 `/mobile-app/lab-maker-app-x.y.z.apk`，禁止查询参数、跳转和外部来源。版本和构建号均须高于当前实际安装信息；签名来源不同或系统版本不满足要求时不下载。

APK 最大 150 MiB，原生层使用 32 KiB 缓冲流式写入应用私有缓存。安装包字节不经过 JavaScript 桥接。完整长度和摘要核对后，再通过 Android 包信息 API 核对包名、版本、最低系统及签名标识；失败/取消清理临时文件。缓存只允许一个候选，旧缓存存在时先由用户清理，不静默重复下载。

安装前再次验清单、当前安装信息、候选标识绑定、文件长度/摘要及包元数据，候选在同一进程内 15 分钟过期。用户确认后才尝试打开系统安装页；缺少授权时只提示，由用户另外点击进入系统设置，再返回重新确认安装。安装确认交给 Android，页面只报告“已打开系统安装页面”，不宣称已经安装成功。[Android PackageManager 文档](https://developer.android.com/reference/android/content/pm/PackageManager#canRequestPackageInstalls())说明了来源安装授权的检查条件。

插件在应用离开前台或销毁后不再打开安装器/系统设置。页面取消、离开和迟到响应不能将旧下载结果变成可安装候选；另一版清单不能复用已下载的旧候选。系统安装器仍负责最终 APK 签名验证及实际替换。

## 本地发布候选

`scripts/prepare-app-update.mjs` 先用 Android 工具核对实际 APK 的签名、包名、版本及最低系统，再生成清单和 SHA-256。默认仅生成 `mobile-app-manifest.unsigned.json` 与回执，不读私钥、不复制额外 APK、不上传。指定 `--apk` 可选已有安装包，`--output` 选择新候选目录；已有目录拒绝覆盖。

只有操作者显式提供 `--key` 才会读取该文件签名，并与内置发布公钥复核；调试证书 APK 拒绝生成正式签名发布候选。生产 Android 签名及发布密钥仍需正式配置，不能用当前调试包冒充正式更新。

本轮生成的 `artifacts/app-update-candidates/0.52.0-api24` 为本地未签名候选，应用会拒绝其空签名。未启用云端更新，也未执行安装。

## 验证

- 7 项逻辑测试：签名与包绑定、篡改/额外字段/错误公钥、来源与版本/大小边界、显式原生参数及进度隔离、监听未完成时取消、活动请求取消及迟到响应。
- 6 项新增 JVM 测试：匿名流式下载与完整摘要发布、来源/跳转/错误摘要、分块超限/取消、安装包身份与版本策略、应用清单固定路径/404。使用本地模拟 HTTP 服务和临时文件，不下载真实发布 APK。
- 全部逻辑测试 247 项、原生 JVM 测试 124 项通过。
- 更新生产组件 9 项通过，下载和安装端口使用模拟；实际主应用设置入口/导航 13 项回归通过。
- 六种 320～1280 像素宽度无横向溢出，人工检查 320、1024 像素长说明截图。证据位于 `artifacts/verification/app-update-ui`。
- 最终包 104 项资源、29 个原生类定义和 11 个 DEX 已核对；APK 调试签名有效。

Android 包信息 API 的真实设备结果、系统授权返回、FileProvider 向安装器授权及覆盖安装尚未实机验收；JVM 策略测试和编译通过不能替代它们。没有安装设备、操作真实用户数据、上传报告、选退课、付费 API 或云端发布。iOS 应用更新原生能力未接入；整体移植目标仍未完成。

实际 APK 元数据核对发现本工程最低 SDK 为 API 24。已将清单/原生校验统一为 API 24 起，API 24／25 由系统旧安装器处理未知来源，API 26 起使用每应用安装来源授权；新增两项对应策略测试。初版候选在 0.52.0 目录被标注 REJECTED，当前候选为 0.52.0-api24，不能发布旧候选。
