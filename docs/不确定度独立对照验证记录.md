# 不确定度独立对照验证记录

基于 0.59.0 的正式计算资源。此次增加开发期验证，不修改应用计算逻辑、界面或安装包，版本保持不变。

## 新增覆盖

独立参照仅使用 Python 标准库和模拟输入，不导入报告脚本、共享统计函数或计算结果来构造预期。

| 实验 | 核对内容 |
| --- | --- |
| 激光波长 | 位移 A/B 类及合成不确定度、波长传播、mm 到 nm 换算 |
| 凸透镜焦距 | 自准法 A/B 类、像距 A/B 类及合成、固定物距口径的焦距传播 |
| 凹透镜焦距 | 凸透镜参考结果、位置差 A 类、两次独立读数的 sqrt(2) B 类、合成 |
| 灵敏电流计 | 拟合斜率/截距标准误、内阻和电流常数的传播 |
| 电子元件伏安特性 | 拟合斜率/截距标准误、电阻传播及 mA 单位换算 |

小样本 t 系数使用现有课程约定：68.3% 口径，n>6 取 1。它不是对任意置信水平的通用结论。凸透镜物距按课程模型视为固定，不据此宣称完整评估了仪器所有相关误差。

## 本轮结果

- 独立参照自检 12 项通过，包括手算均值标准误、残差协方差、噪声缩放、完全重复数据、凹透镜两次读数传播和波长单位换算。
- 原 28 个实验关键量 79 项，加上五个实验的不确定度 23 项，共 102 项；电脑 Python 与手机采用的 WebAssembly 各通过 102 项。
- 五个实验各三组额外输入，共 15 组、69 项：完全重复/精确直线、非零散布/拟合残差、仪器限差或残差幅度改变。正式计算资源在两个运行时分别通过全部 69 项。
- 分别故意给理论磁场、波长不确定度引入 1000 倍单位错误，检查器均以失败退出并定位对应字段。平均值正确不能掩盖不确定度单位错误。

此次覆盖范围内没有发现新的计算偏差，因此没有为了修改而改动原有算法。未改变测量值和报告显示精度。

## 重复运行与证据

激活工具后运行 `npm run test:science`，会重新取得电脑及 WebAssembly 的正式计算上下文，再独立核对；不会依赖上一轮缓存结果。电脑解释器可通过 LAB_MAKER_TEST_PYTHON 指定，不需要联网、学校账号或付费模型。

结果在 artifacts/science-audit/：

- audit-summary.json：版本、实际报告源码摘要和总数。
- python-independent-results.json、wasm-independent-results.json：102 项预期、实际、单位、公式、差值和容差。
- uncertainty-jobs.json：15 组模拟输入；python-uncertainty-results.json、wasm-uncertainty-results.json：各 69 项结果。
- rejected-unit-error.json、rejected-uncertainty-error.json：明确标记的故意错误拒绝结果，不得当作真实故障。

范围限制：参照要求重复测量样本不触发坏值剔除；未证明全部实验的不确定度、异常值分支、相关误差、全部绘图或实测数据合理性。也不代替 Android 真机、平板性能或 WPS 排版验收。总移植目标保持进行中。
