# 0.4.0 一站通读取链路

2026-10-23：沿用原版 `src/course-selection/server.py` 的学校路径、ASP.NET 表单字段、身份/学时/已选课表/可退列表/周余量解析规则。新增代码位于手机版原生 LabPortal 插件、portal 领域解析器、SchoolPortal 会话服务与 PortalView。原版源码未修改。

## 当前实现

- Android 内存独立 CookieJar，不与 WebView、浏览器或 AI 插件共享 Cookie。登录用最新隐藏字段，登录后重新读取受保护的身份与课表页面才确认成功。身份不一致或页面格式变化均报错。
- 原生层单请求串行队列，固定学校域名、路径和操作，不提供任意 URL 请求接口。HTTP 按原官网现有协议保留，没有升级或替换官网服务。
- 查询仅限官网提供的周次。`id` 与表单提交 `name` 分别解析，保留新 VIEWSTATE/EVENTVALIDATION，图片按钮使用 `.x/.y` 字段；60 秒缓存，手动刷新失效。
- 已选课表突出未来最近一场，不突出已开始或未知日期。北京时间计算时间与 72 小时显示原因；在时间边界和重新聚焦时只更新状态，不重建卡片或清除登录草稿。
- 原版 28 个实验推荐、27 位教师评价分类及别名映射作为静态数据迁入；实验卡片与已选课表均能原地查看实验评价。教师未明确核实时不显示其他教师的评价，评价正文黑色 18px。
- 清除登录立即更换会话、清空余量和个人课表内存缓存、取消在途请求并丢弃旧响应，不自动重连。密码未写本机文件；账号加密保存尚未接入。

## 验证

`npm.cmd test`：20 组领域测试，新增日期/北京时间、72 小时精确边界、已开始/未知日期/官网禁退、未来最近一场、名称别名和教师评价不可跨实验借用。

`node scripts/smoke-portal-android.mjs`：专用 Android 16 / API 36 模拟器，连接固定回环模拟官网。覆盖 Cookie 登录、302 跳转、ASP.NET 隐藏字段、GB18030 中文页面、身份/课表/周余量、缓存、周次不匹配、学校 HTML 脚本不执行、读取时清除会话、延迟旧响应隔离、登录失效、小屏布局及请求串行。测试不会连接真实学校或发送真实凭据。

证据：`artifacts/verification/portal-native.json`、`portal-availability.png`、`portal-small.png`。图片均为模拟账号、模拟课表；不作为真实官网验收。

## 未完成项保持原范围

本轮仅完成读取依赖，尚未接入选退课提交、一次性票据、最终复核/确认/回读、教师/教室元数据、教务冲突、筛选/跨周搜索/推荐扫描、报告系统登录/成绩/上传预览确认、账号加密管理及 iOS 一站通。页面明确显示待核实、未校验和迁移状态，不将未知信息当作正常完成。时间限制目前只用于只读状态展示，不能称为后端最终提交规则已验收。

后续继续完成这些业务链路；完整原版功能目标没有缩减，也未宣称已可正式发布。
