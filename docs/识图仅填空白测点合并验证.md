# 识图仅填空白的测点合并验证

版本：0.100.0。识图服务使用模拟数据，未调用付费模型或学校写接口。

之前在“仅填入空白数据”下，只要识图数组长度与已有数据不同且原数组含值，应用就拒绝合并，并提示关闭该选项。现在按位置填充已有空白、保留非空值和旧数组完整尾部；识别结果更长时可增加末点。相互关联的测点数组与测量表仍需长度一致，否则拒绝保存。未勾选的字段不改变。

独立测试覆盖新增点、短识图保留已填和空白尾部、零值、水中声速 10/12 点及关联表格失配；真实识图校对组件使用模拟模型验证编辑后扩展并保留原值。原有测试中针对“必须拒绝长度变化”的断言已按新行为改成检查数据保留；完整构建 381 项领域测试及安卓原生单元测试、资源核对通过。

安卓模拟器使用隔离目录、模拟照片和模型结果完成七项验收，包含原始图片处理、校对缓存、重复识图仅填空白、显式替换、尾部保留与清除。首次连接因 WebView 调试入口未就绪失败，应用启动后重试通过。覆盖安装前后 217 个数据文件一致；界面测试后 216 个一致，另一个为系统 WebView 设置。测试未评估真实模型的识图准确率。

iOS 共享资源已同步，未进行 Xcode 构建或设备测试。
