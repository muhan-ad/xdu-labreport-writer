# 教务登录窗口与课表页面（0.18.0 测试版）

一站通页面新增“教务课表”入口。账号默认沿用已登录的实验账号，也可手动填写；点击“登录并同步课表”打开官网统一认证窗口，完成认证后点击窗口顶部“读取课表”。应用只读取课表，不替用户进行教务业务提交。

## 本轮实现

原生 `LabAcademicPlugin` 使用 AndroidX WebKit 1.14.0 的独立 Profile，按账号哈希选择，避免与应用默认 WebView 或另一账号共用登录存储。官网页面没有 Capacitor/JavaScript 原生接口；不提供文件上传或设备权限，只执行封装的固定只读课表脚本，并在导入时再次核对身份及校历。

明确清除只操作对应教务 Profile 的 Cookie、网页存储和当前内存课表，不调用默认 CookieManager 的全局清除。系统 WebView 不支持 MULTI_PROFILE 时提示更新，不回退到与报告系统混用的配置。以上实现已编译，实际设备的 Profile 行为仍待验收。

窗口允许官网统一认证的两个 HTTPS 主机 `ehall.xidian.edu.cn`、`ids.xidian.edu.cn`，拒绝其他主机、非 HTTPS、用户信息和自定义端口；TLS 校验失败不跳过。若实际官网新增必要跳转或资源主机，需核对后适配，本轮未实际登录确认当前官网流程。

同步使用原版的固定读取脚本，必须核对返回课程的本人学号。后台解析完成后，仅在当前请求、当前页面和当前账号仍有效时接受结果。关闭、取消、页面跳转、清除和新读取使旧结果失效；超时刷新官网页面，结束旧读取上下文，避免重试叠加旧任务。会话清理进行中不允许新建连接。

应用页面采用绿色圆角样式，搜索课程/日期/教室，每次增加 100 场，避免一次渲染全部长列表；课程字段转义后展示。读取失败可重试，清除需确认，切换账号立即移除上个账号的可见课表。
