# 请勿点击彩蛋移植验证记录

版本：0.59.0，Android versionCode 62。仅本地预览测试包，未安装或发布。

## 实现范围

设置中新增“请勿点击”。原版 19 个效果源文件原样保留，运行时仅将三个统计存储键接到隔离统计适配器，保留三级确认、第一次原音频、稀有效果概率与不连续重复的随机逻辑。原音频 76,536 字节，按需读取并核对 SHA-256，不新增音频依赖。来源及致谢见 public/easter-egg/SOURCE.txt。

效果位于 sandbox="allow-scripts" 的独立不透明页面，只操作静态应用外观副本。内容策略禁止网络连接及嵌入外部页面，没有学校账号、实验数据、文件系统或原生桥权限。窗口抖动、消失等效果在该副本内表现；磁盘查询明确不可用，不伪造本机容量。外部链接仅保留原版固定地址的显式用户点击路径，测试未打开外部网站。

父页面始终提供独立退出按钮。返回、导航离开、进入后台及运行时尺寸变化释放隔离页、音频和音频上下文；保留原版动效。缺失或校验失败的音频显示资源检查和重试，并恢复第一次播放计数，避免假成功或卡住。

## 轻量化

主效果模块按需加载，约 59.61 KB（gzip 21.07 KB），平台模块约 1.55 KB，共享模块约 1.04 KB。首页不请求效果模块或音频。画布像素比上限为 1.5，保留原版喷发效果的 260 个粒子；未全局关闭动画。
