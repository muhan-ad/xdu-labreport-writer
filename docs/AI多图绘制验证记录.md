# AI 多图绘制与报告插图验证（0.31.0 预览版）

对照原版 src/main/plot-runner.py 的八图能力，手机版补齐一次代码生成最多八张图。按 fig1.png 至 fig8.png 顺序保存并分别指定图注；保留现有隔离 iframe / Worker、本机数据、离线库和停止机制。单图最多 8 MB，图组最多 32 MB，超过限制明确失败，不截成部分图组。

## 页面与保存

绿色数字按钮切换预览；逐张设置图注、插入章节、是否插入报告，支持放大。采用图组前顺序保存并回读所有图片，再保存完整设置。中途失败不发布部分配置，重试复用当前预览中已核实的图片。配置保存成功后才清理旧图片缓存，保留整组被引用的文件。

旧版单图配置继续可读；多图配置携带完整顺序与逐图设置，首图兼容字段须与第一条一致。恢复时核对当前数据摘要，数据变化不展示为可直接采用的新图。报告仅导入已采用 PNG，不执行模型代码；按图组顺序将勾选的图片分别插入实际章节，每张校验 SHA-256、尺寸与图注。

## 发现及修复

首次浏览器验证停在加载：Windows 换行使隔离页脚本的 CSP SHA-256 与浏览器规范化后的脚本不一致。构建脚本现统一 LF 后再计算校验值。添加跨平台换行回归，并保留 connect-src none / 脚本哈希限制，没有放开 unsafe-inline。
