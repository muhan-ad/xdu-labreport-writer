# 模型列表与连接测试草稿验证（0.36.0 预览版）

对照原版 src/main/api-models.js 和 renderer.js 的 fetchApiModels/testApiConnection，手机版增加获取模型、搜索和选择。连接测试改为测试当前表单草稿，纠正此前测试前隐式保存的行为；明确点击“加密保存”才改动持久配置。

## 模型列表

报告问答和图片识别两套配置独立。显式获取时请求所填 API 根地址的 /models，使用输入的新密钥；留空时仅允许从原生存储复用当前用途、同一个规范化地址的已有密钥。更换地址且密钥留空会在请求前拒绝，不借用另一个地址或用途的密钥。

沿用原生 HTTPS/公网地址检查、禁重定向和禁自动重试；30 秒时限、1 MB 响应、最多 10000 条记录，模型名最多 256 字。只接受有效标识，去重排序，丢弃已知密钥回显；保存的密钥不主动回传页面。列表不推断图片能力，不把问答模型自动当作识图模型。

页面支持搜索整份返回列表，单次最多展示 200 项；超过时提示继续搜索，服务 has_more 明确显示部分列表。用户选择只填入名称，不自动保存或测试。地址/密钥改变、用途切换、停止、关闭和旧请求回包都不会把旧列表套进当前表单；服务不支持列表仍能手填模型。

## 测试与保存

测试采用当前地址/模型/密钥草稿，在原生构造固定的简短文本请求，最多 128 输出 token，读取 30 秒、总时限 45 秒。不写入加密存储，不改变已有配置，不清空输入的新密钥。测试成功明确提示本次未保存；识图用途说明文本测试不代表验证了图片能力。

只有“加密保存”写入 Android Keystore 加密配置，保存后清空页面的密钥输入；清除只作用于当前用途。异常密钥在构造认证头前拒绝并给出通用错误，防止 HTTP 库的异常信息回显密钥。

## 验证

- 133 项领域测试回归通过。
- 8 项纯 JVM/本地 MockWebServer 检查通过：标识/去重/排序/部分列表和密钥回显过滤、空与超限响应、同地址密钥绑定、GET/Authorization/无 Cookie、重定向/401/403/404/405/429 不重试、1 MB 与取消、草稿不修改原配置、异常密钥不回显。原生业务合计 105 项（另有框架样例 1 项）通过。
- 生产 AIFeatures 配置页面 10 项通过，原生服务模拟：无自动保存/选用、跨整份列表搜索、标签转义、显式保存、用途隔离、改地址/停止/关闭的旧响应隔离、手填和部分列表、测试不保存与独立清除。320/360/390/768/1024/1280 无横向溢出，窄屏截图人工查看。见 artifacts/verification/ai-models-ui/。
- 识图校对录入 9 项、实际 main.ts 设置路由 5 项回归通过。
- 安卓构建通过，96 个资源和 23 项原生定义核对通过，调试签名与旧预览一致。

APK 与核对记录位于 artifacts/preview/。没有真实服务商请求、付费调用、设备安装、学校写操作或仓库发布。实际服务兼容性、Android Keystore/网络和真机交互仍待验收；资源维护/更新等其余移植工作和整体目标尚未完成。
