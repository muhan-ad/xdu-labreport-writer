# 0.3.0 AI 基础功能验证

日期：2026-10-22。平台为 Android 16 / API 36 专用模拟器 emulator-5560；不是安卓真机验收。界面沿用绿色、圆角和输入框本身绿色边框。

## 实现范围

- Android 原生 LabAI 插件，以 Android Keystore 的 AES-256/GCM 加密完整配置；chat 与 vision 独立存储，密钥不回传页面。明文密钥只用于用户保存时进入原生层和构造服务请求，不写日志或测量 JSON。
- 默认要求 HTTPS 服务地址，禁用自动重定向与自动重试；实际 DNS 解析后的地址需为公网地址。仅 Debug 构建为本机模拟接口 127.0.0.1:58440 开放 HTTP。发布构建没有该例外。
- 图片缩放后发送给用户配置的图片模型，响应按实验 schema 校验，支持科学计数、警告项默认不选、人工勾选、仅填空白、缺失不覆盖、数组/表格匹配校验。切页、取消或配置变化不会录入旧结果。
- 自定义思考题与章节润色先展示可编辑结果，导入后随本实验报告设置保存。使用当前测量数据作为问答上下文，润色使用实际生成章节。报告端沿用原版内容策略校验与公式转换。数据变化后旧导入内容禁止继续生成。
- 报告清除沿用现有清理能力，连同本实验 AI 导入设置一起删除；独立 API 配置保留。

## 验证入口和证据

`npm.cmd test`：17 组测试，包括全部 28 个实验的 OCR 字段形状/录入往返、科学计数、空值与零、错误数组长度、成组表格、问答配对、配置边界与快照变化。

`node scripts/smoke-ai-android.mjs`：真实 APK 原生插件连接本机模拟服务，覆盖加密保存与不回显、地址绑定、请求协议、HTTP 401、空正文、禁止重定向、手动取消、配置变更使旧请求失效、文件和日志无明文测试密钥、实际保存照片识别核对录入、仅填空白和主动覆盖、自定义问答与润色再生成、数据变化阻止旧 AI 内容。

最终实际 DOCX 验证：自定义题目、回答和润色正文各出现一次，保留可编辑 OMML 公式。界面证据：`artifacts/verification/ai-config.png`、`ai-report.png`、`ai-report-small.png`；报告与测试记录位于同目录。它们只包含模拟数据与模拟回答。

## 尚未验收

没有使用真实 API Key，没有发起真实付费调用，因此未测服务商识别率、真实模型知识质量或收费行为。没有执行真实选退课、报告上传或发布。iOS 目前明确提示安全存储尚未接入，不采用明文密钥回退。

完整 AI 教程、原版技能/知识库上下文全集、润色历史与 AI 自定义绘图尚待迁移；一站通仍待实现，不能宣称原版功能已全部移植。

实现依据：[Android Keystore](https://developer.android.com/privacy-and-security/keystore)、[OkHttp 4.12 源码](https://github.com/square/okhttp/tree/parent-4.12.0)。安装包保留原项目与运行库许可，新增网络库为 Apache-2.0 开源依赖。
