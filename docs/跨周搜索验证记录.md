# 0.8.1 跨周搜索

开始选课中的“搜索全部未来周次”读取官网允许的本周及以后场次，名称搜索和已应用的实验筛选同时作用于结果。每张结果卡片保留真实周次、时段、余量及明确教师对应关系；查看评价复用弹窗，选课继续使用原生准备、一次性票据、最终复核与回读。

复用候选目录的缓存、串行查询及在途任务；后加入的多选目录订阅者也可获得正在进行的查询结果。已读取场次先展示，后台逐周补齐，失败明确显示未完整获取及失败周，支持重试，不伪称完整目录。退出、换账号、清除或刷新会话使旧任务失效；旧任务不会清除新任务句柄。只核实为未来的场次进入跨周结果，未知日期仍在候选状态中提示待核实。
