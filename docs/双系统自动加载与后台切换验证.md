# 双系统自动加载与后台切换验证

0.85.0 在原有选课和报告系统独立自动加载基础上修复过期任务阻塞：账号设置变化后，下一次加载不必等待旧任务返回；旧任务迟到不会清除新的运行状态。报告原生网页销毁时主动结束待返回的读取请求，避免其结果悬挂或重复回调。

测试先用隔离安卓测试包和本地模拟站点刻意挂起一次报告登录响应：0.84.0 在更改设置后未能启动下一次报告登录；0.85.0 在旧响应仍挂起时启动新会话，随后释放旧响应，当前报告会话保持正确。后台切出和恢复期间没有重复请求。两套系统同时启用、分别关闭正在加载的另一套、清除任一会话及网页重载后恢复均通过；请求只到本地模拟站点，无报告上传和选退课。

实际 Android 组合 12 项、报告单系统回归 6 项、选课单系统回归 8 项通过；另有恢复中切换账号的组件专项和 357 项领域测试、Android 单测、构建、资源及签名核对。320×568、568×320、430×932、768×1024 的选课和报告页截图已留档并检查，未出现横向溢出；屏幕高度较低时需要滚动。记录见 artifacts/verification/native-dual-preload-1793149942563/results.json，辅助应用和端口转发已清理。

模拟器此前停止，按已获授权重启同一 LabMaker_API36；备份并核对 215 个文件后覆盖安装 0.85.0，安装后文件无缺失和新增，仅 WebView 运行设置变化。测试使用虚构账号和本地网站，并不代表真实报告官网登录或真机、完整冷启动和低内存恢复已经验收；未进行真实选退课、报告上传、付费 API 调用或发布。
