# 识图校对保存失败保护

0.108.0 处理本机识图校对草稿无法保存时的退出行为。关闭弹窗、页面切换和重新识别前，先保存并核实当前校对内容；失败时留在当前页面，保留未完成数字、勾选与其他校对内容，并在底部显示错误。用户可以重试，或明确选择“仍然关闭”；仍然关闭可能丢失本次修改。保存期间锁定校对控件，避免写入与新的编辑交错。正式录入测量数据仍需单独点击，识图草稿不会自动写入实验记录。

验证：浏览器使用实际校对页面和仓储、模拟文件写失败，覆盖退出、重新识别、打开新识图、失败后的主动关闭、写入挂起时锁定及恢复后的续接；三种手机和平板尺寸留图，既有识图校对、学生信息、照片、变长测点和缓存恢复回归通过。安卓隔离验收应用在实际 WebView 和原生私有存储接口上模拟写失败，检查退出、页面跳转、重新识别和恢复续接 4 项；所有识图响应是模拟数据，没有真实模型调用或学校操作。388 项领域测试和调试构建通过，当前模拟器覆盖更新前后 217 个文件一致。
