# 0.12.0 DeepSeek 配置教程

设置的 AI 服务新增“配置教程”，配置窗口中也可打开。移植原版最后确认的四步内容：登录开放平台、查看余额、创建密钥、填写实验搭子。保留大字引导、官网按钮、步骤切换与阅读进度，未恢复原版设计阶段已删除的模拟网站卡片。

最后一步移动并复用实际配置表单与保存/测试操作。切换步骤、返回配置保留未保存输入；推荐参数只填写地址和模型，不覆盖密钥，不自动保存或调用服务。Android 返回键或 Esc 从教程回到配置；关闭窗口清理教程状态，异步读取/保存不会重新打开旧页面。密钥输入框直接使用绿色加粗边框，没有外部绿色方块。

阅读进度使用应用私有文件 api-tutorial-a/b.json，经现有轮换副本及 SHA-256 验证，仅保存四个步骤编号。进度和加密 API 配置分开；损坏进度可重新阅读，不影响密钥、测量记录或报告。重启验收发现 WebView 本地存储的进度未可靠恢复，因此改用原生文件保存；测试不通过时没有宣称进度持久化完成。

官方配置依据核对于 2026-10-24：[首次调用 API](https://api-docs.deepseek.com/zh-cn/)、[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/)。当前推荐地址为 https://api.deepseek.com，模型名 deepseek-flash。教程不固定充值金额或价格，也不承诺识图准确率。
