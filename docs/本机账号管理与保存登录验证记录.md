# 本机账号管理与保存登录（0.16.0 测试版）

设置已接入绿色账号管理界面，支持添加、编辑、删除和明确确认后重置；选课和报告登录页可手动选择已保存账号登录，不会因进入页面自动登录。教务账号类型已预留，界面明确提示教务登录待接入。本轮没有存储真实账号密码，没有执行真实登录、选退课、报告上传或付费 API 调用。

## 存储与登录

沿用独立系统标识、AES-256-GCM、随机 IV 和 Android Keystore。密文通过 AtomicFile 保存到应用 `getNoBackupFilesDir()/school-accounts-v1.json`，提交后回读核对。单条密文缺失、格式损坏或校验失败仅锁定该记录，其余可读账号仍展示；目录结构损坏时拒绝自动覆盖，须明确重置。保存失败保留旧配置。编辑需重新输入密码，保存成功或退出界面清空密码输入框。

保存账号登录仅向原生端传记录标识和预期账号。选课流程先读取新鲜官网表单状态，再由原生端注入密码；登录响应不会原样返回可能回显凭据的 HTML，随后课表快照核对实际身份。报告登录复用独立原生 WebView，并核对当前登录代次，过期响应不能恢复旧会话。已删除、锁定、跨系统或账号已变化的记录会被拒绝。删除保存账号不等于退出现有会话。
