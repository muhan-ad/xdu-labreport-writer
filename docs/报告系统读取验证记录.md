# 0.10.0 报告系统读取初版

## 行为与边界

一站通增加实验报告提交入口。原报告网站使用 Ext/uniGUI，现由一个没有 Capacitor 桥接的独立原生 WebView 承载，读取符合原版实际字段 0/1/2/3 和操作列的唯一 grid；登录填写仅允许在报告网站内的唯一可见账号/密码字段和“学生登录”按钮。页面和资源采用限定来源策略，证书错误取消，不允许本机文件读取、文件选择和权限请求。

连接前、清除时重建报告 WebView 并清理 WebView Cookie。报告 Cookie 由系统 WebView 管理，与选课 OkHttp CookieJar 独立；不声称它是三系统加密账号管理，也不把浏览器 Cookie 描述成密码配置文件。应用不把报告密码写入配置，页面表单保存禁用。报告登录过期、密码失败、清除期间的迟到结果不会保留旧账号的报告列表。

列表、前后翻页及刷新从真实网页 store 读取，不拼造报告、分数或提交状态。后台状态更新在相同记录标识下只更新状态和控件，刷新不替换现有卡片；重新进入时复用已识别结果，保留位置。手机显示两列信息加状态区，平板三列，绿色周次块、黑色状态、28px 分数。

图片状态采用 ML Kit 随包中文模型在本机推理，不使用用户 AI API Key。两种缩放/灰度视图、每张图重复两行：数字成绩需重复值及两次结果一致，范围 0–100；任何一次识别出现“已”，按既定产品规则显示“已上传”；“未上传”等需一致。读取不可靠时保留图片并显示待核实，不假定为未上传或零分。文本成绩和状态优先，明确成绩禁用上传资格。SDK 自身的运行统计不是学校报告上传；这里不宣称整个 SDK 完全没有网络活动。依赖依据：[Google ML Kit Android 文档](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)。

本轮原生插件没有上传、commit 或文件选择方法。对应本机报告查找、原网站预览、上传前大弹窗预览和最终上传会继续实现，不以只读入口代替这些闭环。

## 验证

- 40 项领域测试通过：含新报告分数格式、范围、文本优先、图片来源、唯一 grid、原网站字段映射、分页范围和只读命令。
- 17 项业务 Java 单测通过（另有 1 项模板示例测试）：原有事务/网络/Cookie 11 项，新增状态规则 3 项及报告来源策略 3 项。
- 最新 APK 对本机模拟 uniGUI 通过 7 项组合：登录、原始“已上传”小图片和数字成绩的实际 ML Kit 识别、六种视口、翻页/未上传文本/未知图、刷新卡片节点保持、无上传方法、过期/密码错误和清除期间旧响应隔离、清除报告后选课 Cookie 仍保留。Cookie 隔离服务使用 Connection: close，排除模拟服务器空闲连接超时对该专项断言的干扰。
- 14 项原有选课读取原生回归通过。
- 查看 report-site-320.png、report-site-768.png：状态和数字为清晰原生文字，手机/平板无横向溢出。全部六种视口：320/360/430/768/1024/1280 CSS px。物理手机和 iOS 未验收。
- 真实官网 HTTP 匿名入口返回 200，确认 Ext/uniGUI；最新 APK 的匿名页面从 loading 进入 needs_login（report-site-anonymous.json），登录提交次数为零。之前发现文档尚未加载时误判来源，已加入文档提交/完成就绪门槛和空白文档等待；静态框架遵循浏览器正常缓存，不每次强制重新下载。
- 真实账号测试命令被自动审批拒绝，工具仅返回 blocked by policy，无具体理由。命令未执行，不存在本轮真实报告账号成功登录证据；没有绕过审批。
- 报告和选课模拟检查均未向学校提交；本轮未调用付费 AI，也没有上传报告。

## 体积与交付

中文模型压缩内容约 2 MB；主要额外体积来自 OCR 四种架构原生库。启用原生库压缩后，通用 APK 从开发过程约 72.6 MB 减到约 49.9 MB，仍含 arm64-v8a、armeabi-v7a、x86、x86_64，不通过移除手机架构削减当前兼容范围。安装包签名、网页资源、原生读取脚本与最终 APK 核对后交付。版本 0.10.0 / code 13。
