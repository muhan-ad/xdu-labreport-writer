# 单实验测试数据与中断恢复（0.50.0）

在实验录入页“更多”加入原版的“填入测试数据”。当前草稿先正常保存；确认填入后校验样本、备份并回读原测量记录，再写入当前实验，照片、报告和章节设置不参与写入。取消不填入样本。最近一次测试前备份会被替换，确认文字明确说明这一点。

备份现可包含一个或多个明确实验；恢复时只修改备份内的实验，其他实验在备份后手动填写的内容保留。普通模式也可以恢复或删除已有备份，不需要先打开开发者模式。页面显示备份时间和实验数量。

## 中断标记

新增应用私有目录下的 `debug-operation-a.json`、`debug-operation-b.json`。全部原记录已备份后、第一份测量写入前，双份保存操作阶段并回读；正常完成和逐份回读后清除标记。不能核实标记时不开始新写入。

应用启动发现未完成标记时，主页提供“查看并恢复”。调试页允许普通模式恢复，阻止再次填入或删除待恢复备份。恢复失败但其自身写入已回滚时，之前的中断状态仍保留。写入已全部核实、仅结束标记保存失败时，不反向破坏已完成的测量写入，而是明确告知标记保存问题，备份保留。

这补齐了 0.49.0 未完成的启动提示，不声称是操作系统级事务或自动恢复。真实系统杀进程、突然断电、存储设备故障仍需真机验证。当前恢复需要用户明确确认。
