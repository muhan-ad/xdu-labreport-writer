# 科学绘图库（0.24.0 测试版）

为 AI 本机绘图加入 Pyodide 0.29.3 对应的 SciPy 1.14.1、Pandas 2.3.3 和完整依赖。资源来自当前固定版本的官方锁文件，下载逐项核对 SHA-256；不升级已有 NumPy、Matplotlib，也不重新同步桌面实验模板或用户数据。`scripts/prepare-plot-science.py` 可独立补齐这些资源，完整运行环境准备脚本也保留相同依赖。

## 范围与加载

支持 Pandas 内存数据处理，以及 SciPy 的 optimize、interpolate、stats、signal、integrate、special、linalg、ndimage。模型提示同步这些能力。Pandas/NumPy 直接文件接口、SciPy io、系统/网络/桥接及反射等继续受原有执行约定和代码检查限制；AST 检查不是正式 Python 安全沙箱，实际代码仍只进入一次性、无本机桥接的独立 Worker，并继承禁止联网的 CSP。

库文件随安装包离线提供。客户端按代码是否包含 scipy/pandas 库名单词，选取依赖闭包并逐项校验后交给独立进程；Worker 采用同样选择加载包。代码注释或字符串包含库名也可能提前加载对应库。没有库名的普通绘图不会加载新科学库；普通报告引擎仍只加载原有四个基础包。

当前资源清单下，基础绘图传入资源 25,717,959 字节，SciPy 任务 41,096,339 字节，Pandas 任务 30,211,343 字节，两库同时使用 45,589,723 字节。这是资源字节量，不是运行时峰值内存。

## 验证

- 全部领域测试 87 项通过，新增依赖闭包/按需选择/缺失依赖检查。
- WASM 适配器 4 项正常场景和 18 项错误场景通过。科学场景使用明确的模拟点：分组后得到 y=2x+1，检验 curve_fit 与线性回归斜率 2、截距 1，样条 x=0.5 时 y=2，0 至 3 积分 12，以及线性方程、滤波、特殊函数、图像算子结果。生成 PNG 后清理临时任务。
- 桌面 Chrome 的实际独立 iframe/Worker/WASM 完整科学绘图通过，图像已人工查看。隔离与取消、超时、语法错误检查共 6 项通过，网络探测请求为 0。证据在 `artifacts/verification/ai-plot-isolation/`。
- 同一台桌面机器的两个不同测试任务：基础绘图 6370 ms、含两库的科学计算绘图 11691 ms。任务内容不同，不能据此估算库本身的固定耗时，也不能当作手机性能结果。
- Android 构建及 81 项业务原生单元测试通过。安装包 69,703,773 字节，相比 0.23.0 增加 19,747,743 字节；96 项安装资源和 18 项原生类定义核对通过。保持同一调试证书和关闭桥接参数日志。

本轮没有设备安装、真实付费模型调用、官网选退课或报告上传。手机内存、速度、绘图库在手机上的兼容性及完整 iOS 功能仍待验收。支持上述模块不等于支持原版任意 Python 代码，完整移植目标仍在推进。
