# 报告原始照片读取保护

0.117.0 在报告读取原始照片前核对路径、文件大小和图片类型；读取失败或明显异常时提示重新添加，停止本次生成，不覆盖已生成的报告。报告运行环境仍会进一步解码、检查图片，不能仅凭文件头保证图片完整。

模拟 Android、iOS 桥验证照片缺失、超过大小限制、格式错误及正常读取；实际浏览器文件系统验证照片保存到报告读取的往返。生成器故障测试确认读取照片失败时不执行计算或发布。393 项领域测试、Android 构建及 iOS 共享资源同步通过。

这不是 Android 真机或 iOS 原生验收；本次未安装更新，也未执行学校提交或付费 API 调用。证据：`artifacts/verification/photo-report-read.json`、`photo-read-all-tests-0.117.0.log`、`build-0.117.0.log`、`sync-ios-0.117.0.log`。
