# 0.70.0 带原始照片报告修复

2026-10-27。模拟器完整界面验收发现：带原始照片生成报告时报 `UnboundLocalError: cannot access local variable 'ai_total_bytes'`。0.69.0 不带照片的 28 个 Worker 测试没有覆盖此分支，因此此前报告生成验收不足以证明正常的带照片流程可用。

## 修复

`runner.py` 原始照片分支错误地累加尚未初始化的 AI 图组计数。删除该分支中的 AI 图组累计逻辑，保留原始照片的 Base64、8 MB、图像完整性检查。AI 图组仍在自身分支初始化并执行单张 8 MB、整组 32 MB 和摘要检查。

同步纳入技能分享取消的中文提示，仍以取消处理，不当成成功。
