# 安卓 AI 流式响应与等待验证

0.77.0（80）让 Android 普通聊天请求使用流式响应。手动思考题、生成前答题、章节调整、润色及 AI 绘图使用共同的聊天通道，因此都能在生成期间看到临时内容；思考增量只用于显示思考状态，不进入正文。完成后的答案仍需经过原有核对和导入流程。识图和连接测试维持原有非流式请求。

流式面板支持停止。超过 90 秒没有新的正文或思考内容时，显示“继续等待”和“停止”；继续等待保留原连接，不重新发送。新内容恢复时，过期的等待提示自动收起。仅保留有限的临时预览，较长内容显示最近部分；最终结果不因此截断。思考题的 JSON 外壳不会出现在常见预览中。

Android 原生层按请求隔离事件，校验取消和配置变更。请求密钥即使跨数据块出现，也先在本机替换后才发送到界面；中断或超长响应报错，不把部分结果当作完成结果。若兼容服务返回普通 JSON，沿用原有解析。网络地址和正式包的限制不变。

## 验证

- 351 项领域测试、141 项 Android 单元测试、完整构建及资源、原生类与签名检查通过。
- 新增原生解析测试覆盖 UTF-8 跨块、CRLF/CR、末事件、不同频道、密钥跨块、断流、损坏数据和长度上限；心跳不被当作有效进度。
- 请求适配测试覆盖先监听再发送、请求标识与顺序、注册期间取消、迟到事件、继续/停止和监听器清理。界面组件 5 项测试覆盖文本转义、思考与正文分离、长文本限制、等待选择、报告弹窗以及 320、568、768、1024 宽度；手机和横屏截图已抽查。
- `native-ai-stream-1793147546981` 在独立 Android 测试包上以本机模拟服务实测真正的 90 秒无内容提示、继续等待、单次 HTTP 请求、分段输出及停止。该轮是 0.77 最终界面调整前的原生实现，随后最终版补验了其他实际流程。
- `native-ai-stream-1793147976861` 对最终构建完成 6 项自动化检查：实际 Android 界面与本机服务的流式问答、跨块密钥脱敏、普通 JSON、断流拒绝导入、停止、实际报告润色和 AI 绘图代码草稿。测试使用独立包与临时密钥，未请求真实模型。
- 测试包单独允许访问本机模拟地址。正式 APK 的网络配置已回读，仍只有原有学校域名的明文例外，没有测试地址例外。当前模拟器主包更新前已备份，215 份原数据/配置更新后摘要均一致。

本次没有调用收费模型、学校写接口或发布应用。模拟器测试不能代替实体手机、真实服务商的流式兼容与输出质量验收；90 秒提示与最终版静态代码和组件分别验证，未将旧测试截图称为最终版截图。完整原版功能对齐仍需继续。
