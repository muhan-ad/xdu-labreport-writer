# 实验图表预设（0.17.0 测试版）

图表页新增“实验预设”，支持全部主图、单图预览、图片保存、放大查看和明确保存后的报告插入配置。沿用绿色界面，选择但未保存的配置在关闭后放弃；配置按实验保存。预设默认不追加到报告，开启并保存后才追加，原报告脚本自身的图表保持原有行为。

## 原版来源与范围

预设说明来自本机桌面版 `src/shared/experiment-chart-presets.js`，覆盖 28 个实验；其中 13 个实验有图组，共 23 个单图选项。派生坐标与渲染复用已封装的 `common/official_charts.py`，与本机桌面源码除换行符外一致。来源和哈希见《图表预设来源.json》。本轮没有重新浏览核对官网要求，不把已有定义称为本轮官网核验结果。

没有关系图要求或资料待核实的实验不会编造预设。两学期偏振实验分别使用马吕斯关系和三组极坐标；霍尔“全部主图”只包含两张霍尔电压图，两张磁场辅助图可单独选择。螺线管按原版规则绘制左右两侧纵坐标，保留单位，不添加左右图例。

报告插图重新使用本次数据生成，不把过期预览带入新数据。无效数据、预设或插入章节会明确失败并清理任务。预设渲染使用独立样式上下文，防止报告脚本的全局绘图样式改变预览与插图。

## 验证结果

- 69 项领域测试通过，包括实验归属、学期隔离、无预设实验及旧配置兼容。
- WASM 实际运行：36 组整组/单图预览、13 个实验报告追加图组、4 项异常检查通过。核对 PNG、图片数量、插入章节及图组顺序；报告插图与对应预览 PNG 逐字节一致，成功和失败后临时任务目录均为空。
- 28 个实验默认报告生成回归通过。
- 桌面 Chrome 生产报告组件 11 项检查通过，覆盖草稿放弃、恢复、保存失败重试、旧结果隔离、改选后失效、无预设实验及嵌套放大/返回。此测试模拟引擎，展示独立 WASM 检查实际生成的 PNG，不等同 Android 验收。
- 320、360、390、768、1024、1280 像素宽度无横向溢出，320/360 截图已人工检查。修复预览图撑宽页面及底部按钮文字挤成多行的问题。
- Android 构建与 40 项原生业务单测通过；APK 92 个安装资源、关闭桥参数日志、9 个原生类定义及调试签名检查通过。

入口：`npm test`、`node scripts/test-official-presets-runtime.mjs`、`node scripts/test-official-presets-browser.mjs`、`node scripts/test-report-runtime.mjs --all`。浏览器测试依赖实际运行产生的 PNG。记录与截图位于 `artifacts/verification/official-presets`、`artifacts/verification/official-presets-ui`。
