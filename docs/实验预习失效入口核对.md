# 实验预习失效入口核对

版本：0.99.0。2026-10-28 只读核对学校 [实验目录](https://wlsyzx.xidian.edu.cn/expe/index.html) 及其 `experiments.js`：目录列出 24 个编号，原有“劈尖干涉”映射的 22 号未列出；学校详情页对未列出编号显示“实验未找到”。其余已映射编号均在当时目录中。“电子元件伏安特性的测量”和“长度与体积的测量”也没有明确映射。目录可能随学校维护而变化，上述结论不表示这些实验没有其他资料。

移除当前失效的 22 号映射；未明确匹配时提示用户，并提供学校实验目录和取消按钮。光偏振上下学期、薄透镜及空气/水声速的既有共用映射保持，命中时直接打开详情。用户在确认时切换实验，不会打开旧实验的目录。

生产页面模拟测试覆盖提示、取消、目录入口、上下学期映射及 320/390/768/1024 宽度；已检查 320 宽截图。当前安卓模拟器的真实应用界面通过四项操作，Browser 打开调用替换为记录以避免真实跳转，并已检查截图。379 项领域测试、安卓构建及资源核对通过。

模拟器覆盖安装前后 217 个文件一致；完成界面测试后，216 个文件仍一致，另一个为系统 WebView 设置。iOS 共享资源已同步，但未进行 Xcode 构建或设备测试。
