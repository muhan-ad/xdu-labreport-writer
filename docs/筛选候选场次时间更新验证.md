# 筛选候选场次时间更新验证

版本：0.97.0。模拟学校数据，没有真实选退课或上传。

原筛选候选目录在已读取后缺少场次开始时的增量更新，弹窗打开或目录缓存仍有效时可能显示已经开始的场次。现在到达开始时间、或页面恢复焦点时，使用已读取的场次重新计算实验和教师候选；不重新请求官网，不把部分读取标记为完整。

已经勾选但不再属于当前候选列表的项目继续保留，可由用户自行取消；界面说明它当前不在已读取的候选列表中。候选列表重绘时尽量保留当前候选焦点和滚动位置。

模拟页面测试覆盖实际定时器跨越开始时间、删除未勾选过期场次、保留勾选和焦点、教师与剩余实验配对及应用筛选；原教务筛选与账号切换测试分别通过 12 项和 4 项。375 项领域测试、安卓构建及资源核对通过。当前模拟器已备份并覆盖安装，217 个数据文件前后一致；未在 Android 界面复现这一时间边界。

iOS 共享资源已同步核对，但未进行 iOS 构建或设备测试。真实官网响应、真实手机的系统键盘和长列表仍需验收。
