# AI 章节变体调整（0.28.0 测试版）

生成报告的章节组合中新增“AI 调整”，对应当前选中的文字变体；随机选项下打开第一份变体，采用后明确选定该编号。只读题目/答案组不加入文字变体调整。弹窗可查看原文、填写要求、生成/停止、编辑结果并采用，已有调整可恢复内置。新结果不自动采用。

请求复用启用技能、实验知识、自定义要求/风格、当前测量与可取得的计算上下文，明确要求保持原意、全部 LaTeX 公式和 %%...%% 数据占位符。采用前检查公式与占位符的完整原文序列，限制文本和配置大小；数据、章节或变体变化时拒绝旧返回。保存失败保留内容，可重试。

调整按实验、章节、变体编号保存在报告配置，记录内置原文与新文本。旧配置没有该字段时保持原行为。采用时只清除本章冲突的已导入润色及关联，不删除历史正文、其他章润色或思考题，避免旧润色覆盖新变体。

## 报告引擎

生成时将调整配置传入离线 Worker。Python 再次检查文本、公式、占位符、编号、体积与内置原文，临时包装当前任务内的变体读取；只处理当前报告目录中实际读取的模板。结束时恢复读取函数，失败清理临时任务。任何配置未找到对应原文时拒绝发布报告，不静默忽略。没有改写安装包资源或桌面原项目。
