# 开发者调试（0.49.0）

对照原版设置中的模式切换、全部填入测试数据和诊断导出，新增手机版调试工具页。设置中“贡献数据”独立放在“开发者调试”下方。

默认普通模式隐藏测试数据修改按钮；模式采用本机双副本存储。开启后可对全部 28 个实验填入已有模拟样本。样本来自项目已经用于运行时验证的 `tests/fixtures/measurements.json`，生产副本为 `src/data/test-measurements.json`；不编造用户的实测数据。

## 数据语义

先读取全部原记录、校验全部样本，随后完成测试前测量备份的双副本写入及回读，最后才逐个保存测量记录，每份保存后回读。最后一个样本无效或备份失败也不会开始修改测量记录。日期保留；照片、报告、AI 内容、章节与账号存储不参与写入。

写入中发生错误时，包括“已落盘但返回失败”的当前实验，均按逆序尝试恢复原记录并回读。恢复失败会列出实验名称，保留完整备份，不声称全部恢复成功。可重新打开调试页手动恢复备份；恢复前再次明确提示会覆盖测试后手动修改的测量数值。

保留最近一次测试前备份，下一次填入会替换它。可单独确认删除备份的两个副本，当前测量、照片与报告保留。备份最多 1,800,000 字节，超出时停止而不是跳过备份。它保存在应用私有目录的 `lab-maker/v1/debug-backup-a.json` 和 `debug-backup-b.json`，不上传。

这是有持久备份和异常回滚的串行操作，不是操作系统级多文件事务。系统在写入中直接杀进程/断电尚未实机验证，也没有宣称自动续传或自动回滚；再次打开后可用持久备份手动恢复。测量数据清除不会自动删除这份明确创建的调试备份，需要在调试页单独删除。

## 诊断与页面

诊断摘要仅包含应用版本、平台、时间、公开实验名称、填写项数、是否存在数据及可读取/降级/不可读取状态。不包含测量值、原图、学生信息、报告正文、账号密码或 API Key。资源及实际报告运行诊断复用已有维护页。

确认和写入期间，应用路由与 Android 返回处理阻止离开；确认框仍可取消，取消不生成备份或写入数据。后台、进程终止和系统分享器仍需真机检查。

- 7 项调试领域测试：28 样本与备份顺序、非空原记录/日期精确恢复、末项无效/备份失败零修改、落盘后异常回滚、恢复失败列名、回读不一致/无效备份拒绝、模式/备份跨仓储实例恢复及删除。
- 全部逻辑测试 233 项通过。
- 实际生产路由/仓储浏览器组合 9 项通过，测试使用独立浏览器目录；28 份填入和恢复后的主页记录数分别为 28 和 0，诊断输出字段已检查。
- 实际设置与其他入口回归 11 项通过。
- 实际 Reports 按钮、共享生成器、WebAssembly 和浏览器文件系统保存回读通过，刚体报告 64 条公式。未更改计算算法，不重复全部 28 实验科学验算。
- 调试页 320、360、390、768、1024、1280 像素无横向溢出，截图位于 `artifacts/verification/developer-ui`；人工检查 320/1024 像素布局。

本轮未操作真实用户数据，未安装到设备，未执行选退课、上传、付费 API 或发布。预览包的资源、签名及原生测试核对见 `artifacts/preview/verification-0.49.0.json`。
