# 自建变体归档与管理（0.29.0 测试版）

AI 调整弹窗默认勾选“同时存入自建变体库”。采用后将完整文本、内置原文、实验/章节/编号和时间归档；相同内容使用相同标识，重复归档不增加重复条目。沿用原版“采用成功、归档失败单独提示”的处理，可重新打开已采用文本重试归档，或取消勾选只采用。

设置 → 自建变体库支持选择实验、搜索章节或前 100 字摘要、每页 10 条、查看原文/正文、确认选用、删除、清空和导出。选用前重新读取归档并核对当前内置原文；内置版本不匹配时只可查看、导出，不猜测映射。当前选用对应已有变体编号，会清除本章冲突的已导入润色；其他章、思考题和测量数据保持。

删除归档或清空库不撤销已采用文本。清除测量数据/报告配置保留独立自建库。库按实验保存于现有私有文件存储，采用双份校验、独立条目和有界索引；不保存 API 配置。删除/清空会使此前排队的归档失效，防止晚到写入恢复已删除内容。

## 手机版文件导入导出

支持本实验完整库或单条导出；文件为带版本、归属和内容标识的手机版 JSON。导入前完整检查每条公式、占位符、实验归属、结构和内容标识，再开始写入；重复内容合并，保留记录时间。不执行文件中的任何代码。

单文件最多 8 MB、500 条；完整库超限时拒绝导出并提示按条导出，不把部分结果称作完整库。写入中失败显示已核对完成数量及其余状态待重试，重试去重，不宣称全部完成。当前不直接接受缺少内置原文/编号映射的桌面旧格式。

## 验证

- 全部领域测试 111 项通过，新增 8 项归档标识去重、实验隔离、损坏副本/内容绑定、删除清理、配置更新边界、文件校验及旧写入隔离检查。
- 10 项实际库页面和仓库检查，覆盖分页、转义、搜索、确认选用、旧内置限制、导出和实际 File 导入解析、无效文件不写入、删除/清空范围、读取失败重试和晚到响应。
- 实际 Reports 变体组合扩为 5 项，确认默认归档、恢复不删归档、归档失败不撤销采用及取消归档；批量润色、报告偏好各 5 项回归继续通过。
- 320/360/390/768/1024/1280 宽度检查管理页，320 宽度截图人工查看。证据在 `artifacts/verification/variant-library-ui/` 和 `report-variant-ui/`。
- 自动化浏览器启动时遇到 Windows 短暂端口文件锁，测试工具增加有界重试；重试后的报告偏好检查通过，未将启动失败归为应用故障。

本轮没有真实付费调用、设备安装、系统分享发送或官网写操作。原生文件选择/存储/分享、真机性能、桌面库格式互导，以及把归档追加为新的候选编号仍待继续；当前可用于其对应内置变体位置，未将这一步称作整个原版库功能或应用移植完成。
