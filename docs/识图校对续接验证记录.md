# 识图校对续接验证记录

版本 0.62.0，Android versionCode 65。

## 功能

有可用记录时，识图准备页优先提供绿色“继续上次校对”；也可明确选择重新识别。恢复不会再次调用模型，也不会自动录入测量数据。

保存内容包含识别字段、人工修改、勾选项、可变测点及对应表格长度、“仅填空白”和扫描增强状态。未写完的科学计数输入可以原样保留，继续编辑后仍须通过正常校验才能录入。

每个实验只保存最近一份，使用现有私有存储双副本、摘要、串行写入和回读机制。绑定实验、schema、测量记录日期/更新时间/草稿与照片存储路径；绑定变化或结构不兼容时不提供旧结果。照片使用已有不可变路径引用，缓存不重复保存图片、API Key 或密码。

识别成功后保存一次，后续校对输入短暂防抖保存；关闭时再保存当前状态。缓存写入失败保留校对界面并提示，不能因此阻止用户关闭窗口。恢复读取期间只暂时禁用开始识别/处理预览，关闭和原图查看仍可用。

新照片、移除照片、清除实验均清理本实验缓存；明确录入成功后也清理，不在关闭时重新保存旧结果。清理递增任务代次，旧识别、旧保存以及跨过清理边界的读取不能用新代次复活旧记录。缓存损坏可以单独清除，测量数据不受影响。

缓存负载上限为 500,000 个 UTF-8 字节，读取前还检查文件大小。校验字段、数组层级、字符串长度、选择项和照片/数据绑定；不是把任意旧 JSON 直接回填表单。缓存不包含原始模型全文或新的图片副本。

- 11 项实际 AIFeatures + OCRReviewEditor + Repository 组合检查通过。模拟识别接口和隔离内存存储覆盖关闭/恢复、全新实例、未完成输入、勾选/仅空白、增减点、数据/照片/实验隔离、损坏、写失败、清除、晚到响应和明确录入后不残留。六尺寸截图保留。

- 原校对 9 项、可变测点 4 项、调试中断/单实验 6 项及设置导航 16 项回归通过。正式压缩构建的图片处理/导航/照片保存 4 项回归通过。

## 测试等待修正与限制

正式构建图片预览测试曾超时。诊断记录显示 document.getAnimations() 包含折叠 details 内 group-fields 的 pending arrive 动画，等待整页所有 finished Promise 会不结束。测试改为观察当前可见 ai-sheet 的透明度和变换稳定，应用原有动画未关闭或修改。修正后连续两次通过；诊断在 artifacts/verification/ocr-image-ui/animation-diagnostic.json。

全部识图请求为模拟，照片/数据为合成样本，未触碰用户真实数据。浏览器重载与新实例不能代替 Android 强杀进程、断电或系统存储故障验收；最后一次尚未完成写入的编辑也不能保证恢复。尚未实机安装或发布，学生信息识别及其余原版差异继续核对，总目标未完成。
