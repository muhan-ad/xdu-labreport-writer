# 队列单项管理（0.67.0 / Android 70）

## 原版对照与行为

原版 `renderer.js` 的 `moveQueueItem`、`cancelQueueItem`、`removeQueueItem` 和 `clearFinishedQueue` 分别提供等待任务调序、单项取消/当前终止、移除记录和清除已结束。手机版此前只有全队列暂停/继续/停止/重试。

现补齐这些操作：等待任务可上移、下移或取消；计算中的任务可单独终止，后续任务继续；已结束任务可移除记录；队列空闲时可清除已结束记录。操作只改变队列状态，不删除报告、照片或测量数据。清除记录保留实验选择。保存阶段禁用单项终止，原有“完成当前后停止”仍负责安全结束发布。

列表按实际队列顺序显示，再列出未加入本次队列的实验；搜索不会重排真实队列。任务按钮与选择标签分离，避免点操作按钮改动选择。按钮按手机宽度换行，页面去掉重复的“批量生成报告”标题。

调度改为每次从当前列表取下一项，避免移动/移除造成索引遍历漏项或重复执行。终止信号只属于当前计算，迟到进度不能覆盖后续任务。暂停时取消最后一个等待任务会唤醒调度并正常结束，防止永远停在暂停状态。

- `test-report-queue-worker.mjs`：实际 Repository、ReportGeneration、ReportQueue 和生产 WASM Worker 跑完 28 实验；先隔离一份不完整数据，修复后只重试该项，生成调用共 28 次，最大并行数 1，28 份报告均有已回读元数据和生成身份。
- `test-queue-controls-production-browser.mjs`：实际压缩应用五项检查。隔离的浏览器本机存储填入内置测试数据，确认三项队列，调序/取消等待项，第一份真实报告完成后暂停，续跑时终止当前 Worker，最后清除队列并在报告管理中核对已发布报告文件仍可读取。五尺寸截图已检查；没有模型或学校调用。

测试没有触碰用户测量记录，也没有安装到手机、执行真实学校提交、请求付费模型或发布。桌面浏览器中的真实 WASM 不替代 Android 真机长队列、系统后台与进程中断验收。证据位于 `artifacts/verification/report-queue-*`、`queue-controls-*`。
