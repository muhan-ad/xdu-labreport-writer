# 物理实验报告自动化

大学物理实验数据处理一键生成 Word 实验报告（.docx），含公式渲染、数据表格、不确定度计算、思考题解答。

## 快速开始

1. 双击 `setup.bat` 一键安装 Python 和依赖（清华镜像，无需手动操作）
2. 进入 `实验脚本/<实验名>/`，双击 `run.bat`
3. 首次运行自动生成 `数据.xlsx` 模板，填入测量数据后再次运行
4. 生成 `实验报告.docx`，公式可双击编辑，直接提交

## 依赖

- Python 3.9+
- openpyxl（Excel 读写）
- matplotlib（图表）
- python-docx（报告生成）
- latex2mathml、mathml2omml、lxml（公式 LaTeX → OMML；已随 `实验脚本/common/_vendor/` 内置）
- pywin32（**可选**，仅 `tests/word_report_test.py` 的 Word 实物验收用；报告生成不需要 Word）

`setup.bat` 会自动安装所有依赖。

## 项目结构

```
物理实验/
├── setup.bat              ← 一键安装
├── requirements.txt
└── 实验脚本/
    ├── common/            ← 公共工具库
    │   ├── docx_report.py     报告生成（python-docx + OMML 公式，无需 Word）
    │   ├── docx_omml.py       LaTeX → OMML 公式转换
    │   ├── _vendor/           内置公式依赖（latex2mathml / mathml2omml）
    │   ├── uncertainty.py     不确定度计算
    │   └── ...
    └── <实验名>/
        ├── generate.py    数据处理主脚本
        └── run.bat        双击运行
```
